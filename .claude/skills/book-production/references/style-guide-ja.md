# 『孫子の兵法』Web book — 執筆スタイルガイド v1

## 読者と約束

- 読者は高卒〜大学一般教養レベル。漢文の素養は前提にしない。専門語は初出で一行定義する。
- 本書は「本」であり、ブログでも教科書でもない。文庫本一冊（全体で約11万字）。章は 5,500〜7,000 字（前編各篇）。
- 文体は **です・ます調**。一文は 60 字以内を目安（長くても 80 字）。段落は 3〜6 文。箇条書きは章に 2 回まで（原則は散文で語る）。
- 語りかけは「読者のみなさん」ではなく、二人称を使わず主語を工夫する。「私たち」は使ってよい（著者と読者が一緒に読む姿勢）。
- 比喩や例は **メカニズムが同じ**ものだけを使う。「似ている気がする」程度の連想は書かない。

## 章の型（前編の各篇）

1. **導入**（600〜900字）：この篇が答える問い。具体的な場面（史実・現代の場面・身近な例）から入る。
2. **原文を読む**（2,500〜3,500字）：篇の論理順に 3〜6 個の `quote` ブロックを置き、各ブロックの直後にその一節の解説（背景・語の意味・前後関係）を 300〜600字。原文は **必ず** `quotes.md` の `原文` と一字一句同じ文字列を使う（照合リントあり）。訓読・出典も register の値を使う。訳は register の現代語訳を使うか、より自然に整えてよい。
3. **構造を図で見る**（300〜500字 + 図1）：篇の論理を一枚の SVG にする。図は `![図N キャプション](figures/NN-name.svg)`。図は章あたり 1〜2 枚。
4. **接続**（`connect` ブロック 2 つ、各 400〜700字）：異なる分野（科学・工学・産業・市場・スポーツ・生物・歴史など）で**同じ形**をしている現象と結びつける。章ごとに割り当てられた分野を使い、他章と重複させない（接続マップ参照）。「なぜ同じ形なのか」を一文で言い切り、違いも一言添える。
5. **誤解されやすい点**（`note` ブロック 1〜2 個）：成語化で意味がずれた表現、テキスト異同、後世の解釈など。
6. **この篇の一行**（200〜400字）：篇を一文に圧縮し、次の篇への橋をかける。最後の段落は次篇の問いで終える。

## 後編（応用）の型

- 原文の引用は前編で提示済みの一節を `quote` ブロックで再掲してよい（1 章 2〜4 個）。
- 「現代の言い換え」は必ず「原文はこう言っている → 現代ではこう読める → ただし原文はこうは言っていない」の三段で書き、原文に無いことを原文に帰さない。
- 当ワークフォース（約 40 名の AI ペルソナからなる会社：Notion に記事を書き、PR をレビューし、ポッドキャストを作る。統治文書 L0〜L3、R ルールの機械ゲート、pr-autopilot による合議マージ、エージェント×スキル×プロジェクトの結合）への適用は、第18章にのみ集中させ、他章では一般のプロジェクトとチームを対象にする。

## 書いてはいけないこと

- 原文に無い文言を「孫子は言った」と書く（例：「兵は拙速を貴ぶ」は成語。原文は「兵聞拙速、未睹巧之久也」）。
- 特定の現代訳者の訳文・書き下しの独特な表現をそのまま写す（訓読は慣用に従った自前の書き下し）。
- 「ビジネス書」的な断定（「成功者は皆〜」）、自己啓発調、感嘆符。
- 数字・年号・人名で確証のないもの（不確かなら「〜と伝えられます」「諸説あります」と明記）。
- 同じ接続（例：免疫系、将棋、サッカー）を複数章で使うこと。
- 見出しの乱用：H2 は 4〜6 個、H3 は必要最小限。

## Markdown の約束

- 1 行目は `# 篇名 — 副題`（例：`# 始計篇 — 戦う前に、数える`）。
- `quote` / `connect` / `note` のフェンスは `references/content-contract.md` の形式どおり。
- 図：`![図1 五事七計 — 勝算を数える五つの軸](figures/01-five-factors.svg)`。キャプションは「図N 題 — 一行説明」。
- 表は GFM。URL は本文に出さない（出典は巻末）。
- ふりがなは `訓読` の難読字に「殆（あや）うからず」の形で初出のみ。本文中の難読語も同じ形で初出のみ。
