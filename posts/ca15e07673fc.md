## Executive Summary

Anthropic Economic Index の2026年6月版「Cadences」は、Claude の利用ログを約9,700人の自己申告アンケートと接続し、AI利用が時刻・曜日・職種によって構造化された「リズム（cadence）」を持つことを示した。最大の発見は自動化パラドックスである。作業をAIに委任した割合が高い利用者ほど、翌年の自分の仕事への影響を悲観するのではなく、むしろ楽観的だった。利用データが捉える「観測された曝露」より、人々が自己申告する体感のAI能力の方が一貫して高い。

## 調査設計：利用ログと自己申告を9,700人で接続

これまでの Economic Index は利用ログの分類に依存していた。今回は自己申告アンケートを利用実態と紐づけた点が新しい。ログは「何を使ったか」を語るが、「どう感じているか」は語らないためだ。

- 「最終的にリンクされたサンプルは約9,700人（about 9,700 survey respondents）」の回答者で構成される。
- 分類器は「Claudeの会話の93%が成果物（artifact）を生成した」と判定した。
- 成果物の上位は「説明（explanations、会話の17%）、文書・レポート（documents and reports、15%）、ガイダンス（guidance、11%）」。
- 回答者の職業構成は米国雇用と乖離する。Computer/Mathematical は回答者の30%（米国雇用は4%）、Management は23%（同7%）で、運輸・飲食・建設は過少代表。
結論：この構成の偏りは、報告書の数値が「AIを既に使う層」の断面であることを意味する。母集団全体ではなく、早期採用者の心理と行動を読むデータとして扱う必要がある。

## 「Cadences」：利用は時刻と暦に沿って動く

報告書名の通り、利用は平準化されておらず、生活と業務の周期を反映する。

- 個人的な会話の比率は平日の約35%から週末の約50%へ上昇する。
- レシピ関連の要求は午後6時に平均の2.3倍。
- 「4月14日には、税務関連のクラスタが5月の平均的な日の8倍（eight times as common）」に達した。
- 製品面ごとに自律性が異なる。Claude Code は自律度が平均で「0.37ポイント高い（0.37 points）」。Claude Code の会話の54%が Opus で処理され、チャットおよび Cowork では10%（54% ... against 10%）。
- 用途は業務・個人で偏る。マーケティング・コンテンツ作成は80%が業務、ブログ・記事作成は81%が業務、データベース照会は82%が業務。一方で創作は80%以上が個人利用。
- 消費トークンにも賃金勾配がある。高賃金のマーケティング・マネージャーは編集者の約2.5倍のトークンを消費し、アプリ・ウェブサイトは会話中央値の3倍、説明は約5分の1。トークン消費における賃金勾配の44%は成果物の構成（output mix）で説明される。
結論：AIは単発のツールではなく、生活・業務・暦のリズムに組み込まれた常在的な層になりつつある。曜日・時刻で用途が切り替わり、成果物の種類が賃金と結びつく以上、単一の「平均的ユースケース」を前提とした製品設計や評価は実態を取りこぼす。

## 自動化パラドックス：委任するほど楽観的になる

最も反直感的な発見は、自動化の度合いと将来展望の関係である。

- 「自動化されたセッションの割合が高い人ほど、翌年の自分の仕事の結果に対するAIの影響について、より楽観的に感じている（feel more optimistic）」。
- 今後12か月の体感として、速度で86%、範囲で82%、品質で69%が改善を報告（86%, 82%, and 69%, respectively）。
- 57%が「自分のスキルはより価値を増す」と回答。
- 一方で自己申告の曝露は観測された曝露を一貫して上回る。約6割が今後12か月でタスク自動化の増加を見込む。
結論：自動化＝雇用不安という単純な図式は、少なくとも早期採用者の体感とは合わない。委任を進めた層は喪失より拡張を体験している。ただしこれは因果ではなく、楽観的な人ほど委任するという選択効果の可能性を排除できない。

## 誰が使い、誰が恐れるか

採用と不安には人口統計上の勾配がある。

- 女性は「リンクされた回答者サンプルのわずか12%」。自動化比率は「0.33標準偏差低い（7.3パーセントポイント）」一方、反復的でチャット時間の長い協働的な利用が多い。
- 経験15年以上の層は、キャリア初期層より体感曝露が約10ポイント低い。
- 自分の失職を「起こりそう／非常に起こりそう」と評価したのは10%にとどまる。一方、後輩・若手の同僚については約37%が失職確率60%以上と評価した。人々は自分より他者の仕事を心配する傾向がある。
- 所得のパラドックスも観測される。高所得国はAIのタスク遂行能力を約10ポイント低く評価し、低所得国はむしろ高く評価する。IMFは低所得経済における補完的スキルとインフラの不足を指摘している。
結論：AIの採用度・自律性の高い使い方・将来不安は、性別・経験年数で偏って分布する。全社導入を「均一な曝露」として扱うと、協働的に使う層と委任的に使う層の差、そして初期キャリア層の不安を見落とす。体感と観測のギャップこそ、次に測るべき指標である。
