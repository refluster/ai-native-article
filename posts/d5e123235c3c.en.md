## Executive Summary

On July 2, 2026, Anthropic added admin analytics, model permission settings, and spending-threshold alerts for Claude Enterprise. By combining dashboards that visualize usage and cost by group and user, a dedicated metrics tab for Claude Code, Analytics Chat for natural-language queries, and the Analytics API for programmatic integrations, the company aims to give organizational administrators and finance and IT teams a unified way to monitor and govern Claude deployment and costs.

## Admin Dashboard: Visibility by Group and User

The centerpiece of this update is an admin dashboard that displays usage and cost by group and by user. It is designed not just to show total spending, but to break down what that spending consists of.

- It displays created artifacts, the number of files edited, and the skills / connectors used, each alongside its associated cost.
- It can be filtered by SCIM groups, allowing aggregation to map directly onto an organization’s existing structure.
- At the user level, administrators can view cost breakdowns by product and by model, as well as progress against a spend limit.
Rather than stopping at “how much was spent,” the focus of this feature is to break spending down into “what it was spent on” — generated outputs, edits, and connected destinations.

## Dedicated Usage / Value Tabs for Claude Code

For Claude Code, which developers use, the dedicated dashboard now includes 2 new tabs.

- **Usage** tab: Shows the number of active developers, the number of sessions, and top commands, and is updated daily.
- **Value** tab: Shows productivity lift estimates, cost per commit, and annual value.
The structure is designed so that Usage covers “how much it is being used,” while Value covers “how much value that usage is producing,” making it possible to assess return on investment from both the cost side and the outcomes side.

## Analytics Chat and the Analytics API

Access to aggregated data is also provided in 2 directions.

- **Analytics Chat**: Lets users query analytics in natural language. One example given is “Which teams doubled their Claude usage this month?”, and results can be exported as chart artifacts.
- **Analytics API**: Provides programmatic access to the same data and can integrate with cost-management tools such as Datadog Cloud Cost Management and CloudZero.
By supporting both interactive exploration through Analytics Chat and automated ingestion into existing operational infrastructure through the Analytics API, the company makes it possible to use visualization data both for individual review and for organization-wide cost management systems.

## Model Defaults and Spending-Threshold Alerts

In addition to visibility, the update also adds proactive control mechanisms.

- **model defaults and entitlements**: Administrators can set the default Claude model used for new conversations in chat, Cowork, and Claude Code.
- **spending-threshold alerts**: Administrators are notified when organization-level limits reach 75% and 90%.
- **in-app notifications for users**: The relevant user sees a notification when their limit reaches 75% and 95%, and can request a higher limit directly from there.
- **Admin API**: Automates review of increase requests, monitoring of spend limits, and flagging of usage patterns so the system can be operated at enterprise scale.
These features are aimed at organizational administrators managing Claude deployment across the company, as well as finance and IT teams. The core of this update is that it brings visibility — what happened — and control — what to allow through default models and thresholds — into the same administrative surface, so retrospective monitoring and proactive governance can be handled as one continuous operational workflow.
