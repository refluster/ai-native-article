## Executive Summary

The "Claude Forward Deployed Engineer" path on Anthropic's partner learning site, Skilljar, is a self-paced sequence of 11 courses, about 9.5 hours in all, for people who take a customer from a first use case to a working pilot on site. Its stated end point is not code but a pilot plan: the baseline you will measure against, the success measures agreed before building, the part of the use case shipped first, and how the first wave of users is brought on.

## What the path is for

The page states the aim in one line: take a customer from a first use case to a working pilot, on site. The stated prerequisite is that you build software and have worked directly with client teams. The format is self-paced, about 9.5 hours, in order or one course at a time.

What you can do at the end is write a pilot plan for a customer use case. The plan covers four things:

- the baseline you will measure against
- the success measures you agree on before building
- the part of the use case you ship first
- how you bring on the first wave of users
## The 11 courses

The courses fall into three groups. Durations are the page's own; the totals are summed here.

**Core (1–4)** 1. AI Capabilities and Limitations (about 60 min): the limits you will be explaining to users from the first day of a pilot. 2. AI Fluency for Builders (about 45 min): the 4D Framework of delegation, description, discernment and diligence, applied to building. 3. Claude Platform and Model Foundations (about 60 min): the four decisions before writing a prompt: entry point, capability features, model and context. 4. Choosing the right Claude model (about 10 min): which model fits which kind of task, and how each draws on your rate limit.

**Role courses for building (5–9)** 5. Claude Platform 101 (about 90 min): from the first API call through the agent loop, tools, extended thinking, skills, Model Context Protocol (MCP), context management and managed agents. 6. Claude Code 101 (about 60 min): the tool you prototype with in the customer's repository. 7. Claude Code in action (about 60 min): running long, hands-off sessions in a customer's repository and controlling them with permission modes, hooks and verification. 8. Introduction to Model Context Protocol (about 60 min): connecting Claude to the customer's systems. 9. Introduction to agent skills (about 30 min): packaging what works so the customer's team can reuse it.

**Role courses for delivering the pilot (10–11)** 10. Delivery Methodology (about 40 min): qualify the use case, design the pilot, capture the baseline, and manage adoption and risk. 11. Driving enterprise adoption of Claude (about 60 min): how a customer moves from activation to scale, covering the success team, enablement, launch and finding the next workload.

The groups sum to 175, 300 and 100 minutes: 575 minutes, about 9 hours 35 minutes, consistent with the page's "about 9.5 hours".

## Relation to the Claude Developer path

According to the page, this path shares nine courses with the Claude Developer path. If you have completed that path, two courses remain, about 100 minutes in all. In the list above the shared courses are 1 to 9 and the remaining two are 10 and 11, whose durations add up to exactly 100 minutes. The path's own content is therefore concentrated in delivery methodology and adoption, not in technique.

The page adds that a core course completed once on the site counts toward every path that includes it.

## Link to certification

The recommended next step is preparing for Claude Certified Developer - Foundations. The exam is the credential the path leads toward and counts toward partner tier in the Claude Partner Network. The prep courses go deeper on prompting, agents and tool use, evaluation and security, and take about 13 hours.

Three further routes are listed:

- If engagements move toward production: Claude Certified Developer - Professional (agent architecture, reliability, observability, evaluation, cost and latency, security).
- If you lead solution design: Claude Certified Architect - Professional prep, two of whose prep courses fit this path.
- If you deploy Claude Code for customers: the Claude Code partner badge. This path includes one of the badge's eight courses; the badge is free, the courses take about 12 hours, and a capstone and an assessment follow.
Registration is open to Claude Partner Network members.

## Evidence and conclusion

**Evidence (what the page says):** the target deliverable is a pilot plan; nine of the 11 courses are shared building content while the two path-specific courses are delivery methodology and adoption; the definition of the deliverable includes success measures agreed before building, and a baseline.

**Conclusion (what we draw from it):** the role this path assumes is someone who writes code and also agrees the measurement terms with the customer first. Nine courses on technique and two on the customer-side process mean technique takes most of the learning time, while measurement and adoption come first in the definition of the output. The page gives no post-course outcomes or pass rates, so this source cannot show whether the path actually raises pilot success.
