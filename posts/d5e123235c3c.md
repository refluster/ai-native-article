## Executive Summary

Anthropic は 2026 年 7 月 2 日、Claude Enterprise 向けに管理者用の分析機能・モデル権限設定・支出しきい値アラートを追加した。グループ／ユーザー単位で利用量とコストを可視化するダッシュボード、Claude Code 専用の指標タブ、自然言語で問い合わせる Analytics Chat、そしてプログラム連携用の Analytics API を組み合わせ、組織の管理者と財務・IT 部門が Claude の展開状況とコストを一元的に把握・統制できるようにする。

## 管理者ダッシュボード：グループとユーザー単位の可視化

今回の中心は、利用量とコストをグループ別・ユーザー別に表示する管理者ダッシュボードである。単なる支出額だけでなく、その支出の中身を並べて示す設計になっている。

- 作成された artifacts、編集されたファイル数、使用された skills / connectors を、それぞれのコストと並べて表示する。
- SCIM グループでフィルタリングでき、既存の組織構造にそのまま合わせて集計できる。
- ユーザー単位では、プロダクト別・モデル別のコスト内訳と、支出上限（spend limit）に対する消化状況を確認できる。
支出を「いくら使ったか」で終わらせず、「何に使われたか」（生成物・編集・接続先）へ分解する点が、この機能の主眼である。

## Claude Code 専用の Usage / Value タブ

開発者が使う Claude Code については、専用ダッシュボードに新たに 2 つのタブが加わった。

- **Usage** タブ：アクティブな開発者数、セッション数、よく使われるコマンド（top commands）を表示し、日次で更新される。
- **Value** タブ：生産性向上の推定値（productivity lift estimates）、コミットあたりのコスト（cost per commit）、年間価値（annual value）を示す。
Usage が「どれだけ使われているか」を、Value が「その利用がどれだけの価値を生んでいるか」を扱う構成で、投資対効果をコスト側と成果側の両面から捉えられるようにしている。

## Analytics Chat と Analytics API

集計データへのアクセス手段も二方向で用意された。

- **Analytics Chat**：自然言語で分析を問い合わせられる。例として「Which teams doubled their Claude usage this month?（今月 Claude の利用が倍増したチームはどこか）」といったクエリが挙げられており、結果はチャートの artifact として書き出せる。
- **Analytics API**：同じデータへプログラムからアクセスでき、Datadog Cloud Cost Management や CloudZero といったコスト管理ツールと連携できる。
対話的な探索（Analytics Chat）と、既存の運用基盤への機械的な取り込み（Analytics API）の双方を押さえることで、可視化データを個別の確認用にも、全社的なコスト管理の系にも流し込めるようにしている。

## モデル既定値と支出しきい値アラート

可視化だけでなく、事前の制御手段も加わった。

- **モデル既定値と権限（model defaults and entitlements）**：管理者は、chat・Cowork・Claude Code の新規会話で使う既定の Claude モデルを設定できる。
- **支出しきい値アラート**：組織単位の上限に対して 75%・90% の時点で管理者に通知が届く。
- **ユーザー向けのアプリ内通知**：上限の 75%・95% の時点で当該ユーザーに通知が表示され、そこから管理者へ直接、上限引き上げを申請できる。
- **Admin API**：引き上げ申請のレビュー、支出上限の監視、利用パターンのフラグ付けを自動化し、大規模な組織でも運用できるようにする。
これらの対象は、企業全体で Claude の展開を管理する組織管理者と、財務・IT 部門である。可視化（何が起きたか）と制御（既定モデルとしきい値で何を許すか）を同じ管理面にまとめ、事後の把握と事前の統制を一続きの運用として扱えるようにした点が、今回の更新の骨子である。
