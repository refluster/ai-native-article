## Executive Summary

Anthropicのパートナー向け学習サイトSkilljarが公開する「Claude Forward Deployed Engineer」パスは、顧客の最初のユースケースから動くパイロットまでを現地で担う人材向けの、自分のペースで進める約9.5時間の11コース構成である。到達目標はコードではなく「パイロット計画書」で、測定のベースライン、着手前に合意する成功指標、最初に出荷する範囲、最初のユーザー群の立ち上げ方を書けることとされている。

## 何のためのパスか

ページはこのパスの狙いを「顧客を最初のユースケースから動くパイロットまで、現地で連れていく」と一文で示している。受講の前提は「ソフトウェアを作った経験があり、顧客チームと直接仕事をしたことがある」こと。形式は自分のペースで学ぶ約9.5時間で、順番どおりでも1コースずつでもよい。

終了時にできることとして挙げられているのは、顧客のユースケースに対するパイロット計画の作成である。計画に含めるものは次の4点。

- 比較対象にするベースライン
- 作り始める前に合意しておく成功指標
- 最初に出荷するユースケースの部分
- 最初のユーザー群をどう迎え入れるか
## 11コースの構成

コースは3つの束に分かれる。時間はページ記載の値で、合計は本稿で足したものである。

**コア（1〜4）** 1. AI Capabilities and Limitations（約60分）：パイロット初日からユーザーに説明することになる限界。 2. AI Fluency for Builders（約45分）：委任・記述・識別・勤勉の「4D」フレームワークを構築に当てはめる。 3. Claude Platform and Model Foundations（約60分）：プロンプトを書く前の4つの判断、すなわち入口、機能、モデル、コンテキスト。 4. Choosing the right Claude model（約10分）：タスクごとに合うモデルと、レート制限の消費の仕方。

**構築のための役割別コース（5〜9）** 5. Claude Platform 101（約90分）：最初のAPI呼び出しから、エージェントループ、ツール、拡張思考、スキル、MCP、コンテキスト管理、マネージドエージェントまで。 6. Claude Code 101（約60分）：顧客のリポジトリで試作するためのツール。 7. Claude Code in action（約60分）：顧客のリポジトリで長時間・手放しのセッションを走らせ、権限モード、フック、検証で制御する。 8. Introduction to Model Context Protocol（約60分）：顧客のシステムにClaudeをつなぐ。 9. Introduction to agent skills（約30分）：うまくいったやり方をパッケージ化し、顧客チームが再利用できるようにする。

**パイロット提供のための役割別コース（10〜11）** 10. Delivery Methodology（約40分）：ユースケースの適格性判定、パイロット設計、ベースライン取得、導入とリスクの管理。 11. Driving enterprise adoption of Claude（約60分）：顧客が有効化から全社展開へ進む道筋。サクセスチーム、イネーブルメント、ローンチ、次のワークロード探し。

合計は175分、300分、100分で575分、約9時間35分となり、ページの「約9.5時間」と整合する。

## Claude Developerパスとの関係

ページによれば、このパスはClaude Developerパスと9コースを共有する。Developerパスを修了済みなら残るのは2コース、合わせて約100分である。上の表で見ると、共有分が1〜9、残る2コースが10と11で、時間の合計もちょうど100分になる。つまり本パスの独自部分は、技術ではなく「提供の方法論」と「採用の推進」の2コースに集中している。

ページは、コアのコースを一度完了すればそれを含むすべてのパスで数えられると説明している。

## 資格との接続

推奨される次の一歩は「Claude Certified Developer - Foundations」の準備である。この試験は目標とする資格であり、Claude Partner Networkでのパートナー階層にも数えられるとされる。準備コースは約13時間で、プロンプト、エージェントとツール利用、評価、セキュリティをより深く扱う。

その先の選択肢は3つ示されている。

- 本番投入に向かう案件なら Claude Certified Developer - Professional（エージェント設計、信頼性、可観測性、評価、コストとレイテンシ、セキュリティ）
- ソリューション設計を率いるなら Claude Certified Architect - Professional の準備（そのうち2つの準備コースが本パスに合う）
- 顧客にClaude Codeを展開するなら Claude Code partner badge（8コースのうち1コースが本パスに含まれる。バッジは無料で、約12時間のコースに加えて最終課題と評価がある）
登録はClaude Partner Networkのメンバーに限られる。

## 証拠と結論

**証拠（ページに書かれていること）**：到達目標はパイロット計画書であること。11コースの大半は構築側（1〜9）だが、独自の2コースは提供方法論と採用推進であること。成果物の定義に、着手前に合意する成功指標とベースラインが含まれること。

**結論（ここから引き出せる含意）**：このパスが前提にする職務は、コードを書く人であると同時に、測定条件を顧客と先に合意する人である。技術習得に9コース、顧客側の進め方に2コースという配分は、学習時間では技術が大半を占めても、成果物の定義では測定と導入が先に来ていることを示す。ただしページは受講後の成果や合格率を示していないため、このパスが実際のパイロット成功率を上げるかどうかは、この資料からは判断できない。
