# 本調査のリサーチプロセス設計 (stage-gate) — プロフェッショナル実務からの借用

出典: `process/professional-practices.md` (P-1〜P-35、検証印 [V]/[S]/[2nd]/NOT FOUND 付き)。本書はそれを **research-study v0.1.1 の12段階 (S0–S11)** に写像し、各ゲートに「誰が・何を・どの基準で」を固定したものである。Stage-Gate (Cooper) の規律に従い、**ゲートの成果物・基準・審査者はこの S0 時点で全段階分を書き切り、途中で再交渉しない**。ゲートの判定語は Go / Kill / Hold / Recycle の4値。

## 固定語彙 (S0 で凍結、以後変更しない)

- 判定: 支持 / 一部支持 / 不支持 / 未検証
- 確度: 高 (独立した一次資料 ≥2 が一致) / 中 (一次 1 件、または信頼できる二次複数) / 低 (二次のみ・推計・資料間で不一致)
- 証拠階層: 一次 > 準一次 > 二次 > 内部。三次 (ブログ・生成要約) は引用不可
- 所見の確度 A/B/C (ページで一次を確認 / 一次が示されるが二次経由 / 二次のみ)
- 蓋然性語 (将来予測に使う): ほぼ確実 (≥95%) / 高い (80–95%) / どちらかといえば (55–80%) / 五分 (45–55%) / 低い (20–45%) / 非常に低い (5–20%) / ほぼない (<5%) — ICD 203 の7段階を写したもの。確度語と同一文に置かない。
- 証拠に「ベンダ調査」フラグ: セキュリティ/SaaS ベンダの自社調査は単独で鍵判断を支えない。
