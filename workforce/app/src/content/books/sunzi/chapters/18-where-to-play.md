# 後編 IV 虚実と軍争 — 価値のある場所を選び、迂路を取る

## 強い所に、力を注がない

態勢が整い、力も溜まりました。次に決めるのは、その力をどこへ向けるかです。ここで多くの計画がつまずきます。準備が十分だと感じるほど、いちばん目立つ場所で、いちばん強い相手と、正面から勝負したくなるからです。

一つの場面を考えてみます。小さなチームが新しい事業を始めようとしています。誰もが知る大きな市場には、資金の豊富な大手が何社も並んでいます。同じような製品で正面から入るのか。それとも、大手が目を向けていない片隅を探すのか。どちらを選ぶかで、同じ努力が実を結ぶかどうかが大きく変わります。地形を読む仕事にたとえれば、まず等高線を引き、どこが高く、どこが低いかを確かめる段階です。

孫子の虚実篇と軍争篇は、この選択に二つの視点を与えてくれます。虚実篇は「どこで戦うか」を、軍争篇は「どの道を、どの速さで行くか」を扱います。「実」とは兵力や備えが充実している所、「虚」とは手薄な所のことです。「軍争」とは、有利な地点や時機を敵より先に押さえようとする争いを指します。

本章では、この二篇から四つの一節を読み直します。そのうえで、場所の選び方、主導権の握り方、回り道の価値、そしてチームの気の扱い方へと、順に現代の読みを広げていきます。どの読みにも、原文が言っていないことを書き添えます。古典を現代に置くときの、本書の決まりごとです。

## 水は低い所へ流れる — 実を避けて虚を撃つ

```quote
原文: 夫兵形象水、水之形、避高而趨下。兵之形、避實而擊虚。
訓読: 夫れ兵の形は水に象る。水の形は高きを避けて下きに趨き、兵の形は実を避けて虚を撃つ。
出典: 虚実篇
訳: 軍の形は水に似ている。水が高い所を避けて低い所へ流れるように、軍は敵の充実した所を避け、手薄な所を撃つ。
```

象（かたど）るは「似せる、なぞらえる」という意味です。この一節は虚実篇の終わり近くに置かれ、篇全体の結論の役目を果たしています。前段で孫子は、敵の守っていない所を攻めれば必ず取れ、敵の攻めてこない所を守れば必ず固い、と述べていました。そして、前を守れば後ろが手薄になり、左を守れば右が手薄になると続けます。あらゆる所に備えようとすれば、あらゆる所が手薄になる、というのです。

ここが要点です。虚は偶然に見つかる穴ではありません。相手の資源が有限である限り、どこかに必ず生まれるものです。水の比喩は、その虚へ向かう動きが、意志の力ではなく地形に従う自然な流れであるべきだと示しています。原文はさらに、水が地形によって流れを決めるように、兵は敵によって勝ち方を決める、と続きます。

虚を撃つことは、自分の力を一か所に集めることと表裏です。虚実篇は、自分の形を隠して敵の形をさらけ出させれば、自分は一つにまとまり、敵は十に分かれると述べます。そうなれば、局所では十で一を攻める形になります。全体の兵力が少なくても、戦う一点では多数になれるのです。虚を選ぶとは、弱い所を探すことであると同時に、自分が多数になれる所を選ぶことでもあります。

原文は、敵の充実した所を避け、手薄な所を撃てと言います。現代では、競合が厚く備えている市場を避け、まだ満たされていない需要へ力を向けよ、と読めます。ただし原文は「誰もいない場所へ行け」とは言っていません。虚とは敵の備えとの関係で決まるもので、相手が動けば虚の位置も動きます。また、原文の虚は「敵の弱点」であって「顧客の困りごと」ではありません。買い手を敵と見なす読み方は、原文のどこにも根拠がありません。

![図18 実と虚の地図 — 競合の備えが厚い「実」を避け、備えの薄い「虚」へ力を流す](figures/18-void-map.svg)

図18は、市場を一枚の地形として描いたものです。濃い部分は競合の備えが厚い「実」、淡い部分は手薄な「虚」を表します。矢印は、水が低い所へ流れるように、自分の力が虚へ向かう道筋です。大切なのは、この地図が固定されていないことです。相手が守りを移せば、濃淡も入れ替わります。

```note
よく使われる「避実撃虚」という四字の言い回しは、この一節を縮めた形で、原文そのものではありません。原文は「実を避けて虚を撃つ」と「而」でつなぎ、その前に水の比喩を置いています。また伝本によっては「兵の形」を「兵の勝」と作り、兵の勝ち方は実を避けて虚を撃つ、と読めます。形の話か勝ち方の話かで力点は少し違いますが、指す行動は同じです。
```

```connect
title: ニッチの経済学 — 強者が「備えない」場所
市場の中で、特定の需要を持つ小さな区画を「ニッチ」と呼びます。経営学では、大企業がこうした区画を取りこぼす理由がよく論じられてきました。規模が小さすぎて大きな組織の固定費に見合わないこと、既存の大口顧客を優先せざるをえないこと、などです。経営学者クレイトン・クリステンセンが論じた「イノベーションのジレンマ」も、合理的な強者ほど小さな市場を守らない、という構造を描いています。

この構造は、虚実篇の「すべてに備えれば、すべてが手薄になる」と同じ形をしています。なぜ同じ形なのか。どちらも、有限の資源を持つ強者が全域を厚く守ることはできず、守らない場所を自分で選ぶしかないからです。虚は、強者の怠慢ではなく、強者の合理的な判断から生まれます。だからこそ、小さな側にとって虚は探す価値があります。

違いも一つあります。戦場の虚は、一撃で目的を果たせば去ることができます。市場の虚は、入った後も買い手に価値を出し続けなければ、そこに留まれません。
```

## 人を致して人に致されず — 自分のリズムで進む

```quote
原文: 故善戰者、致人而不致於人。
訓読: 故に善く戦う者は、人を致して人に致されず。
出典: 虚実篇
訳: だから戦上手は、敵を思いどおりに動かし、自分が敵に動かされることはない。
```

致（いた）すは「招き寄せる、こちらの望む所へ来させる」という意味です。この一節は虚実篇の冒頭にあります。直前で孫子は、先に戦場に着いて敵を待つ者は楽で、後から戦場に駆けつける者は疲れる、と述べていました。その対比を受けて、戦上手は相手を動かす側に立つ、と結論するのです。

続く部分では、その方法も示されます。敵を自分から来させるのは利益を見せるからで、敵を来られなくするのは害を見せるからだ、といいます。主導権、つまり戦いの場所と時を決める力は、相手の利害を読むことから生まれます。力で押しつけるのではありません。

先に着く者が楽だという指摘は、地味ですが重いものです。先に着いた側は、地形を調べ、休み、待つ場所を選べます。後から着いた側は、息を整える前に戦いを強いられます。差を生んでいるのは兵の強さではなく、到着の順番と、それを決めた判断です。

原文は、先に場を押さえ、相手を動かす側に立てと言います。現代では、自分で決めた周期で作り、確かめ、届けるという読み方ができます。競合の発表や流行に反応して計画を書き換え続ければ、いつも後から駆けつける側になり、疲れるのは自分です。ただし原文は「相手を見るな」とは言っていません。虚実篇は、相手の形をさらけ出させることを前提にしています。相手をよく見ることと、相手に動かされることは別のことです。また原文の「致す」は相手を操る行為で、自分の歩調を守るという読みは、そこから一歩引いた応用です。

## 迂を以て直と為す — 遠回りの価値と、急ぎの代償

```quote
原文: 軍爭之難者、以迂為直、以患為利。
訓読: 軍争の難きは、迂を以て直と為し、患を以て利と為す。
出典: 軍争篇
訳: 軍争の難しさは、回り道を近道に変え、不利な条件を有利に転じるところにある。
```

迂（う）は回り道、直は真っすぐな近道、患（かん）は不利な条件のことです。軍争篇はこの一節の直後で、方法を具体的に示します。わざと遠回りの道を取り、利で敵を誘って足止めすれば、後から出発しても先に着ける。これを迂直（うちょく）の計を知る者、と呼びます。

「患を以て利と為す」も見落とせません。不利な条件そのものを、有利に転じる材料にせよという意味です。小さな側にとって、規模の小ささは不利です。しかし小さいからこそ大手が見向きもしない道を通れ、警戒もされにくい。不利がそのまま迂路の通行証になることがあります。

そして篇は、急ぎの代償を数字で示します。全軍で利を争えば間に合わず、輜重（しちょう）、つまり食糧や装備を運ぶ部隊を置いていけば補給を失います。鎧を巻いて昼夜休まず百里を急げば、着くのは十人に一人で、将軍たちまで捕らえられる。五十里なら半分、三十里なら三分の二しか着かない、と原文は述べます。輜重や糧食がなければ軍は滅ぶ、とも重ねます。

この数字の並びには、はっきりした傾きがあります。急ぐ距離が長いほど、着く割合が下がっていくのです。しかも先に着くのは強い者だけで、疲れた者は後ろに取り残されます。急ぎの代償は、全体が少し遅れることではありません。軍が強い者と弱い者に引き裂かれ、まとまりそのものを失うことなのです。

原文は、回り道を近道に変えることが軍争の核心であり、強行軍は兵と補給を失わせると言います。現代では、目の前の機能を急いで出すより、基盤を先に作るほうが早く着くことがある、と読めます。検証の仕組み、整ったデータ、相手からの信頼がそれにあたります。置き去りにした輜重は、後で必ず請求書を送ってきます。ただし原文は「遠回りはいつでも良い」とは言っていません。迂は、利で相手を誘う「計」と組になって、はじめて直になります。ただ遅いだけの回り道は、作戦篇が戒めた長引く戦いに近づきます。

```note
「軍争為危」という句で知られる箇所は、本によって字が異なります。十一家注などでは、軍争は利にもなり、同じ軍争が危うさにもなる、と読める形です。本書の底本（四庫全書本）では後半が「衆争は危たり」で、統制の取れた軍争は利になり、群衆のように争えば危うい、という対比になります。どちらで読んでも、急ぎの代償を説く後段の内容は変わりません。
```

## 気を治める — チームの気は奪われうる

```quote
原文: 善用兵者、避其銳氣、擊其惰歸、此治氣者也
訓読: 善く兵を用うる者は、其の鋭気を避けて、其の惰帰を撃つ。此れ気を治むる者なり。
出典: 軍争篇
訳: 用兵の上手な者は、敵の士気が盛んなときは避け、士気が緩んで帰りたがっているところを撃つ。これが士気を制する方法である。
```

この一節の直前に、孫子は短い前提を置いています。全軍からはその気を奪うことができ、将軍からはその心を奪うことができる、というものです。気とは、集団が持つ士気やはりの総量のことです。続けて、朝の気は鋭く、昼の気は緩み、暮れの気は帰ることを思う、と一日の波を描きます。惰帰（だき）は、緩んで帰りたがる状態を指します。

原文はこのあと、気と並べて三つの「治め方」を挙げます。

- 治心：整った態勢で乱れた敵を待ち、静けさで騒がしい敵を待つ
- 治力：近くで遠来の敵を待ち、休んだ兵で疲れた敵を待ち、満ちた腹で飢えた敵を待つ
- 治変：旗の整った敵を迎え撃たず、堂々とした陣を攻めない

原文は、敵の士気には波があり、盛んな時を避け、緩んだ時を撃てと言います。現代では、自分のチームの気も同じく波を持ち、奪われうる資源だと読めます。立ち上げ直後の鋭い気は、最も難しい課題に充てる。疲れの出る時期には、重い判断を置かない。長い回り道を選んだなら、気を保つ仕掛けはなおさら必要です。迂路は、着くまでの時間が長い道です。その間に気が尽きれば、正しい道を選んだ意味が失われます。ただし原文は、自軍の士気を高める方法を説いてはいません。主語は「善く兵を用うる者」で、対象は敵の気です。チームの気の管理として読むのは、それを裏返した応用です。朝・昼・暮れの区分も、一日の時刻をそのまま当てはめる話ではありません。気には満ちる時と引く時がある、という観察として受け取るのが穏当です。

## この章の一行

二篇を一文に縮めるなら、こうなります。価値のある場所とは、相手の備えが薄く、自分の力が一つに集まる場所です。そこへは急がず、気を保ったまま、自分の歩調で回り道をして着くものです。

虚実篇は場所を、軍争篇は道と速さを語りました。両者に共通するのは、自分の力を量るだけでなく、相手の資源の限りと、自分の資源の限りを同時に見る態度です。全域を守れない相手は虚を残し、急ぎすぎる自分は輜重を落とします。地図は一枚でも、そこには二つの限界が描かれています。

そして、どちらの篇も、勝ち方を一つの型に固定しません。虚実篇は、勝ち方を繰り返さず、相手の形に応じて限りなく変えよと説きました。虚の位置が動く以上、場所の選び方も、道の取り方も、そのつど地図を引き直して決めることになります。

ここまで、一般のプロジェクトとチームを念頭に、孫子を現代に置いてきました。その読み方は、作り手の側にも同じように当てはまるはずです。最後に、私たち自身——AI エージェントの会社——に孫子を置いてみます。
