# 軍争篇 — 迂直の計

## 早く着くことと、良い状態で着くこと

軍を動かせば、距離があり、時間がかかり、疲れが生まれます。軍争篇は、この「動く」局面を正面から扱う篇です。

篇名の「軍争（ぐんそう）」とは、有利な地点や時機を敵より先に押さえようと、軍どうしが競い合うことを指します。戦場には、先に着いた側が大きく有利になる場所があります。そこへ向かう競争です。孫子は篇の冒頭で、用兵のなかでこれほど難しいものはないと述べています。

身近な場面で考えてみます。山頂を目指すとき、地図の上でいちばん短いのは、斜面をまっすぐ登る線です。けれども多くの登山道は、斜面を左右に折り返す「つづら折り」になっています。距離は何倍にも延びますが、一歩ごとの負担が小さいので、脚を残したまま頂上に着けます。直登した人が先に着いても、頂上で座り込んで動けなければ、着いた意味は半分になります。

この篇が答える問いは、ここにあります。早く着くことと、良い状態で着くことは同じなのか。孫子の答えは、同じではない、しかし両方を得る道はある、というものです。その道の名が「迂直（うちょく）の計」です。迂は回り道、直はまっすぐな近道を意味します。この章では、回り道がなぜ近道になりうるのか、そして急ぐことが何を失わせるのかを、原文に沿って読んでいきます。

## 原文を読む

```quote
原文: 軍爭之難者、以迂為直、以患為利。
訓読: 軍争の難きは、迂を以て直と為し、患を以て利と為す。
出典: 軍争篇
訳: 軍争の難しさは、回り道を近道に変え、不利な条件を有利に転じるところにある。
```

「以◯為△」という形は「◯を以て△と為す」と読み、「◯を△に変える」という意味になります。迂を直に変え、患（かん、わずらい・不利な条件）を利に変える。ここで孫子は、回り道を避けよとは言っていません。回り道を近道に「変えよ」と言っています。

地図の上の距離そのものは変わりません。変わるのは、その距離が持つ意味です。敵が「あの道は遠いから相手は来ないだろう」と考える道は、敵の備えが薄い道でもあります。地理の上での遠さが、相手の予測の外側という意味での近さに変わるわけです。

患と利の対も同じ構造をしています。悪路や遠回りという不利な条件は、敵がそこを軽く見る理由になります。その油断が、こちらの利になります。難しいのは、この変換が自動では起きないことです。ただ遠回りをすれば、ただ遅れるだけです。何をすれば迂が直に変わるのか。その手順を示すのが、すぐ後に続く一節です。

```quote
原文: 故迂其途、而誘之以利、後人發、先人至、此知迂直之計者也。
訓読: 故に其の途を迂にして、之を誘うに利を以てし、人に後れて発し、人に先んじて至る。此れ迂直の計を知る者なり。
出典: 軍争篇
訳: わざと遠回りの道をとり、利で誘って敵を足止めすれば、敵より後に出発しても先に着ける。これが迂直の計を知る者である。
```

手順は二つあります。自分の道をあえて迂回させること。そして、敵を利で誘うことです。「之を誘う」の「之」は敵を指します。敵の前に目先の利を置けば、敵はそこで足を止めたり、寄り道をしたりします。敵の到着が遅れれば、こちらが遠回りをしても先に着けます。

ここで大切なのは、競争の勝ち負けを決めるのが自分の到着時刻ではなく、敵との到着時刻の差だという点です。差を広げるには、自分が速くなる方法と、敵を遅くする方法の二つがあります。前者には限りがあり、無理をすれば軍が傷みます。後者は、自分の体力を削らずに差を作れます。

「人に後れて発し、人に先んじて至る」という句は、この篇の問いへの答えを凝縮しています。出発の早さと到着の早さは、別のものです。そして、遠回りをする軍は無理な速度を出さないので、着いたときにも隊列が崩れていません。迂直の計は、早く着くことと良い状態で着くことを、同時に満たすための工夫だと読めます。

迂直の計の裏側として、孫子は急ぐことの危うさを数字で示します。まず、軍争は利をもたらすが、大軍がひしめいて争えば危うい（衆争は危と為る）、と前置きします。全軍をそろえて利を争えば間に合いません。軍を置き去りにして身軽な部隊だけで争えば、輜重（しちょう、食糧や武具を運ぶ部隊とその荷）を失います。そして、鎧を巻いて走り、昼夜休まず、通常の倍の行程で百里先の利を争えば、三軍の将がみな捕らえられる、と続けます。強い者が先に着き、疲れた者が遅れ、着くのは十人に一人だというのです。五十里なら先鋒の将が倒れて半数が着き、三十里なら三分の二が着く、と計算は続きます。結論は、輜重・糧食・蓄えのどれが欠けても軍は亡ぶ、というものです。

この計算の要点は、急ぐ距離が延びるほど到着できる割合が下がることです。急げば先頭は早く着きますが、着いた先頭は全軍の一部にすぎません。早く着くことと戦える状態で着くことが別物だという答えが、ここでは数字になっています。

```quote
原文: 故兵以詐立、以利動、以分合為變者也。
訓読: 故に兵は詐を以て立ち、利を以て動き、分合を以て変を為す者なり。
出典: 軍争篇
訳: 戦争は敵を欺くことで成り立ち、利益によって動き、兵力の分散と集中によって変化するものである。
```

ここで孫子は、迂直の計を支える原理を三つの言葉にまとめます。詐（さ）は欺くこと、利は動機、分合（ぶんごう）は兵力を分けたり合わせたりすることです。

詐は、計篇の「兵は詭道なり」と同じ系統の考え方です。敵に本当の進路を知られていれば、遠回りはただの遠回りです。こちらの動きが見えないからこそ、迂は直に変わります。

利で動くというのは、自軍にも敵軍にも当てはまります。軍は利のある方へ動く。だからこそ、敵の前に利を置けば敵を動かせます。前の一節の「之を誘うに利を以てす」は、この原理の応用だと言えます。

分合は、迂直の計を実行するための道具として読めます。全軍が一つの塊として動けば、遠回りか近道かのどちらかしか選べません。軍を分ければ、一部で敵の目を引き、別の一部で回り込むといった組み合わせが可能になります。ただし分けた軍は、必要なときに再び合わさらなければ力になりません。分けることと合わせることが一組で語られているのは、そのためだと考えられます。

```quote
原文: 故其疾如風、其徐如林、侵掠如火、不動如山、難知如陰、動如雷震。
訓読: 故に其の疾きこと風の如く、其の徐かなること林の如く、侵掠すること火の如く、動かざること山の如く、知り難きこと陰の如く、動くこと雷震の如し。
出典: 軍争篇
訳: 軍は、進むときは風のように速く、待つときは林のように静かに、攻めるときは火のように激しく、守るときは山のように動かず、隠れるときは暗闇のように捉えがたく、いざ動けば雷のように一気に襲いかかる。
```

日本では「風林火山」として知られる一節ですが、原文は六句です。並べてみると、三組の対になっていることがわかります。疾（はや）きと徐（しず）か、つまり速さと静けさ。侵掠（しんりゃく、攻め込んで奪うこと）と不動、つまり攻めと守り。知り難きと雷震、つまり隠れることと一気に現れることです。

この一節の要点は、どれか一つの性質を持てということではありません。相反する性質のあいだを切り替えられること、そのものが強さだという点です。いつも速いだけの軍は、速さを読まれます。いつも静かなだけの軍は、攻めてこないと見切られます。

迂直の計に重ねると、この六句の意味がよく見えてきます。回り道をしている間の軍は、林のように静かで、陰のように所在がつかめません。敵が利に誘われて足を止めている間に、風のように距離を詰めます。そして目的の地点に着いた瞬間、雷のように現れます。遠回りの静けさと到着の激しさは、一つの動きの前半と後半だと読めます。

孫子はこのあと、合図の太鼓や旗で兵の耳目を一つにまとめる話を挟み、続いて軍の「気」へと話を移します。三軍からはその気を奪うことができ、将軍からはその心を奪うことができる。そして、朝の気は鋭く、昼の気は惰（だ、たるみ）、暮れの気は帰る、と述べます。気とは、兵の士気、戦おうとする勢いの総量のことです。それは一日のなかで満ち引きします。朝は勢いがあり、昼にはゆるみ、夕方には早く帰りたいという気持ちが勝つのです。

```quote
原文: 善用兵者、避其銳氣、擊其惰歸、此治氣者也
訓読: 善く兵を用うる者は、其の鋭気を避けて、其の惰帰を撃つ。此れ気を治むる者なり。
出典: 軍争篇
訳: 用兵の上手な者は、敵の士気が盛んなときは避け、士気が緩んで帰りたがっているところを撃つ。これが士気を制する方法である。
```

惰帰（だき）は、たるんで帰りたがっている状態です。敵の鋭気とまともにぶつからず、気が引いた谷で撃つ。ここにも、この篇の問いが別の角度から現れています。同じ敵でも、どの状態のときに出会うかで、強さはまるで違うのです。

孫子はこれを「気を治める」と呼び、同じ形の言葉を重ねます。整った状態で乱れた敵を待ち、静かな状態で騒がしい敵を待つ。これが心を治めることです。近くにいて遠くから来る敵を待ち、休んだ状態で疲れた敵を待ち、満腹の状態で飢えた敵を待つ。これが力を治めることです。

最後の「力を治める」は、迂直の計の裏返しになっています。迂直の計は、こちらが良い状態で着く工夫でした。こちらは、良い状態で待ち、悪い状態で着いた敵を迎える工夫です。どちらも、勝敗を決めるのは出会った瞬間の両軍の状態だ、という同じ見方から出ています。到着の早さは、その状態を作るための手段の一つにすぎません。

```quote
原文: 歸師勿遏、圍師必闕、窮寇勿追
訓読: 帰師は遏むる勿かれ、囲師は必ず闕き、窮寇は追う勿かれ。
出典: 軍争篇
訳: 本国へ引き上げる軍を遮ってはならない。包囲するときは必ず逃げ道を一つ空けておく。追い詰められた敵を追撃してはならない。
```

篇の最後に、孫子は用兵の禁則を八つ並べます。高い丘にいる敵に向かうな、偽って逃げる敵を追うな、といった具合です。引いたのは、そのうち最後の三つです。遏（とど）むるは遮ること、闕（か）くは欠けさせること、窮寇（きゅうこう）は追い詰められた敵を指します。

三つに共通するのは、敵の「状態」への配慮です。家に帰ろうとする軍は、帰ることに必死です。その道を塞げば、帰るために死に物狂いで戦います。四方を完全に囲まれた軍も、逃げ道がなければ最後の一兵まで戦います。逃げ道を一つ残しておけば、敵の多くはそこから逃げることを選び、戦う力は散ります。

ここまで読むと、この篇が一貫して見ているものが浮かび上がります。距離でも速度でもなく、出会ったときの相手の気と力です。敵を死地に追い込めば、その気をかえって最高潮に引き上げてしまいます。なお、底本は「窮寇は追う勿かれ」ですが、十一家注本などの他本は「窮寇には迫る勿かれ」と作ります。

## 構造を図で見る

![図9 迂直の計 — まっすぐな道は先頭だけが早く着き、回り道は敵を利で足止めして全軍そろって先に着く](figures/07-detour.svg)

図9は、出発点から争う地点へ向かう二本の道を並べたものです。上の線はまっすぐな近道です。距離は短いのですが、強行軍で急ぐと、輜重が置き去りになり、疲れた兵が脱落していきます。着いたときには、先頭のわずかな部隊しか残っていません。

下の線は回り道です。距離は長くなりますが、途中で敵の前に利を置き、敵の足を止めています。こちらは無理な速度を出さないので、輜重も兵も欠けずに着きます。敵との到着時刻の差で見れば、回り道の側が先に着いています。

図の右端では、到着したときの軍の状態を比べています。この篇の問いは、図の横軸である到着時刻だけでなく、縦に並べた到着時の状態を合わせて見なければ答えられません。孫子が「迂を以て直と為す」と言うとき、比べているのは道の長さではなく、この二つを合わせた結果だと読めます。

## 異分野への接続

```connect
title: ネットワークの経路制御——最短経路が最速とは限らない
インターネットでデータを送るとき、データは小さな塊に分けられ、中継機器を何台も経由して届きます。中継の一段を「ホップ」と呼びます。経路を選ぶ仕組みには、ホップの数が少ない道を選ぶ単純なものがあります。回線の速さなどを「費用」として数え、費用の合計が小さい道を選ぶものもあります。

ホップ数が最少の道が、最も速いとは限りません。その道の途中に混雑した回線があれば、データはそこで順番待ちになり、あふれた分は捨てられて送り直しになります。ホップが多くても空いた道を回るほうが、全体として早く、欠けずに届くことがよくあります。そのため多くの経路制御は、ホップ数ではなく、回線の速さなどから定めた費用の合計で道を選びます。混雑や損失を実測して道を切り替える仕組みは、一部に限られます。

同じ形なのは、どちらも到着の早さと質を決めるのが道の長さではなく、途中で失うものの総和だからです。孫子の百里の計算で兵が脱落していく様子は、混雑した回線でデータが捨てられていく様子とよく似た構造をしています。

違いもあります。ネットワークの経路選びには、こちらを妨げようとする相手がいるとは限りません。孫子の迂直の計は、相手を利で誘って遅らせるという、相手の判断に働きかける部分を含んでいます。
```

```connect
title: 長距離走——ペース配分と「気」
マラソンや一万メートル走では、序盤に飛び出して貯金を作ろうとすると、終盤に大きく失速しやすいと、多くの指導者が指摘しています。体が使えるエネルギーには限りがあり、速いペースほど消耗が急になります。前半で予定より速く走って稼いだ数十秒は、後半に脚が止まって失う数分に比べると小さいのです。そのため、一定のペースを守るか、後半をやや速くする配分が勧められることが多くあります。

同じ形なのは、どちらも限られた蓄えを、到着までのどこで使うかという問題だからです。孫子の強行軍は、序盤に全力で飛び出したランナーと同じく、蓄えを前半で使い切って最後に崩れます。

さらに、朝の気は鋭く、昼にたるみ、暮れに帰るという孫子の観察は、レースの展開にも重なります。集団が勢いよく飛び出した直後に競り合うのは損で、相手のペースが落ちる後半に勝負を仕掛けるほうが効率的です。鋭気を避けて惰帰を撃つ、という形です。

違いは、長距離走が基本的に自分の体との勝負であることです。走者は相手の気を奪うことはあっても、相手を利で誘って遠回りさせることはできません。
```

## 誤解されやすい点

```note
「風林火山」は、戦国時代の武将・武田信玄の旗に記されたと伝えられる四句「疾如風、徐如林、侵掠如火、不動如山」の通称です。孫子の原文はさらに「難知如陰、動如雷震」と続き、全部で六句あります。信玄の旗は、六句のうち前半の四句を抜き出したものです。また、最後の句を「雷霆」とする版もありますが、本書の底本を含む主な版は「雷震」です。
```

## この篇の一行

軍争篇を一文に縮めるなら、「勝負を決めるのは着いた早さではなく、出会ったときの両軍の状態である」となるでしょう。遠回りは、敵を利で誘って遅らせれば近道に変わります。急げば先頭は早く着きますが、軍の大半と補給は道に落ちていきます。だから孫子は、自軍の状態を保ったまま着く道を選び、敵の気が引いたときに撃ち、追い詰められた敵には逃げ道を残します。では、その原則を破ってよいのは、どんなときでしょうか。
