# 用間篇 — 知ることに金を払う

## 十万の軍と、百金の出し惜しみ

『孫子』は計篇で、戦う前に彼我を数えることから始まりました。けれども、数えるには材料が要ります。敵の将の力量も、兵の士気も、蔵の兵糧も、こちらからは見えません。最後の用間篇は、その見えないものをどう手に入れるかを論じる篇です。「間（かん）」とは、敵の内情を探る者、つまり間諜のことです。

篇の書き出しは、戦争の費用の勘定です。十万の兵を千里の遠くへ出せば、一日に千金が消えます。国の内外が騒ぎ、道に疲れて家業に就けない家が七十万戸に及ぶ、と孫子は数え上げます。ここまでは作戦篇の続きのように読めます。

ところが、その直後に話の向きが変わります。これほどの費用を払いながら、間諜に与える爵位や俸禄や金を惜しむ者がいる。孫子はそれを、将の資格も君主の補佐の資格もないとまで言います。

身近な場面に置き換えると、形がよく見えます。何千万円もかけて新しい店を出すのに、その町を歩いて人の流れを数える数日分の手間を省く。誰もが愚かだと思うはずです。けれども実際には、大きな支出ほど「もう決めたこと」として進み、小さな調べものの費用が削られがちです。

この篇の問いは一つです。十万の軍を動かしながら、情報に金を惜しむのはなぜ愚かなのか。そして、その情報はどこから、どう取るのか。

## 原文を読む

```quote
原文: 相守數年、以爭一日之勝、而愛爵祿百金、不知敵之情者、不仁之至也
訓読: 相守ること数年、以て一日の勝を争う。而るに爵禄（しゃくろく）百金を愛（お）しみて、敵の情を知らざる者は、不仁の至りなり。
出典: 用間篇
訳: 何年も対峙したうえで、たった一日の決戦の勝ちを争う。それなのに、間諜に与える爵位・俸禄・百金を惜しんで敵情を知ろうとしないのは、民を思う心を欠いた最たるものである。
```

この一節は、時間の非対称を突いています。両軍がにらみ合う「相守」は数年に及びます。しかし勝敗が決まるのは、そのうちのたった一日です。数年分の費用と犠牲は、その一日の判断に懸かっています。

「爵祿百金」は、間諜への報酬です。爵は位、禄は俸給、百金はまとまった金を指します。日に千金を費やす戦争から見れば、百金は一日分にも届きません。比べるまでもない額を惜しんで、一日の判断を目隠しのまま下す。孫子はこれを、計算の誤りとしてではなく「不仁」として責めます。

ここで「仁」が出てくるのは意外かもしれません。仁とは、人を思いやる心のことです。戦争の費用を実際に払うのは、税を納め、家業を離れて従軍する民です。情報を惜しんで負ければ、その犠牲はすべて無駄になります。だから情報への出費を惜しむことは、倹約ではなく、民への裏切りだという理屈です。損得の話を、責任の話に置き直しているところに、この篇の重さがあります。

```quote
原文: 先知者、不可取於鬼神、不可象於事、不可驗於度、必取於人、而知敵之情者也。
訓読: 先知なる者は、鬼神（きしん）に取るべからず、事に象（かたど）るべからず、度に験（ため）すべからず。必ず人に取りて、敵の情を知る者なり。
出典: 用間篇
訳: 前もって知ることは、神霊や占いからは得られず、過去の事例からの類推でも得られず、天体の運行などの計測からも得られない。必ず人から得て、敵の実情を知るのである。
```

直前で孫子は、すぐれた君主や将が人並み外れた成果を挙げるのは「先知」、つまり先に知っているからだと述べます。この一節は、その先知の取り方を限定します。

退けられる道は三つです。一つ目は鬼神、すなわち神霊に祈り、占いで吉凶を問うことです。二つ目は「事に象る」、似た過去の出来事から今を類推することです。三つ目は「度に験す」で、天体の度数のような計測で確かめることだと解されています。ただし「度」を天文と読むのは、注釈上の一説です。

残る道は「人」だけです。敵の陣営を実際に見聞きした人間から、敵の今の状態を聞き出す。ここで大切なのは、退けられた三つがどれも手元で完結する方法だという点です。祈りも類推も計測も、敵に近づかずにできます。孫子は、敵の情は敵の側にしかないと見ています。だから、そこに人を送るしかありません。

```quote
原文: 故用間有五、有鄉間、有內間、有反間、有死間、有生間。
訓読: 故に間（かん）を用うるに五有り。郷間（きょうかん）有り、内間有り、反間（はんかん）有り、死間有り、生間有り。
出典: 用間篇
訳: 間諜の使い方には五種類ある。郷間、内間、反間、死間、生間である。
```

孫子は続けて、五つの間をそれぞれ一行で定義します。郷間は、敵国の土地の住民を使うものです。内間は、敵の役人を使うものです。反間は、敵がこちらに送り込んだ間諜を使うものです。死間は、偽りの情報を味方の間諜に知らせ、それを敵に伝えさせるものです。偽りが露見すれば命はないので「死」の字が付きます。生間は、敵地から生きて戻り、報告するものです。

五つを並べると、分類の軸が見えてきます。郷間と内間は、誰を情報源にするかの違いです。死間と生間は、情報を運ぶ向きの違いです。死間は偽りを敵へ運び、生間は真実を味方へ運びます。そして反間だけが、敵の仕組みそのものを裏返して使います。

孫子は五つがそろって動き、しかも敵がその筋道を知らない状態を「神紀（しんき）」と呼び、君主の宝だと言います。一本の糸ではなく、互いに支え合う網として情報を扱っているのです。

```quote
原文: 非聖智不能用間、非仁義不能使間、非微妙不能得間之實。
訓読: 聖智（せいち）に非ざれば間を用うること能（あた）わず、仁義に非ざれば間を使うこと能わず、微妙に非ざれば間の実を得ること能わず。
出典: 用間篇
訳: すぐれた知恵がなければ間諜を活用できず、思いやりと正しさがなければ間諜を働かせられず、細やかな洞察がなければ間諜のもたらす情報の真偽を見抜けない。
```

この一節の直前で、孫子は間諜の扱いを三つの最上級で語ります。全軍の中で、間諜ほど親しくすべき者はいない。間諜ほど厚く賞すべき者はおらず、間諜ほど秘密にすべきこともない。原文では「莫親於間、賞莫厚於間、事莫密於間」の三句です。親しさ、厚さ、秘密の三つがそろって初めて、間諜は命を懸けて働きます。

そのうえで、使う側に三つの資質を求めます。聖智は、誰をどこに置くかを見通す知恵です。仁義は、間諜が裏切らずに働きたくなるだけの誠実さです。そして微妙は、届いた報告の真偽を細かく見分ける目です。

三つ目が特に鋭い指摘です。間諜は人間なので、嘘もつけば、買収もされ、思い込みもします。だから情報を集める力と、情報を疑う力は別の能力です。孫子は、その二つを一人の指導者の中にそろえよと求めています。

```quote
原文: 微哉。微哉。無所不用間也。
訓読: 微（び）なるかな、微なるかな、間を用いざる所無きなり。
出典: 用間篇
訳: 実に微妙なものだ、実に微妙なものだ。間諜を使わない場面など、どこにもない。
```

短い一節ですが、『孫子』の中では珍しく感情の動きが見える箇所です。同じ言葉を二度重ねるのは、論を進めるためではなく、嘆息に近い調子です。「微」は、目に見えないほど細かいこと、かすかなことを指します。

ここで「微」が指すものは二つあると読めます。一つは、直前の「微妙」と同じく、真偽の見分けの細かさです。もう一つは、情報が及ぶ範囲の細かさです。戦場の大きな動きだけでなく、門番の名前一つにまで間諜の仕事は及びます。実際、この少し後で孫子は、攻めたい城や討ちたい相手があれば、守将や側近、取り次ぎ役、門番、雑用係の姓名まで先に知れと述べています。

この一節の直後には、厳しい規定も置かれています。間諜の仕事がまだ表に出ないうちに外から聞こえてきたら、その間諜も、話を聞いた者も、ともに死罪とする。秘密が漏れた網は、敵にとっての網に変わるからです。情報の仕事は、一度仕組みを作れば終わるものではありません。細部まで、絶えず手入れを要する営みです。

### 反間がすべての起点になる

五間の説明の後、孫子は五つの順番を示します。まず、こちらを探りに来ている敵の間諜を必ず探し出し、利を与え、手厚くもてなして寝返らせます。これが反間です。原文は「必索敵間之來間我者」と、探し出す側の能動を強く言います。

反間からは、敵の内部事情が分かります。そこで初めて、どの住民やどの役人を味方にできるかが見え、郷間と内間が使えるようになります。反間を通じて敵が何を信じやすいかが分かるので、死間に運ばせる偽りの中身が決まります。敵の動きの時期が分かるので、生間を予定どおりに出し入れできます。

孫子は「五間の事は主必ず之を知る。之を知るは必ず反間に在り」と結び、だから反間は厚く遇さなければならないと言います。最も危うい存在を、最も厚く扱う。逆説のようですが、筋は通っています。

```quote
原文: 故明君賢將、能以上智為間者、必成大功。此兵之要、三軍之所恃而動也。
訓読: 故に明君賢将の、能く上智（じょうち）を以て間と為す者は、必ず大功を成す。此れ兵の要にして、三軍の恃（たの）みて動く所なり。
出典: 用間篇
訳: だから賢明な君主や優れた将で、最高の知性の持ち主を間諜とすることのできる者は、必ず大きな功績を挙げる。これこそ用兵の要であり、全軍がそれを頼りにして動くものである。
```

この直前に、孫子は二つの例を挙げます。殷が興ったとき伊摯（いし）は夏の国にいた。周が興ったとき呂牙（りょが）は商（殷）にいた。伊摯は伊尹（いいん）、呂牙は太公望呂尚として知られる、建国の功臣です。

二人を間諜と呼ぶのは、ずいぶん大胆な読み替えです。けれども孫子の目から見れば、二人は敵国の中枢を内側から知り、その知識を新しい王朝にもたらした人物です。間諜とは、こそこそ嗅ぎ回る小者ではなく、最高の知性が就くべき仕事だと言いたいのです。

そして全書は「三軍の恃みて動く所なり」で閉じます。軍は情報を頼りにして動く。ここで謀攻篇の一句が思い出されます。「彼を知り己を知れば、百戦して殆うからず」。十三篇の最後は、その「彼を知る」の方法論でした。計篇の計算に始まり、計算の材料を得る篇で終わる。書物全体が一つの円を描いています。

## 構造を図で見る

![図15 五間の関係 — 反間を中心に、郷間・内間・死間・生間がつながる](figures/13-five-spies.svg)

図の中心に置いたのは反間です。敵の間諜を寝返らせると、そこから矢印が四方に伸びます。敵の内情が分かるので郷間と内間を得られます。敵の信じやすいものが分かるので死間の偽りを作れます。敵の時期が分かるので生間を往復させられます。

この図で見てほしいのは、四つの間が互いに独立していないことです。どれも反間から得た知識を土台にしています。反間を失えば、残りの四つは見当違いの場所を探ることになります。孫子が「反間は厚くせざるべからず」と念を押すのは、この構造の要だからです。

図の外側には、君主と将がいます。彼らの「聖智・仁義・微妙」が、網全体を動かし、真偽をふるい分けます。情報の網は、仕組みと人の資質の両方でできています。

## 異分野への接続

```connect
title: 決定が変わる情報にだけ、値段が付く
情報の経済学には「情報の価値」という考え方があります。ある情報を得たとき、決定がより良い方へ変わる見込みがどれだけあるか。その期待値の増え方が、情報に払ってよい上限になる、という考え方です。

この考え方には、直感に反する帰結があります。どれほど正確な情報でも、それを知っても決定が変わらないなら、価値はゼロです。逆に、懸かっているものが大きく、しかも判断が割れている場面では、わずかな情報にも大きな値が付きます。

孫子の勘定は、これと同じ形をしています。懸かっているのは十万の軍と七十万戸の生活で、勝負は一日で決まります。判断を変えうる敵情に百金を払うのは、期待される損失の大きさから見れば安すぎるほどです。両者が同じ形なのは、どちらも「情報の値段は、それが左右する決定の重さで決まる」という一点から出発しているからです。

違いもあります。情報の経済学は、確率と損得を数字で置いて上限を計算します。孫子は数式を持たず、その計算を「不仁」という倫理の言葉で締めくくりました。
```

```connect
title: 二重スパイが情報網の質を決める
第二次世界大戦中、英国はドイツが送り込んだ諜報員を次々に捕らえ、その多くを寝返らせて使ったと伝えられます。この仕組みはダブルクロス・システムと呼ばれます。

寝返った諜報員は、二つの働きをしました。一つは、ドイツ側から届く指示を通じて、ドイツが何を知りたがっているかを英国に教えたことです。問いの中身が、相手の意図を映していました。もう一つは、英国が作った偽の情報をドイツへ流す経路になったことです。連合軍の上陸地点をめぐる欺瞞に使われたことが、よく知られています。

これは用間篇の連鎖と同じ形です。反間から敵の関心と内情を知り、その知識で死間に運ばせる偽りを設計する。両者が同じ形なのは、敵の情報網に直結した一点を押さえると、敵が何を見て何を信じるかを同時に握れるからです。

違いは、検証の手段です。英国は暗号解読によって、自分たちの流した偽情報が相手に信じられているかを確かめられたとされます。孫子の時代には、その確認もまた人の「微妙」に頼るしかありませんでした。
```

## 誤解されやすい点

```note
「鬼神に取るべからず」は、迷信の批判として読むことができます。ただし孫子は、鬼神が存在しないとは言っていません。言っているのは、敵の情を前もって知る方法として、祈りや占いは役に立たないということです。九地篇にも「禁祥去疑」、つまり吉凶の占いを禁じて兵の迷いを取り除くという句があります。そちらは兵の心を乱さないための措置です。神霊を論じるのではなく、判断の材料と兵の士気から占いを外す。その実務的な態度として読むのが穏当です。
```

## この篇の一行

用間篇を一文にすると、こうなります。知ることへの出費は、知らずに戦う費用と比べて判断せよ。

勝負を左右する情報は、祈りや類推の中にはなく、敵の側にいる人の中にあります。その人を得るには、厚い報酬と誠実さと、届いた話を疑う目が要ります。そして網の要には、敵の手を裏返した反間が座ります。計篇で始まった「数える」営みは、この篇でようやく材料の出どころを得ました。

戦う前に数え、数えるために知り、知るために人に払う。十三篇は、その順で互いを支えています。十三篇を読み終えたいま、その流れを一本の線として引き直すと、何が見えてくるでしょうか。
