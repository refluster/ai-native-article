# 作戦篇 — 戦争は高い

## 一日に千金が消える

計篇は「数えてから戦え」と説いて終わりました。作戦篇は、その数える対象をいきなり目の前に並べます。最初に出てくるのは、勇ましい檄文でも陣形でもありません。請求書です。

篇題の「作戦」は、現代語の「作戦計画」とは意味が違います。「戦いを作（おこ）す」、つまり戦争を起こして動かすことだと読むのが一般的です。その起こし方を語る最初の一節が、そのまま費用の一覧になっています。

挙がる品目はこうです。馳車（ちしゃ）千駟（しし）、四頭立ての軽い戦車が千台。革車（かくしゃ）千乗、革で覆った重い車が千台。帯甲（たいこう）十万、よろいを着けた兵が十万人。さらに、千里の遠くまで糧食を運ぶ費用が加わります。国の内外の出費、使者をもてなす費用、弓や車を補修する膠（にかわ）や漆の材料、車とよろいの維持費も続きます。

合計は「日に千金を費やす」です。これだけ払ってはじめて十万の軍が動き出す、と孫子は書きます。千金が現在のいくらに当たるかは諸説あり、正確な換算はできません。

十万という人数の重さも考えておきたいところです。これは一つの都市に近い人口です。その全員が田畑の仕事を離れ、食べながら移動し続けます。しかも彼らが本来つくるはずだった作物は、その間つくられません。戦費には、支払う額と、失われる稼ぎの両方が含まれているのです。

それでも、いちばん目を留めたい点は別にあります。孫子は総額ではなく、一日あたりの額を示しました。戦争の費用は、始めた日から日割りで積み上がっていくということです。止めない限り、請求は毎朝届きます。

では、その日割りの請求書が戦いの長さと掛け合わさると、何が起きるのか。作戦篇の問いはここにあります。長引く戦いは、なぜ必ず負けるのでしょうか。

## 原文を読む

```quote
原文: 其用戰也、勝久則鈍兵挫銳、攻城則力屈、久暴師則國用不足。
訓読: 其の戦いを用うるや、勝つも久しければ則ち兵を鈍らせ鋭を挫き、城を攻むれば則ち力屈き、久しく師を暴せば則ち国用足らず。
出典: 作戦篇
訳: 戦いを行うにあたっては、たとえ勝っていても長引けば軍は疲れて鋭さを失い、城攻めをすれば戦力が尽き、軍を長く野外にさらせば国の財政が足りなくなる。
```

この一節には、長期戦が削るものが三つ並んでいます。一つ目は兵です。「鈍（にぶ）らせ」は刃が鈍ること、「鋭を挫（くじ）く」は勢いの先端が折れることです。二つ目は力です。城攻めは守る側が有利なため、攻める側の戦力が尽きていきます。三つ目は国の財布です。「師を暴（さら）す」とは、軍を野外に長くさらしておくことです。

注目したいのは「勝つも久しければ」という読みです。孫子は、負けている場合の話をしていません。勝っていても、長引けばこの三つは減っていくと言っています。戦場の勝ち負けとは別に、時間そのものが費用として働くのです。

なお、他本はここに「貴」の字を加えて「貴勝、久則……」と作り、「勝つことを貴ぶ。久しければ……」と読みます。どちらで読んでも、長引くことが害だという骨格は変わりません。

原文はこのあと、疲れ果てた国の隙を見て、他国の諸侯が兵を起こすと続けます。そうなれば、どんな知恵者がいても後始末はつけられない。長期戦の請求書には、自国の消耗に加えて、第三者の介入という項目が後から書き足されるのです。

```quote
原文: 故兵聞拙速、未睹巧之久也。
訓読: 故に兵は拙速を聞くも、未だ巧の久しきを睹ざるなり。
出典: 作戦篇
訳: だから戦争では、多少まずくても素早く切り上げて成功した例は聞くが、巧みに長引かせて成功した例は見たことがない。
```

この一節は、のちに「兵は拙速を貴ぶ」という成語になりました。しかし原文の言い方は、もっと慎重です。「拙速（せっそく）」とは、出来は拙いが速いことです。孫子は、拙くても速く終えた例は「聞く」、巧みでも長引いた例は「睹（み）ない」と、見聞の記録として語っています。

比べられている組み合わせに注意が要ります。拙くて速い、と、巧みで遅い。この二つを並べて、後者の成功例がないと言うのです。「拙くてよい」とは言っていません。言っているのは、巧みさと速さが両立しないとき、巧みさのために時間を払うのは割に合わない、ということです。

前の一節の数字と合わせると、理由は算数になります。一日に千金かかるなら、作戦を磨くために一か月延ばすことは、三万金で完成度を買うことです。その完成度が三万金に見合った例を、孫子は見たことがないと言っているわけです。

原文は続けて、「兵久しくして国利する者は、未だ之れ有らざるなり」と言い切ります。戦いが長引いて国が得をした例は、これまで一つもない、という断定です。拙速の一句は、この断定を導く前置きとして置かれています。

この断定の根拠は、先に見た第三者の存在にあります。戦いは二国だけで完結しません。二国が長く争えば、両方が弱ります。そのとき最も得をするのは、戦っていない周りの国です。長期戦は、自国の費用で他国の好機をつくる行為だということになります。

```quote
原文: 故不盡知用兵之害者、則不能盡知用兵之利也。
訓読: 故に尽く用兵の害を知らざる者は、則ち尽く用兵の利を知ること能わざるなり。
出典: 作戦篇
訳: 戦争の害を知り尽くしていない者には、戦争の利益も本当にはわからない。
```

この句は、篇の前半の結論です。「害」とは、ここまで並べてきた費用と消耗、そして他国につけ込まれる危険のことです。「利」は、戦争で得られるもの、つまり領土や安全や勝利そのものです。「尽（ことごと）く」は、残らず全部という意味です。

順序に意味があります。利を知るには、先に害を知り尽くさねばならない。利益は、費用を差し引いた後にしか確定しないからです。売上だけを見て商売の良し悪しを決められないのと同じ理屈です。勝利の価値も、それに払った時間と財貨を引いて、はじめて測れます。

計篇は「勝算」を数えよと言いました。作戦篇はそこに、勝算の裏側にある「費用」の欄を書き加えます。勝てるかどうかと、勝つのにいくらかかるか。二つの欄がそろって、はじめて開戦の判断ができる。この句は、その二つを結ぶ位置に置かれています。

では、費用をどう抑えるのか。孫子の答えは補給にあります。

```quote
原文: 故智將務食於敵、食敵一鍾、當吾二十鍾。萁稈一石、當吾二十石。
訓読: 故に智将は務めて敵に食む。敵の一鍾を食むは、吾が二十鍾に当たり、萁稈一石は、吾が二十石に当たる。
出典: 作戦篇
訳: だから賢い将は、できるだけ敵地で食糧を調達する。敵から得た食糧一鍾は自国から運ぶ二十鍾に相当し、馬の飼料一石は自国の二十石に相当する。
```

この一節の前に、孫子は補給の原則を述べています。兵の徴集は二度せず、食糧の輸送は三度に及ばせない。武具は自国のものを使うが、食糧は「糧を敵に因（よ）る」、つまり相手の土地で手に入れる。「鍾（しょう）」は穀物の量の単位、「萁稈（きかん）」は豆がらや藁のような飼料です。

なぜ敵の一鍾が、自国の二十鍾に当たるのでしょうか。古い注釈には、遠くから運べば多くを費やして、ようやくわずかが届くという説明が見えます。運ぶ人と牛馬もまた、道中で食べるからです。二十倍という数字は、その目減りを一言で示したものと読めます。

原文はこの比率の前に、国の暮らしへの影響も書いています。遠くへ運べば民が貧しくなり、軍の近くでは物価が上がって民の財が尽きる。民の出費は十のうち七が消え、国の出費も車や馬の損耗で十のうち六が消える。補給は、軍だけでなく国全体の家計の問題として描かれています。

さらに孫子は、奪った戦車の旗を自軍のものに替えて混ぜて使い、捕らえた兵は善く扱って養えと続けます。これを「敵に勝ちて益々強し」と呼びます。費用を相手の側から賄えば、戦うほど痩せるという構造を逆向きにできる、という発想です。

```quote
原文: 故知兵之將、民之司命、國家安危之主也。
訓読: 故に兵を知るの将は、民の司命にして、国家安危の主なり。
出典: 作戦篇
訳: だから戦争を理解した将軍は、民の命運を握る者であり、国家の安危を左右する者である。
```

篇の最後の一文です。直前で孫子は「兵は勝つことを貴びて、久しきを貴ばず」とまとめ、そのうえでこの句を置きます。「司命（しめい）」は、命運をつかさどる者という意味です。

ここで言う「兵を知る」は、前の文脈から読めば、戦い方の巧みさだけではありません。一日の費用、長期戦の消耗、補給の目減り、他国の介入。作戦篇が並べてきた「用兵の害」を知り尽くしていることが含まれます。

そう読むと、この句は将への賛辞であると同時に、重い責任の宣告でもあります。戦いを一日延ばす判断は、民の財布から一日分の千金を引き出す判断です。将の判断の出来は、そのまま民の暮らしと命に跳ね返ります。戦争の費用を数えられる者だけが民の命運を預かれる、というのがこの篇の結びだと読めます。

## 構造を図で見る

作戦篇の論理を一本の時間軸に並べると、三つの線が見えてきます。

一本目は費用です。日に千金という日割りの支出が、日数に比例して積み上がります。二本目は疲弊です。兵の鋭さ、攻城の戦力、国の財政は、勝っていても時間とともに削られます。三本目は、第三者の介入リスクです。図では、疲弊が深まった先で諸侯が動き出す危険が急に高まる形として描いています。

![図4 長期戦のコスト曲線 — 時間とともに積み上がる費用と疲弊、その先で高まる第三者介入の危険](figures/02-cost-curve.svg)

図の要点は、三本の線がすべて時間の関数だということです。作戦の巧みさは、どの線の傾きもほとんど変えられません。変えられるのは、線をどこで止めるか、つまり戦いの長さです。そして「糧を敵に因る」は、費用の線の傾きそのものを緩める手段として置かれています。

この図から、冒頭の問いへの答えも読み取れます。長引く戦いが必ず負けるのは、戦場で負けるからではありません。三本の線のどれかが、先に限界に届くからです。国庫が尽きるか、兵が鈍るか、第三者が動くか。勝ち続けていても、時間が延びるかぎり、いずれかの線が必ず限界を越えます。孫子が「未だ之れ有らざる」と言い切れたのは、この構造が戦場の巧拙とは別のところで働いているからだと考えられます。

## 異分野への接続

```connect
title: 財務の「滑走路」
新しい会社の財務には「ランウェイ」、日本語で滑走路という言葉があります。手元の現金を、毎月出ていく額で割ったものです。この毎月の支出の速さを「燃焼率」と呼びます。現金が一億円、燃焼率が月一千万円なら、滑走路は十か月です。その間に売上が立つか、追加の資金が入らなければ、会社は止まります。

作戦篇の冒頭の計算は、これと同じ形をしています。日に千金という燃焼率が決まれば、国庫の額で残りの日数が決まります。孫子が総額ではなく一日あたりの額を示したのは、燃焼率を示したということです。両者が同じ形なのは、どちらも「蓄えが一定の速さで減り、尽きた時点で活動が止まる」という仕組みを持つからです。

この見方をとると、拙速の一句も読みやすくなります。滑走路が短いのに製品の完成度を磨き続けるのは、残り時間を完成度と交換することです。その交換が見合うことは多くありません。完成度の高い製品を出す前に資金が尽きれば、完成度はゼロとして扱われるからです。

違いもあります。会社の滑走路は、資金調達で延ばせることがあります。戦争の国庫も増税で延ばせますが、作戦篇はそれを民の財が尽きる道として描いています。そして戦争では、蓄えが減ること自体が、周りの国を呼び込む合図になります。
```

```connect
title: 補給線の長さと目減り
物流には、輸送距離が長いほど途中で失うものが増えるという構造があります。トラックは走るほど燃料を使い、運転手の人件費がかかります。時間がかかれば生鮮品は傷みます。遠い産地の品に距離の分の費用が上乗せされるのは、このためです。

敵の一鍾が吾の二十鍾に当たるという計算は、これと同じ形です。どちらも「運ぶこと自体が、運んでいる資源の一部を消費する」という仕組みを持つからです。古代の輸送では、運ぶ人と牛馬が道中で食糧を食べました。現代のトラックは燃料を食べます。距離が延びるほど、届く分に対して途中で消える分が大きくなります。

供給の網、いわゆるサプライチェーンを設計する人は、消費地の近くに倉庫や工場を置こうとします。補給線を短くするためです。孫子の「敵に因る」は、この発想をいちばん先まで進めたものと読めます。戦場そのものから調達すれば、補給線の長さはほぼゼロになります。兵の徴集は二度せず、輸送は三度に及ばせないという原則も、往復を減らして線の負担を軽くする工夫と読めます。

違いは、調達の相手です。物流の現地調達は取引先からの購入ですが、孫子の調達は相手の資源を取ることです。敵から取れば、自分の費用が減ると同時に相手の蓄えも減ります。一つの行為で両側の帳尻が動く点は、戦争に特有の性質です。物流では、相手の倉庫を空にすることは目的になりません。
```

## 誤解されやすい点

```note
「兵は拙速を貴ぶ」（「尊ぶ」とも書きます）は、原文にない成語です。原文が比べているのは「拙で速」と「巧で久」の二つで、巧みで速い道があるなら、それを否定してはいません。
```

```note
篇の結びの「民之司命」は、他本には「生民之司命」と作るものがあります。「生民」は人々という意味で、どちらでも、将が人々の命運をつかさどるという内容は変わりません。
```

## この篇の一行

作戦篇を一文に縮めると、こうなります。戦争の費用は日割りで積み上がり、時間は勝っている側の力さえ削るから、勝つなら短く勝て。

計篇が「勝てるかどうか」を数える篇だったとすれば、作戦篇は「勝つのにいくらかかるか」を数える篇です。そして答えは、時間に比例して高くなる、でした。糧を敵に因るのも、奪った車や兵を自軍に加えるのも、この比例の傾きを少しでも緩めるための工夫です。将が民の命運を預かるのも、この費用を払うのが最終的には民だからでした。

けれども、どれほど傾きを緩めても、戦えば費用はかかります。戦いは高くつくから、速く終える。では、いちばん安い勝ち方は何でしょう。
