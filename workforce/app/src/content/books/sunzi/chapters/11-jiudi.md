# 九地篇 — 状況が人を変える

## 同じ人が、別人のように動くとき

前章で読んだ地形は、山や川や道の形でした。九地篇が見つめるのは、その地に立つ人の心の側です。同じ兵士が、自国では逃げ腰なのに、敵国の奥深くでは死を恐れずに戦います。孫子はこの違いを、兵士の性格ではなく、置かれた場所の性質から説明しようとします。

身近な場面で考えてみます。一か月前にはまったく進まなかったレポートが、締切の前夜には数時間で仕上がることがあります。書いた人の能力が一晩で変わったわけではありません。変わったのは、残り時間と、ほかに選べる道の数です。逃げ道が消えると、人は迷いを捨てて一つのことに力を集めます。

ここでいう「地」は、地図の上の場所というより、軍が置かれた立場を指す言葉です。自国からどれだけ離れたか、退路はあるか、敵と味方のどちらが先に着けるか。こうした条件の組み合わせが、九つの型に分けられています。

九地篇は全十三篇のなかで最も長い篇です。前半で九つの地を定義し、後半では兵の心理と将の振る舞いを論じます。底に流れる問いは一つです。同じ人が、なぜ状況によって別人のように動くのか。そして将はその力をどう使い、どこで使ってはならないのか。この章では、六つの原文からその答えを読んでいきます。

## 原文を読む

```quote
原文: 是故散地則無戰、輕地則無止、爭地則無攻、交地則無絕、衢地則合交、重地則掠、圮地則行、圍地則謀、死地則戰
訓読: 是の故に散地には則ち戦うこと無く、軽地には則ち止まること無く、争地には則ち攻むること無く、交地には則ち絶つこと無く、衢地には則ち交わりを合わせ、重地には則ち掠め、圮地には則ち行き、囲地には則ち謀り、死地には則ち戦う。
出典: 九地篇
訳: 自国内の散地では戦わず、敵国に入ったばかりの軽地では留まらず、奪い合いになる争地では攻めかからず、往来しやすい交地では隊列を切らさず、諸国が接する衢地では外交を結び、敵地深くの重地では物資を奪い、進みにくい圮地では速やかに通過し、出入口の狭い囲地では謀略を用い、戦わなければ滅びる死地では戦う。
```

この一節の直前で、孫子は九つの地を一つずつ定義しています。散地は自国の領内で戦う地です。兵の家が近いので、形勢が悪くなると散り散りに逃げ帰ります。軽地は敵国に入ったばかりの浅い地で、兵はまだ引き返したがっています。争地は、敵と味方のどちらが取っても有利になる要所です。交地は双方が行き来しやすい開けた地です。

衢地（くち）は、三つ以上の国に接する交差点のような地です。先に着けば周りの国々を味方にできます。重地は敵国の奥深く、背後に敵の城をいくつも残した地です。圮地（ひち）は山林や沼沢など、通りにくい地を指します。囲地は入口が狭く帰り道が遠回りで、少数の敵に大軍が打たれる地です。死地は、速く戦えば生き残り、ためらえば滅びる地です。

注目したいのは、九つの多くが地理ではなく、自国からの距離と退路の有無で決まっている点です。篇の後段には「深ければ則ち専らに、浅ければ則ち散ず」という句もあります。深く入るほど兵は一つにまとまり、浅いほどばらけるという意味です。散地で戦うなという指示は、兵の心が家に向いているからです。死地で戦えという指示は、戦う以外に道がないからです。同じ兵でも、立つ場所によって取れる行動が変わるのです。

```quote
原文: 兵之情主速、乘人之不及、由不虞之道、攻其所不戒也。
訓読: 兵の情は速を主とす。人の及ばざるに乗じ、虞らざるの道に由り、其の戒めざる所を攻むるなり。
出典: 九地篇
訳: 戦いの本質は速さにある。敵の対応が間に合わないところに乗じ、予想されていない道を通り、警戒していない所を攻めるのである。
```

この一節は問答の答えとして置かれています。整った大軍が攻めてきたらどうするか、という問いです。孫子はまず「先ず其の愛する所を奪えば、則ち聴かん」と答えます。相手が最も大切にしているものを先に押さえれば、相手はこちらの思いどおりに動く、という意味です。そのうえで、この速さの原則が続きます。

「情」は感情ではなく、実情や本質を意味します。戦いの本質は速さにある、という断言です。ここで大事なのは「人の及ばざる」という言い方です。速さとは自軍の足の速さそのものではなく、相手の対応が追いつかない時間差のことです。

この一節は、九地の考え方を敵の側に向けたものとも読めます。九地篇は、置かれた状況が人の動きを決めると説きます。ならば、敵を準備のない状況に置けば、敵は本来の力を出せません。虞（はか）らざる道とは、相手が予想していない道です。戒めざる所とは、警戒していない場所です。速さは、相手の状況を一方的に書き換える手段なのです。

```quote
原文: 故善用兵者、譬如率然。率然者、常山之蛇也。擊其首則尾至、擊其尾則首至、擊其中則首尾俱至。
訓読: 故に善く兵を用うる者は、譬えば率然の如し。率然とは、常山の蛇なり。其の首を撃てば則ち尾至り、其の尾を撃てば則ち首至り、其の中を撃てば則ち首尾倶に至る。
出典: 九地篇
訳: 用兵の上手な者の軍は、率然という蛇のようである。率然とは常山にいる蛇で、頭を打てば尾が助けに来て、尾を打てば頭が来て、胴を打てば頭と尾がともに来る。
```

率然（そつぜん）は、常山にすむとされる蛇の名です。頭を打たれれば尾が、尾を打たれれば頭が、胴を打たれれば頭と尾が同時に応じます。どこを打たれても、残りの部分が指示を待たずに動くのです。孫子は理想の軍をこの蛇にたとえました。

ここで描かれているのは、強い頭を持つ蛇ではありません。どの部分も全体の一部として反応する蛇です。大軍は広い範囲に散らばるので、将の命令がすべての場所に間に合うとは限りません。打たれた場所の近くにいる者が、自分の判断で駆けつける。そうした軍でなければ、弱いところを突かれて崩れます。

では、そんな軍はどうすれば作れるのか。孫子は「率然の如くならしむべきか」と自ら問い、「可なり」と答えます。できる、というのです。その根拠として挙げられるのが、次の一節です。

```quote
原文: 夫吳人與越人相惡也、當其同舟濟而遇風、其相救也、如左右手。
訓読: 夫れ呉人と越人とは相悪むも、其の舟を同じくして済り、風に遇うに当たりては、其の相救うや左右の手の如し。
出典: 九地篇
訳: 呉の人と越の人は互いに憎み合っているが、同じ舟で川を渡っているときに大風に遭えば、左右の手のように助け合う。
```

呉と越は、長く争い続けた隣り合う国です。成語「呉越同舟」はこの一節から生まれました。いまでは「仲の悪い者同士が同じ場に居合わせる」という意味で使われがちです。しかし原文の主旨は、已むを得ない状況に置かれれば、敵同士でも協力するという点にあります。仲が良いから助けるのではありません。舟が沈めば自分も沈むから助けるのです。

続けて孫子は、馬をつなぎ車輪を地に埋めて退路を物理的にふさいでも、それだけでは頼りにならないと言います。勇気をそろえて一つにするのは「政の道」、つまり統率のしかただというのです。そして段落は「善く兵を用うる者は、手を攜（たずさ）えて一人を使うが若し。已むを得ざればなり」と結ばれます。大軍がまるで一人の人間のように動くのは、そうせざるをえない状況に置かれているからです。率然の一体感は、規則や愛着からではなく、状況から生まれるものとして描かれています。

```quote
原文: 投之亡地然後存、陷之死地然後生。
訓読: 之を亡地に投じて然る後に存し、之を死地に陥れて然る後に生く。
出典: 九地篇
訳: 兵は、滅亡するしかない状況に投げ込まれてこそ生き残り、死ぬしかない状況に陥れられてこそ生き延びる。
```

亡地（ぼうち）も死地も、退路がなく、戦わなければ滅びる状況を指します。篇の前半にはすでに「之を往く所無きに投ずれば、死すとも且つ北（に）げず」という句があります。逃げ場がなければ、兵は死んでも敗走しないという意味です。

この発想は、軍争篇の「囲師は必ず闕（か）き、窮寇は追う勿かれ」と表裏の関係にあります。退路を失った集団は異常に強くなる。だから敵には逃げ道を残し、自軍からは逃げ道を消す。同じ法則を、向きを変えて二度使っているのです。のちに漢の韓信（かんしん）が川を背に陣を敷いたとき、この言葉を根拠に挙げたと『史記』は伝えています。

ただし、この一節は将の統率術として語られています。直前には「将軍の事は、静にして以て幽、正にして以て治む」とあります。将は落ち着いて奥深く、公正で乱れない、という意味です。さらに将は兵の耳目をふさいで計画を知らせず、高い所に登らせて梯子を外すように退路を断つ、と書かれています。情報を絞り、兵に迷いの余地を残さない。そのうえで初めて、死地は力を引き出す場になります。計算のない冒険の勧めではありません。

将の「静」と兵の「迷いのなさ」は、一組の仕掛けとして書かれています。孫子は、将が仕事の内容や計画を変えても兵には悟らせず、宿営地や道筋を変えても兵に考えさせないようにせよ、と述べます。兵が先の見通しを持てば、そこから迷いや逃げる算段が生まれるからです。見通しを将の側にだけ残し、兵には目の前の一歩だけを見せる。死地の力は、この情報の偏りによって支えられています。現代の価値観とは大きく隔たる点で、章末の補注で改めて取り上げます。

```quote
原文: 是故始如處女、敵人開戶。後如脫兔、敵不及拒。
訓読: 是の故に始めは処女の如くにして、敵人戸を開き、後には脱兎の如くにして、敵拒ぐに及ばず。
出典: 九地篇
訳: だから、初めは乙女のようにおとなしく振る舞って敵に戸を開かせ、その後は逃げ出す兎のような勢いで動けば、敵は防ぐことができない。
```

篇の最後の一節です。ここでの処女は、嫁ぐ前で家の奥にいる娘を指し、おとなしく目立たない様子のたとえです。脱兎（だっと）は、囲いから逃げ出す兎の素早さです。

この直前に「夫れ兵を為すの事は、敵の意に順詳するに在り」という句があります。敵の意図に従うように見せながら、その意図を詳しく見極める、という意味です。テキストによっては「佯（いつわ）りて順う」となっており、偽装の色がより濃くなります。そのうえで力を一方向に集め、千里の先で敵将を討つ。孫子はこれを「巧みに事を成す」と呼びます。

「脱兎の如く」は、いまでは逃げ足の速さを言うことが多い表現です。しかし原文では、攻撃に転じる瞬間の素早さを言っています。静かに相手の警戒を解き、戸が開いた瞬間に一気に動く。前半の「兵の情は速を主とす」が、篇の結びで具体的な形を与えられているのです。

## 構造を図で見る

![図11 九地と率然 — 自国からの距離と退路の有無で九つの地が決まり、退路が消えるほど軍は率然のように一体化する](figures/11-nine-grounds.svg)

図の左側には、九つの地を自国からの距離の順に並べました。散地から軽地、重地へと進むにつれて、兵の心は家から離れていきます。縦の軸は退路の有無で、いちばん下に死地が来ます。争地・交地・衢地は、距離よりも敵味方の位置関係で決まる地として脇に置いています。

図の右側は率然です。頭・胴・尾のどこが打たれても、残りの部分が矢印のように応じます。左の軸を下に進むほど、つまり退路が消えるほど、軍は右の蛇の形に近づきます。九地篇の論理は、この一本の線にまとめられます。状況が逃げ道を奪い、逃げ道のなさが集団を一体にするのです。

図には、もう一つ読み取ってほしい点があります。九つの地にはそれぞれ別の行動原則が対応していましたが、その違いは兵の側ではなく地の側にあります。同じ兵が、散地では散り、死地では戦います。図の左右をつなぐ線は、兵の性格を一度も経由していません。


## 誤解されやすい点

```note
「死地に投じる」という発想は、現代の組織倫理と正面から衝突します。原文は、二千年以上前の戦争で、将が兵の心理を利用する統率術として述べたものです。兵の耳目をふさぎ、梯子を外して退路を断つという記述も、兵の同意を前提にしていません。これを「社員を追い込めば力を出す」と読み替えるのは、原文の文脈を外れた誤用です。現代に持ち帰れるのは、状況が行動を強く形づくるという観察までです。その力を他人に向けるときは、本人の同意と退路の保障が欠かせません。軍争篇が敵にさえ逃げ道を残せと説いていることも、あわせて思い出しておきたい点です。
```

## この篇の一行

九地篇を一文にすると、こうなります。人は性格だけでなく、置かれた状況によって動き、退路が消えるほど集団は一つになる。九つの地の分類も、率然の一体感も、処女と脱兎の切り替えも、すべてこの一つの観察から出ています。孫子はそれを、自軍には死地を、敵には逃げ道を、という両向きの用法にまで磨きました。同時に、その力が強いからこそ、使い手の計算と節度が問われることも示しています。ここまでは人と地。残る二篇は、道具と情報の話。
