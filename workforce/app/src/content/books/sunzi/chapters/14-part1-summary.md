# 前編を終えて — 十三篇を一本の線に

一篇ずつ読むと、十三篇の話題はばらばらに見えます。数の比較があり、地形の分類があり、火の使い方があり、間諜（敵の情報を探る者）の種類があります。けれども篇の順に要旨を並べ直すと、一つの問いへの答えが段階を追って深まる流れが見えてきます。その問いは「不確かな状況で、どうすれば勝算を高められるか」です。この章では流れを六つの段階にまとめ、各段階から一句ずつ引きます。五句は前編で読んだものの読み返しですが、用間篇の一句だけは、用間篇の章では引かなかった一節です。

## 数えることから始まる

計篇は、開戦前の比較から始まりました。五事と七計で彼我を並べて勝ち目を読むのが、開戦前の見積もり（廟算）です。

```quote
原文: 多算勝、少算不勝、而況於無算乎。
訓読: 算多きは勝ち、算少なきは勝たず。而（しか）るを況（いわ）んや算無きに於いてをや。
出典: 計篇
訳: 算の多い方が勝ち、少ない方は勝てない。まして算がまったくなければ、勝てるはずがない。
```

「算」は、勝つための条件を数えたものです。この句は、勝敗を戦場の出来事ではなく、出発前の見積もりの結果として扱っています。線の起点がここに置かれていることには、意味があります。

続く作戦篇は、同じ数える目を費用に向けました。十万の軍は一日に千金を使い、長引けば国の財政が尽き、他国に隙を突かれます。二篇に共通するのは、戦う前に量を比べ、その結果で動くかどうかを決める姿勢です。比べた末に「戦わない」と決めることも、計算の正しい答えのうちに含まれます。

## 負けない形から、主導権へ

```quote
原文: 是故勝兵先勝而後求戰、敗兵先戰而後求勝。
訓読: 是の故に勝兵は先ず勝ちて而る後に戦いを求め、敗兵は先ず戦いて而る後に勝ちを求む。
出典: 形篇
訳: だから勝つ軍は、まず勝てる態勢を整えてから戦いに臨む。負ける軍は、まず戦い始めてから勝ちを探す。
```

数えて戦うと決めたら、次は負けない形を作ります。謀攻篇は、その形を勝ち方の質から考えました。国や軍を無傷で降すのが上で、打ち破るのはその次です。兵力の比に応じて、囲む、攻める、避けるを選び、勝てない戦いには入りません。

形篇は、勝ちに至る順序をはっきりさせました。負けない態勢は、自分の手で作れます。勝てるかどうかは、敵が隙を見せるかどうかにかかっています。だから先に自分の側を固め、勝ちはその後に待つ、という順になります。

形篇も数えることを手放してはいません。度・量・数・称・勝という計量の連鎖で戦力の差を積み上げ、せき止めた水を深い谷へ切って落とすような態勢に仕上げます。線はここで「計算」から「態勢」へ移ります。

ただし形篇は、勝ちは「知るべくして為すべからず」とも書きました。形だけでは、勝ちを作り出すところまでは届きません。その先を引き受けたのが、続く勢篇と虚実篇でした。

```quote
原文: 故善戰者、致人而不致於人。
訓読: 故に善く戦う者は、人を致して人に致されず。
出典: 虚実篇
訳: だから戦上手は、敵を思いどおりに動かし、自分が敵に動かされることはない。
```

勢篇は、整えた形を一気に放つ力に変える方法を説きました。正攻法で受け止めて奇策で勝ち、個人の奮闘ではなく全体の勢いに頼ります。

虚実篇はさらに、どこで、いつ戦うかを決める側に回れと言います。自軍の形を隠し、敵の形を見えるようにすれば、自軍は集まり、敵は散ります。水が高い所を避けて低い所へ流れるように、敵の充実した所を避けて手薄な所を撃てます。勝ち方を繰り返さず、相手に応じて形を変え続けることも、ここで求められました。線は、守りを固める段階から、相手を動かす段階へ進みました。

## 現場で読み替える

```quote
原文: 是故智者之慮、必雜於利害、雜於利而務可信也、雜於害而患可解也。
訓読: 是の故に智者の慮（おもんぱか）りは、必ず利害に雑（まじ）う。利に雑えて務め信（の）ぶべきなり。害に雑えて患い解くべきなり。
出典: 九変篇
訳: だから知恵ある者は、必ず利益と損害の両面を合わせて考える。不利な状況でも利の面を考えるから事をやり遂げられ、有利な状況でも害の面を考えるから災いを未然に解ける。
```

軍争篇から九地篇までの五篇は、原理を現場で使うための篇です。軍争篇は、回り道を近道に変える「迂直（うちょく）」を説きました。九変篇は、通ってはならない道や受けてはならない君命まで挙げて、定石の例外を知ることを求めました。行軍篇は鳥や獣の動きから敵情を読む兆候を並べ、地形篇は地の類型と敗北の類型を整理しました。九地篇は、退路の有無という状況が兵の心理を変えることを示しました。

この句は、五篇に共通する判断の作法を述べています。有利なときにも害を考え、不利なときにも利を考えるのです。計篇で始まった数える姿勢は、ここで一度きりの廟算から、現場で絶えず繰り返す見積もりへと形を変えています。地形篇が六つの敗北を天災ではなく将の過ちとしたのも、この見積もりの責任が将にあるからです。

## 道具を抑え、先に知る

```quote
原文: 主不可以怒而興師、將不可以慍而致戰。
訓読: 主は怒りを以て師を興すべからず、将は慍（いきどお）りを以て戦いを致すべからず。
出典: 火攻篇
訳: 君主は怒りに任せて軍を起こしてはならず、将は憤りに任せて戦いを仕掛けてはならない。
```

火攻篇は火の使い方を述べたあと、話を戦争そのものの是非に移しました。火は、十三篇で扱われる手段の中でも、とりわけ破壊の大きい道具です。その篇が、道具の使い方ではなく、使わない理由で閉じられます。

同じ篇は、利がなければ動かず、危うくなければ戦わない、と行動の条件を絞ります。勝って攻め取っても成果を固めなければ、「費留（ひりゅう）」と呼ばれる浪費になります。怒りはやがて収まりますが、滅んだ国と死者は戻りません。この自制は、計篇の冒頭の「兵は国の大事」と向かい合っています。強い手段を持つほど、それを動かす判断を感情から切り離さなければなりません。数えることは、ここでは「使わない」判断を支える計算として戻ってきます。

```quote
原文: 故明君賢將、所以動而勝人、成功出於衆者、先知也。
訓読: 故に明君賢将の、動きて人に勝ち、成功の衆に出づる所以（ゆえん）の者は、先知なればなり。
出典: 用間篇
訳: 賢明な君主や優れた将が、動けば敵に勝ち、人並み外れた成功を収めるのは、前もって敵情を知っているからである。
```

最後の用間篇は、線の全体を支える土台を明かします。数えるにも、形を作るにも、主導権を握るにも、相手の実情がわからなければ始まりません。その「先知」は神霊や占い、過去からの類推では得られず、必ず人から得る、と用間篇は言います。だから郷間・内間・反間・死間・生間という五種の間諜を組み合わせて使い、それを扱う側にも知恵と誠実さを求めます。そして情報への出費を惜しむことは「不仁の至り」とまで書きました。

ここで線は起点へ戻ります。計篇の廟算は、正確な情報があってはじめて意味を持つからです。謀攻篇の「彼を知り己を知れば」も、同じことを求めていました。十三篇は、知ることで締めくくられ、その知が冒頭の計算を支える構造になっています。

## 一本の線として見る

![図16 十三篇の論理の流れ — 数える・負けない形・主導権・現場の運用・自制・知るの六段と、知ることが計算へ戻る環](figures/14-thread.svg)

図16は、六つの段を一本の流れに並べ、最後の「知る」から最初の「数える」へ矢印を戻したものです。

この六つの段は、序と導入で示した四つのまとまりと、次のように重なります。「戦う前」の三篇のうち、計篇と作戦篇は第一段の「数える」に入ります。謀攻篇は、損なわずに勝つ形を先に決める篇として、形篇とともに第二段の「負けない形」に置きました。「形と勢」の三篇は、形篇が第二段、勢篇と虚実篇が第三段の「主導権」に分かれます。「運用」の五篇はそのまま第四段です。「特殊な二篇」は、火攻篇が第五段の「自制」、用間篇が第六段の「知る」に当たります。

後編でこの線の各段を現代の場面に当てはめるときは、原文が言っていること、現代ではこう読めること、原文は言っていないことを分けて書きます。孫子が論じたのは国家の戦争であり、会社やチームではないからです。それでも、数え、備え、主導権を取り、見積もり直し、手段を抑え、先に知るという線は、不確かさを相手にする営みに共通する形です。では、この線を現代のプロジェクトとチームの上に置くと、各段はどんな仕事に当たるのでしょうか。
