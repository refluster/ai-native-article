# 計篇 — 戦う前に、数える

## この篇が答える問い

計篇は、戦い方の話から始まりません。陣形も奇策も、まだ出てきません。最初に置かれるのは、戦うかどうかを決める前の作業です。篇の名にある「計」は、はかりごとというより、数えて比べることを指します。

身近な場面に置き換えてみます。小さな洋菓子店が、隣町に二号店を出すかどうかを考えているとします。店主はまず紙に書き出すでしょう。店を任せられる人はいるか。家賃と人件費に、資金は耐えられるか。その町に、甘いものを買う人はどれくらいいるか。近くの競合店と比べて、自分の店は何で勝てるのか。

こうして書き出すと、出店の前から、うまくいくかどうかの見当はかなりつきます。もちろん、見当がつくことと勝ちが決まることは同じではありません。相手も同じように考えていますし、天気や景気のように誰にも動かせないものもあります。それでも、何も数えずに始めるよりは、ずっと確かなはずです。

この篇が答えようとする問いは、ひとつです。始める前に、勝ち負けはどこまで分かるのか。孫子の答えは、思いのほか強気です。かなりの部分まで分かる。そして、分からないまま始めるのがいちばん危うい。その答えを、原文の順に追っていきます。

## 原文を読む（一）——重大だから、数える

```quote
原文: 兵者、國之大事、死生之地、存亡之道、不可不察也。
訓読: 兵は国の大事にして、死生の地、存亡の道なり。察せざるべからざるなり。
出典: 計篇
訳: 戦争は国家の重大事である。人々の生死が決まる場であり、国が続くか滅びるかの分かれ道である。徹底して考え抜かなければならない。
```

『孫子』十三篇は、この一文から始まります。「兵」は武器や兵士も指しますが、ここでは戦争そのもののことです。「死生の地」は人が生きるか死ぬかが決まる場所、「存亡の道」は国が残るか消えるかの分かれ道です。

注目したいのは、結びの「察」という字です。察は、ただ眺めることではありません。細かく調べ、筋道を立てて見極めることです。「察せざるべからざる」は二重の否定で、見極めないことは許されない、という強い言い方になっています。

ここで孫子は、戦争を勧めても止めてもいません。重大だから避けよ、とも言っていません。重大だから、よく見極めよと言っています。重さを理由に考えるのをやめるのではなく、重さに見合うだけ考えよ、という順序です。

この冒頭は、のちに有名になる「兵は詭道なり」より、ずっと前に置かれています。『孫子』を謀略の書として思い浮かべる人は多いのですが、最初の一文は慎重さの宣言です。欺く技術の話は、この慎重さの上にしか乗らない。篇の並び方そのものが、そう語っています。

```quote
原文: 故經之以五事、校之以計、而索其情、一曰道、二曰天、三曰地、四曰將、五曰法。
訓読: 故に之を経るに五事を以てし、之を校ぶるに計を以てして、其の情を索む。一に曰く道、二に曰く天、三に曰く地、四に曰く将、五に曰く法。
出典: 計篇
訳: そこで五つの基本事項で戦争を測り、比較の項目で彼我を比べて、実情を探る。五つとは、道・天・地・将・法である。
```

では、何を見極めるのか。孫子は五つの軸を挙げます。これを五事と呼びます。原文はこのあと、一つずつ中身を説明しています。その説明を一行ずつに縮めると、次のようになります。

- 道：民が君主と思いを同じくし、生死を共にしても危険を恐れない状態。
- 天：昼と夜、寒さと暑さ、季節のめぐりといった時の条件。
- 地：道のりの遠近、地形の険しさ、広さ狭さ、生き延びられる地かどうか。
- 将：指揮官の知恵、信頼、思いやり、勇気、厳しさ。
- 法：部隊の編制、役職の分担、物資と費用の管理。

一番目が「道」であることに目が留まります。武器の数でも兵の数でもなく、人々が同じ方向を向いているかどうかが、最初の軸なのです。

原文の「経（はか）る」は、縦糸を張るように筋を通して測ることです。「校（くら）ぶる」は突き合わせて比べること、「索（もと）む」は手探りで探し出すことです。測る、比べる、探る。三つの動詞が、この篇の作業手順そのものになっています。

孫子は続けて、この五つは将なら誰でも聞いたことがある、と言います。そのうえで、本当に知る者は勝ち、知らない者は勝たないと述べます。聞いたことがあるのと、自分の状況に当てはめて使えるのとは違う、ということでしょう。

五事は、自分を測る物差しです。しかし勝ち負けは、相手がいて初めて決まります。そこで孫子は、五事を七つの問いに組み直し、相手と自分を並べます。これを後世「七計」と呼んできました。本書の底本では「計を以てす」とだけあり、「七」の字はありません。七計は、この七つの問いを指す通称です。

| 問い（書き下し） | 比べていること |
|---|---|
| 主、孰（いず）れか道有る | どちらの君主が民の心を得ているか |
| 将、孰れか能有る | どちらの将が有能か |
| 天地、孰れか得たる | 時と土地の利を、どちらが得ているか |
| 法令、孰れか行わる | 規則がどちらで守られているか |
| 兵衆、孰れか強き | 軍の力はどちらが強いか |
| 士卒、孰れか練れたる | 兵の訓練はどちらが行き届いているか |
| 賞罰、孰れか明らかなる | 賞と罰はどちらが公正か |

すべての問いが「孰れか」、つまり「どちらが」で始まります。ここが肝心なところです。自軍の将がどれほど優れているかを、単独では問いません。相手の将と比べて、どちらが上かを問うのです。この表は、絶対値ではなく差を見るための表だと言えます。孫子は七つの問いを並べたあと、自分はこれで勝負を知る、と言い切ります。

そして次の段で、数えた結果をどう使うかが語られます。将が自分の計に耳を傾けて用いるなら、必ず勝つから、とどまろう。耳を貸さずに用いるなら、必ず負けるから、去ろう。この「将」を将軍と読むか、「もし」の意味に読むかで、解釈は分かれます。後者なら、孫子が王に向かって、自分の計を聴くなら仕えようと告げている場面になります。

どちらに読んでも、骨組みは変わりません。数えた結果が良ければ動き、悪ければ動かない。計算は眺めるためではなく、行動を決めるために行うものです。孫子はさらに、計が受け入れられたら「勢」をつくって外から支えるとも述べます。この勢については、第五篇で詳しく読みます。

## 原文を読む（二）——相手を惑わせ、算を比べる

```quote
原文: 兵者、詭道也。
訓読: 兵は詭道なり。
出典: 計篇
訳: 戦争とは、相手を欺く行いである。
```

計篇でいちばん有名な句です。詭道（きどう）の「詭」は、いつわる、あざむくという意味です。「道」はここでは、やり方や原理のことです。

この句は、五事と七計の話が終わったあとに置かれています。この位置に意味があります。ここまで孫子は、自分と相手を同じ物差しで正確に数えよ、と説いてきました。ところが、相手も同じように数えています。だとすれば、勝つためのもう一つの道は、相手の数え方を狂わせることです。

原文はこのあと、十二の型を並べます。できるのにできないように見せる。使うのに使わないように見せる。近いのに遠く見せ、遠いのに近く見せる。ここまでの四つは、自分の能力、意図、位置の見せ方です。

続く八つは、相手の状態に応じた働きかけです。利を見せて誘い、乱れていれば奪い取る。充実していれば備え、強ければ避ける。怒りやすければかき乱し、へりくだって見せて驕らせる。休んでいれば疲れさせ、結束していれば引き離す。

並べてみると、十二の型はどれも七計の表の欄を狙っています。相手が読み取る自分の力をずらす。相手の将の冷静さを崩す。相手の結束を割る。詭道とは、相手の比較表に誤った値を書き込ませる技術だと言えます。

```note
「詭道」を「卑怯な手を使え」という勧めと読むのは誤りです。原文は戦いという営みの性質を述べた句で、人としての生き方を説いた句ではありません。また、この句は計篇の冒頭ではなく、五事と七計で冷静に数えることを説いたあとに置かれています。自分は正確に数え、相手には誤って数えさせる。二つは同じ一枚の表の、表と裏にあたります。
```

```quote
原文: 攻其無備、出其不意。
訓読: 其の備え無きを攻め、其の不意に出づ。
出典: 計篇
訳: 敵が備えていないところを攻め、敵が予想していないところに打って出る。
```

十二の型は、この短い句に収束します。備えの無い所とは、相手の計算から抜け落ちた場所です。不意とは、相手の予測の外側です。

言われていないことにも目を向けておきます。孫子は、敵より大きな力で攻めよとは言っていません。力の大小ではなく、相手の準備と予測にあいた穴を突けと言っています。正面からの力比べは、七計の表で勝っているときにしか選べません。表で劣っていても、相手の表の誤りを突けば勝機は生まれる。この句は、その可能性を示しています。

原文はこれに続けて、これが兵家の勝ち方であり、前もって伝えることはできないと述べます。どこに穴があくかは、その場の相手しだいだからです。型は教えられても、どの型をいつ使うかは事前には書けません。比べる作業は戦う前にできますが、惑わせる作業は現場でしか決まらない。計篇は、この二つの層をはっきり分けています。

```quote
原文: 夫未戰而廟算勝者、得算多也。未戰而廟算不勝者、得算少也。
訓読: 夫れ未だ戦わずして廟算して勝つ者は、算を得ること多ければなり。未だ戦わずして廟算して勝たざる者は、算を得ること少なければなり。
出典: 計篇
訳: 戦う前の廟堂での軍議で勝つと見通せるのは、勝つための条件（算）を多く得ているからだ。勝てないと出るのは、その条件が少ないからだ。
```

篇の結びに入ります。廟算（びょうさん）とは、開戦前に廟堂で行う軍議のことです。

「未だ戦わずして」という言葉が、二度くり返されます。戦う前の時点で、勝つ側と勝たない側はもう分かれている。孫子はそう見ています。

「算」は、数を数えること、またその見込みを表す字です。「算を得る」は、勝つための条件を一つずつ確かめて手に入れていくことです。七計の問いに「こちらが上」と答えられる欄が多いほど、算は多くなります。

この一節は、運命論ではありません。勝ち負けが天の定めで決まっている、と言っているのではありません。戦う前の準備と見積もりで、大部分が決まっていると言っているのです。だからこそ、戦う前にできることがあります。算が少ないと分かれば、戦わないか、算を増やしてから戦うかを選べます。

```note
廟（びょう）は、祖先を祀る建物です。古代中国では、国の大事は祖先の前で議するものとされ、開戦の評議もそこで行われたと考えられています。祖先の前で数えるとは、その判断が国の過去と未来に責任を負う、ということでもあります。また注釈の中には、「算」を勝ちの条件ごとに置いた数え棒と解し、その本数を比べたとみる説もあります。
```

```quote
原文: 多算勝、少算不勝、而況於無算乎。
訓読: 算多きは勝ち、算少なきは勝たず。而るを況んや算無きに於いてをや。
出典: 計篇
訳: 算の多い方が勝ち、少ない方は勝てない。まして算がまったくなければ、勝てるはずがない。
```

前の一節を、短く言い直した句です。ここにはよくある誤解があります。「数の多い方が勝つ」、つまり兵力の多い方が勝つと読んでしまうことです。原文の「算」は兵の数ではありません。勝つための見込み、確かめた条件の数です。

大軍を持っていても、相手の将の力量を知らず、地形を調べず、自軍の賞罰が乱れていれば、算は少ない。小さな軍でも、七つの問いの多くに「こちらが上」と答えられれば、算は多い。孫子が比べているのは兵力そのものではなく、見積もりの厚みです。

結びの「況（いわ）んや」は、「まして〜はなおさらだ」という強調の型です。算が少ない者が勝てないのなら、そもそも数えていない者は論外だ、と言っています。孫子はさらに、自分はこの方法で見れば勝敗が見える、と述べて篇を閉じます。

冒頭の「察せざるべからざるなり」と、この結びは響き合っています。重大だから見極めよ、と始めた篇が、数えない者は勝てない、で終わる。計篇全体が、ひとつの長い「数えよ」になっているのです。

## 構造を図で見る

計篇の論理を、一枚の図にまとめます。

![図1 五事七計 — 五事を勝算を測る五本の軸に、七計を彼我の対面比較表として一枚に収めた見取り図](figures/01-five-factors.svg)

図では、道・天・地・将・法の五事を、勝算を測る五本の軸として並べています。そのうえで、七計の七つの問いを、自軍と敵軍が向かい合う表として置いています。五事が「何を測るか」を決め、七計が「同じ軸で相手と並べる」役を担います。

表の一行ごとに、どちらが上かを書き込んでいきます。「こちらが上」となる行の数が、算です。算が多ければ動き、少なければ動かない。この判断を戦う前に済ませる場が、廟算です。

詭道は、この表の外側から働きます。自分の表は正確に埋め、相手の表には誤った値を書き込ませる。図を見ると、計篇の前半と後半が別々の話ではないことが分かります。前半は自分の表を正しく作る話で、後半は相手の表を狂わせる話です。どちらも、同じ一枚の比較表をめぐっています。

## 異分野への接続

```connect
title: 意思決定分析——見込みを数え、失敗を先に想像する
意思決定分析は、迷ったときの選び方を体系にした分野です。選択肢ごとに起こりうる結果を書き出し、それぞれの起こりやすさ（確率）を見積もります。結果の大きさに確率を掛けて足し合わせたものを期待値と呼び、期待値の大きい選択肢を選ぶのが基本の考え方です。

この分野でよく使われる手法に、プレモーテムがあります。計画を始める前に、全員で「一年後、この計画は大失敗に終わった」と仮定します。そのうえで、なぜ失敗したのかを各自が書き出します。人は計画を立てると楽観に傾き、失敗の筋書きを見落としがちです。先に失敗を想像すると、隠れていた弱点が言葉になります。

計篇と同じ形をしているのは、どちらも取り返しのつかない行動の前に、判断を気分から切り離し、比べられる数に変えるからです。プレモーテムで浮かぶ弱点は、七計の表で「相手が上」となる欄にあたります。それを戦う前に見つけるのが、廟算の役目でした。

違いもあります。意思決定分析は確率という連続した量を扱いますが、七計は「どちらが上か」の判定を積み上げるだけです。また、相手が自分の計算を狂わせにくることは、通常の意思決定分析では前提にしていません。計篇は、その前提を詭道として正面から書き込んでいます。
```

```connect
title: 航空のチェックリスト——重大だから、毎回、同じ軸で見る
旅客機の操縦士は、何千時間も飛んだベテランでも、離陸前に決まった項目を一つずつ声に出して確かめます。燃料、操縦装置、翼の設定、計器と、順番も言い回しも決まっています。この習慣は、1930年代のアメリカで、新型機の試験飛行中の墜落事故をきっかけに広まったと伝えられます。原因は操縦の腕ではなく、多すぎる手順の一つを忘れたことだったとされています。

この話は、計篇の一節とよく重なります。五事は将なら誰でも聞いたことがあるのに、知る者だけが勝つ、という一節です。聞いたことがあるのと、毎回確実に確かめるのとは違います。チェックリストは、知っていることを確実な行動に変える仕組みです。そして一項目でも異常があれば、離陸しません。数えた結果で動くか動かないかを決める、計篇の骨組みと同じです。

同じ形になるのは、結果が重大で、一つの見落としが命取りになる場面では、記憶や勘よりも、決まった軸で毎回点検するほうが確実だからです。

違いは、相手の有無です。離陸前点検は自分の機体の状態を見るだけで、比べる相手はいません。計篇は五事で自分を測ったあと、七計で相手と並べるところまで進みます。
```

## この篇の一行

計篇を一文に縮めると、こうなります。戦う前に、同じ軸で自分と相手を数え、算が多いときにだけ動け。

その数え方の軸が五事であり、相手と並べる表が七計でした。詭道は、相手にこの表を誤って埋めさせる技術です。そして廟算は、表を戦う前に埋め終える場でした。孫子が最初の篇で教えているのは、勝ち方ではなく、勝てるかどうかの確かめ方です。

ただし、表が「勝てる」と告げても、それで終わりではありません。戦いには人も物も時間も要ります。数えた結果、戦うと決めたとして——その戦いはいくらかかるのでしょう。
