# 後編 I 孫子の方法論 — 不確実性を減らす五つの動作

前編で十三篇を順に読んできました。そこに通っていたのは、勝ち方の技巧よりも、分からないことを減らしてから動くという一本の線でした。この章では、その線をいったん戦場から切り離します。孫子を「不確実性に対する方法論」として読み、いくつかの動作に抽象化してみます。

ここで言う不確実性とは、結果を左右するのに、まだ分かっていないことの総量です。新製品の開発でも、店の改装でも、チームで何かを進めるときには必ずこれがあります。孫子は、これを根性や運で埋めようとはしません。数え、備え、配置し、相手を読み、知るための費用を払います。どれも、分からないことを一つずつ減らすための手続きです。

最初に断っておくことがあります。孫子は戦争の書であり、プロジェクト管理の書ではありません。以下では、まず原文が何を言っているかを示し、次に現代でどう読めるかを述べ、最後に原文が言っていないことを明記します。この三段を崩さないことが、古典を現代に置くときの約束です。

## 十三篇を五つの動詞に直す

十三篇を「何をする動作か」で並べ直すと、五つにまとまります。名詞で覚えるより、動詞で覚えた方が手元で使えます。

- 数える：計篇の五事と廟算（びょうさん）。動く前に、彼我の条件を同じ物差しで比べる。
- 負けない形を先に作る：形篇。自分で制御できる守りを、勝ち筋より先に固める。
- 配置とタイミングで力を引き出す：勢篇の勢と節。個人の奮闘ではなく、位置と間合いで成果を出す。
- 相手を動かし、自分は動かされない：虚実篇と軍争篇の迂直。主導権を握り、回り道を近道に変える。
- 知ることに投資する：用間篇と行軍篇の兆候。情報に費用を払い、小さな異変を読む。

この五つを貫く横串が二本あります。一つは九変篇の「変」、つまり定石を状況に応じて外す裁量です。もう一つは火攻篇の「自制」で、利がなければ動かず、怒りで始めないという歯止めです。五つの動作は、一度たどれば終わる手順ではありません。回り続ける循環として読むと腑に落ちます。知ったことが次の計算を変え、計算が先に作るべき形を変えるからです。

この輪は、孫子自身が描いた図ではありません。十三篇の要旨を、私たちが動作に直して並べたものです。篇の順番とも一致しません。用間篇は全書の最後の篇ですが、輪の上では「数える」の直前に来ます。

## 数える、そして負けない形を先に作る

最初の二つの動作は、戦う前の机の上で行われます。

```quote
原文: 多算勝、少算不勝、而況於無算乎。
訓読: 算多きは勝ち、算少なきは勝たず。而るを況んや算無きに於いてをや。
出典: 計篇
訳: 勝算の多い方が勝ち、少ない方は勝てない。まして勝算がまったくなければ、言うまでもない。
```

計篇の結びの一句です。直前で孫子は、開戦前に廟堂（祖先を祀る建物）で行う軍議「廟算」を語ります。そこで勝つと出るのは「算」が多いからだ、と言います。算とは、もとは数を数えるための棒のことで、ここでは勝つための条件の数を指します。五事（道・天・地・将・法）と七つの問いで彼我を比べ、こちらに分がある項目を数えるのです。

原文が言っているのは、算の多い側が勝ち、少ない側は勝てず、無ければなおさらだ、という比較の論理です。現代のプロジェクトに置けば、こう読めます。着手の前に成否を左右する条件を書き出し、自分たちと競合や障害とを同じ物差しで比べる。分がある項目が少なければ、始める前に条件を増やすか、始めないかを決める。

ただし原文は、数値で確率を計算せよとは言っていません。算はあくまで条件の多寡であり、「勝率何割」という言い方は孫子にはありません。また、算が多ければ必ず勝つという保証も述べていません。

```quote
原文: 是故勝兵先勝而後求戰、敗兵先戰而後求勝。
訓読: 是の故に勝兵は先ず勝ちて而る後に戦いを求め、敗兵は先ず戦いて而る後に勝ちを求む。
出典: 形篇
訳: だから勝つ軍は、まず勝てる態勢を整えてから戦いに臨む。負ける軍は、まず戦い始めてから勝ちを探す。
```

形篇の中心の一句です。その前提には「勝つべからざるは己に在り、勝つべきは敵に在り」という切り分けがあります。負けない態勢は自分で作れるが、勝てる隙は相手が生むものだ、という区別です。だから先に自分の側を固め、勝ちはその上で拾いにいきます。「先ず勝ちて」の勝ちとは、戦う前にすでに整っている、負けない態勢のことです。

現代では、こう読めます。新しい試みを始める前に、失敗しても致命傷にならない仕組みを先に作る。元に戻せる手順、予算の上限、撤退の条件を決めてから着手する。勝ち筋を探すのはその後です。

ただし原文は「危険を冒すな」とは言っていません。形篇は攻めも語り、善く攻める者は天の上から動くように動くと述べています。また、形を整えれば勝てるとも言っていません。勝ちを決めるのは相手の隙であり、形はそれを待つための足場です。

```connect
title: ベイズ更新 — 「算」は確信度の数え直し
ベイズ更新とは、ある仮説がどれほど確からしいかという度合いを、新しい証拠が届くたびに計算し直す考え方です。十八世紀の牧師トーマス・ベイズの名にちなみます。最初の見積もり（事前の確信度）に、その証拠が仮説の下でどれほど起こりやすいかを掛け合わせ、新しい見積もり（事後の確信度）を得ます。

廟算とベイズ更新が同じ形なのは、どちらも「動く前の見積もりを、手に入った情報で組み直す」手続きだからです。孫子は五事と七つの問いで彼我を比べ、算の多寡を出します。用間篇の情報が入れば比較の中身が変わる、と読めば、証拠のたびに見積もりが動くという骨格は共通しています。

違いもはっきりしています。ベイズ更新は確信度を数として扱い、更新の規則を数式で定めます。孫子の算は項目の数え上げであり、重み付けや確率の規則は書かれていません。孫子が教えるのは「数えよ、比べよ」という姿勢までで、計算の作法は後世の道具に任されています。
```

## 配置で力を引き出し、相手を動かす

三つめの動作は勢篇から取り出します。勢篇は、形で整えた態勢を、戦場での力に変える方法を説く篇です。勢とは位置と形が生む力で、孫子は丸い石を高い山から転がすことに喩えます。節とはその力を放つ間合いで、引き絞った弩（ど）、つまり機械仕掛けの弓と、引き金を引く一瞬に喩えられます。名将は勝ちを勢に求め、一人ひとりの兵に責めを負わせない、と勢篇は言います。

現代では、こう読めます。成果が出ないとき、個人の頑張りを疑う前に、配置と順番を疑う。誰がどこにいて、どの順で何を渡すかを見直す。準備が溜まった時点で、短い期間に一気に出す。ただし原文は「個人の能力は要らない」とは言っていません。勢篇は、人を択んで勢に任せると続けます。人選を前提に、その上で構造に頼るという順序です。

```quote
原文: 故善戰者、致人而不致於人。
訓読: 故に善く戦う者は、人を致して人に致されず。
出典: 虚実篇
訳: だから戦上手は、敵を思いどおりに動かし、自分が敵に動かされることはない。
```

四つめの動作の核になる句です。直前で孫子は、先に戦場に着いて待つ側は楽をし、後から駆けつける側は疲れると述べます。「致す」とは、相手を自分の望む場所と時に来させることです。虚実篇はここから、自分の形を隠して相手の形を露わにさせれば、こちらは一つにまとまり、相手は分かれる、と論を進めます。軍争篇の「迂を以て直と為す」も同じ系統の考えです。わざと回り道を取り、利で相手を足止めすれば、後から出ても先に着けるからです。

現代では、こう読めます。締め切りや論点を相手に決められると、こちらの準備は常に後手になります。議題を先に出す、比較の基準を先に示す、日程の主導権を握る。そうすれば、相手の動きに振り回される時間が減ります。

ただし原文は、取引先や同僚を欺けとは言っていません。孫子が語るのは戦場の敵であり、職場の協力者ではありません。この句を人間関係の操作術として読むのは、原文の範囲を越えています。

## 知ることに投資する

五つめの動作は、用間篇と行軍篇から取り出します。

```quote
原文: 故明君賢將、所以動而勝人、成功出於衆者、先知也。
訓読: 故に明君賢将の、動きて人に勝ち、成功の衆に出づる所以の者は、先知なればなり。
出典: 用間篇
訳: 賢明な君主や優れた将が、動けば敵に勝ち、人並み外れた成功を収めるのは、前もって敵情を知っているからである。
```

用間篇は十三篇の最後に置かれた、情報の篇です。孫子はその冒頭で、何年も対峙して一日の決戦を争うのに、間諜（かんちょう、敵情を探る者）への報酬を惜しむのは「不仁の至り」だと断じます。戦争全体の費用に比べれば、知るための費用は小さいという論理です。そして先知は、鬼神や占い、過去からの類推、天象の計測からは得られず、必ず人から得る、と続けます。行軍篇の兆候の列挙も、同じ「知る」の動作に属します。鳥が飛び立つのは伏兵がいるからだ、という読み方は、小さな異変から隠れた事情を推す技術です。

現代では、こう読めます。利用者に直接話を聞く、現場を見に行く、小さな異常の報告を拾う。こうした調べものに予算と時間を割くのは贅沢ではなく、本体の費用を下げる投資だ、と。

ただし原文は「数字を集めよ」とは言っていません。孫子が求めるのは人を介して得る敵情であり、計測からは先知は得られないとまで述べています。現代の計測を否定する句ではありませんが、計測を勧める句でもありません。

```connect
title: ウーダ・ループ — 観察から行動までの循環
ウーダ・ループは、アメリカ空軍の戦闘機乗りジョン・ボイドが唱えた意思決定の型です。観察・状況判断・意思決定・行動の四段を指し、英語の頭文字を並べて「ウーダ」と呼びます。行動の結果をまた観察し、四段を回し続けます。相手より速く回せば、相手は古い状況に対応し続けることになる、というのが要点です。

用間篇から計篇、勢篇へと続く並びとこの循環が同じ形なのは、どちらも「知る、見積もる、配置して動く、その結果をまた知る」を一つの輪として扱うからです。先知が観察に、廟算が状況判断と意思決定に、勢と節が行動に当たります。虚実篇の「人を致す」は、相手の輪を自分の輪に遅れさせることと読めます。

違いは、重みの置き方にあります。ボイドは回す速さと、状況判断の段で古い思い込みを壊すことを重んじました。孫子は回す速さよりも、動く前の算の厚さと、情報に払う費用を語ります。また、孫子は自分の方法を輪として描いてはいません。
```

## 横串の二本 — 変と自制

五つの動作は、それだけでは型にすぎません。型を現場で生かすための横串が二本あります。

一本目は九変篇の「変」です。九変篇は、通ってはならない道、撃ってはならない軍、攻めてはならない城があり、君命でさえ受けないことがあると述べます。原則には例外があり、それを見分けるのが現場の将の仕事だという主張です。現代では、手順書を守りつつ、手順書が想定していない状況では担当者が判断できる余地を残す、と読めます。ただし原文は、上の者の指示一般に逆らってよいとは言っていません。君命を受けない場面は、戦場の利害を見たうえでの例外として語られています。

二本目は火攻篇の「自制」です。火攻篇の後半は、利がなければ動かず、得るものがなければ兵を用いず、危急でなければ戦わない、と述べます。君主は怒りで軍を興してはならず、将は憤りで戦ってはならない。怒りは喜びに戻るが、滅んだ国と死者は戻らないからです。現代では、取り返しのつかない決定ほど、感情の熱が冷めてから下す、と読めます。ただし原文が語るのは国家の開戦の判断であり、日々の小さな決定をすべて慎重にせよという教えではありません。

二本の横串は、引っ張り合う関係にあります。変は動く方向へ、自制は止まる方向へ働きます。作戦篇の「拙速」の観察は、その間に立っています。

```note
「兵は拙速を貴ぶ」は後世の成語です。作戦篇の原文は「兵は拙速を聞くも、未だ巧の久しきを睹ざるなり」で、まずくても速く切り上げた例は聞くが、巧みに長引かせて成功した例は見ない、という観察です。「雑でもよいから速く」という一般論ではありません。
```

```connect
title: リーンの仮説検証 — 小さく速く試す
リーンとは、もとは製造業で無駄を省く考え方で、のちに新しい事業の進め方に応用されました。後者では、作るものを仮説とみなし、最小限の試作で市場に問い、結果から学んで次を決めます。作る、測る、学ぶの輪を短く回すことが要点です。

作戦篇の観察と同じ形なのは、どちらも「長引くこと自体が費用を生む」という前提から、短く切り上げることを選ぶからです。作戦篇は、長期戦が兵を鈍らせ、国の財政を尽きさせると述べます。リーンも、検証されない仮説に時間と資金を注ぎ続けることを、最大の無駄とみます。

違いは、何のために速くするかです。リーンの速さは学ぶための速さで、失敗も情報として歓迎します。孫子の拙速は戦争を終わらせるための速さで、失敗を歓迎する発想はありません。火攻篇の言うとおり、亡国は戻らないからです。小さく試してよいのは、取り返しのつく領域に限られます。
```

## 輪を回し続ける

ここまでの五つの動作を、もう一度輪として眺めます。知ることで算が変わり、算が変われば先に作るべき形が変わります。形が整えば、勢の配置と節の間合いが決まり、相手を動かす余地が生まれます。動いた結果は、また知るべきことを生みます。その輪の外側で、変が型を緩め、自制が輪の暴走を止めます。

この読み方の効用は、孫子の言葉を個別の格言としてではなく、一連の手続きとして使えることにあります。「彼を知り己を知る」も「戦わずして勝つ」も、輪のどこかに位置を持ちます。どこに置くかが分かれば、いまのプロジェクトでどの動作が欠けているかを問えます。

同時に、限界も確かめておきます。孫子は自分の方法を五つに分けてはいませんし、輪として描いてもいません。この章の五つは、十三篇を読んだ私たちの整理です。次の章からは、この整理が実際の場面でどこまで使えるかを、一つずつ確かめていきます。最初の動作、『数える』をプロジェクトに置きます。
