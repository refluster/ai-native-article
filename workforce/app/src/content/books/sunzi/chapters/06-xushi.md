# 虚実篇 — 動かし、動かされない

## 主導権という問い

相手の動きを決める側に立つとは、具体的に何をすることなのでしょうか。虚実篇は、この問いにまっすぐ答える篇です。

身近な場面から考えてみます。初めて行く店で、知人と待ち合わせをするとします。先に着いた側は、席を選び、店の様子を眺め、息を整えてから相手を迎えられます。遅れた側は道に迷い、走り、汗をかいたまま席につきます。同じ一時間でも、どちらが話を運びやすいかは明らかです。

この差を生んでいるのは、能力の差ではありません。時間と場所を、どちらが先に押さえたかの差です。本章ではこの差を「主導権」と呼びます。主導権とは、いつ、どこで、どんな形でぶつかるかを決める立場のことです。

主導権を持たない側は、相手の決めた予定に合わせて動き続けることになります。急ぎ、迷い、疲れ、そのたびに判断の余裕を失います。一つひとつは小さな不利でも、積み重なれば勝敗を左右します。逆に主導権を持つ側は、自分の準備が整った時にだけぶつかればよいのです。

虚実篇は、この主導権を兵力の使い方と結びつけます。篇名の「虚」と「実」は、それぞれ手薄な所と充実した所を指します。自分の力を相手の実ではなく虚へ向けること。そのために、相手には形を見せさせ、自分は形を見せないこと。篇はこの二つを、最後には水の比喩でまとめ上げます。

## 原文を読む

篇は、待ち合わせとよく似た観察から始まります。「凡そ先に戦地に処りて敵を待つ者は佚し、後れて戦地に処りて戦いに趨く者は労す」。佚（いつ）は、楽でゆとりがあることです。先に戦場に着いて待つ側は楽で、後から駆けつけて戦う側は疲れる、という意味です。この観察から、篇全体を貫く原則が引き出されます。

```quote
原文: 故善戰者、致人而不致於人。
訓読: 故に善く戦う者は、人を致して人に致されず。
出典: 虚実篇
訳: だから戦上手は、敵を思いどおりに動かし、自分が敵に動かされることはない。
```

「致（いた）す」は、来させる、呼び寄せるという意味の字です。人を致すとは、相手を自分の選んだ場所と時に来させることです。人に致されずとは、相手の選んだ場所と時に引き出されないことです。つまりこの一文は、戦いの段取りをどちらが書くかを問題にしています。

直後で孫子は、その方法を述べます。敵が自分から来るのは、来れば得があると思わせるからです。敵が来られないのは、来れば損があると思わせるからです。だから敵が楽をしていれば疲れさせ、満ち足りていれば飢えさせ、落ち着いていれば動かす、と続きます。

ここで大事なのは、相手を力ずくで引きずるのではない点です。相手の損得の見積もりに働きかけ、相手が自分の判断で動くように仕向けます。動かされた側は、自分で決めたつもりでいます。主導権とは腕力の問題ではなく、相手の判断の材料を誰が用意するかの問題だと読めます。

では、主導権を持つ側はどこを攻めるのでしょうか。篇は「其の趨かざる所に出で、其の意わざる所に趨く」と続けます。敵が駆けつけられない所に出て、敵が思ってもいない所へ向かう、という意味です。さらに「攻めて必ず取る者は、其の守らざる所を攻むればなり」と述べ、守りについても「其の攻めざる所を守ればなり」と対にします。

攻めが確実になる理由は、自軍の強さではありません。相手がそこにいないことです。ただし「守らざる所」は、相手が気づいた瞬間に「守る所」へ変わります。だから本当に必要なのは、どこを攻めるかを相手に読ませないことです。この対句を、攻守の両面から言い直したのが次の一節です。

```quote
原文: 故善攻者、敵不知其所守。善守者、敵不知其所攻。
訓読: 故に善く攻むる者には、敵其の守る所を知らず。善く守る者には、敵其の攻むる所を知らず。
出典: 虚実篇
訳: 攻めの上手な者が相手だと、敵はどこを守ればよいかわからない。守りの上手な者が相手だと、敵はどこを攻めればよいかわからない。
```

この一節は、攻めと守りを同じ物差しで測っています。上手な攻め手が相手だと、敵は守る場所を決められません。上手な守り手が相手だと、敵は攻める場所を決められません。攻めと守りは別の技術に見えますが、どちらも「読ませない」という一点に立っています。

篇はこのあと「微なるかな微なるかな、無形に至る。神なるかな神なるかな、無声に至る」と続けます。微（び）は、かすかで捉えにくいことです。形も音も相手に届かなくなったとき、敵の命運を握る者になれる、と篇は言います。ここで「無形」という語が初めて現れ、次の一節の土台になります。

```quote
原文: 故形人而我無形、則我專而敵分。
訓読: 故に人を形せしめて我は無形なれば、則ち我は専らにして敵は分かる。
出典: 虚実篇
訳: 敵には態勢をさらけ出させ、自分は態勢を見せなければ、自軍は一つに集中でき、敵は分散する。
```

「形」は本書で何度も出てくる語です。ここでは、軍の配置や構えのうち、外から見える姿を指します。人を形せしむとは、相手に構えを表に出させることです。こちらは構えを見せません。すると、両者のあいだに情報の差が生まれます。

その差が兵力の差に化ける仕組みを、篇は算術で示します。「我は専らにして一と為り、敵は分かれて十と為れば、是れ十を以て其の一を攻むるなり」。こちらは一か所にまとまり、相手は十か所に分かれます。総兵力が同じでも、ぶつかる一点では十対一になります。

数字で確かめてみます。両軍が同じ数の兵を持っているとします。相手が十か所に均等に分かれれば、一か所あたりの兵は全体の十分の一です。こちらが全軍で一か所を突けば、その場の兵力比は十対一になります。相手が残りの九か所から助けに来ようとしても、どこが狙われるかを知らなければ間に合いません。篇が戦う地と日を知られないことを重く見るのは、このためです。

なぜ相手は分かれるのでしょうか。こちらの狙いがわからないので、あらゆる方向に備えるしかないからです。篇は「前に備うれば則ち後寡く、後に備うれば則ち前寡し」と左右前後を並べ、「備えざる所無ければ、則ち寡ならざる所無し」と結びます。寡（すくな）しは、兵が少ないことです。すべてを守ろうとすれば、すべてが薄くなります。

この観察から、篇は大胆な結論を出します。「勝は為すべきなり」。勝ちは作り出せる、という意味です。兵の数で負けていても、相手を分散させれば戦わせずに済む、とまで述べます。

篇の後半は、ここまでの話を一つの比喩にまとめます。

```quote
原文: 夫兵形象水、水之形、避高而趨下。兵之形、避實而擊虚。
訓読: 夫れ兵の形は水に象る。水の形は高きを避けて下きに趨き、兵の形は実を避けて虚を撃つ。
出典: 虚実篇
訳: 軍の形は水に似ている。水が高い所を避けて低い所へ流れるように、軍は敵の充実した所を避けて手薄な所を撃つ。
```

象（かたど）るは、似せる、なぞらえるという意味です。ここで初めて、篇名の二字が対になって現れます。実は兵が厚く備えのある所、虚は備えの薄い所です。水が坂を登らないように、軍も厚い所へ正面からぶつからない、という主張です。

この比喩の要点は、力の向きを決めるのが自分ではなく地形だという点にあります。篇は続けて「水は地に因りて流れを制し、兵は敵に因りて勝ちを制す」と言います。水の流れ道は土地の高低が決め、軍の勝ち筋は敵の配置が決める、ということです。水は低い所を探して迷うことがありません。軍に求められているのも、自分の得意な形を押し通すことではなく、相手のどこが低いかを正しく読み取ることです。

ただし、ここまで読んできた私たちには、もう一つ見えるものがあります。虚は、たまたまそこにあるとは限りません。相手を動かし、構えを見せさせ、分散させた結果として作られる虚もあります。篇の前半はその作り方を、後半はその使い方を述べていると整理できます。

```quote
原文: 故兵無常勢、水無常形、能因敵變化而取勝者、謂之神。
訓読: 故に兵に常勢無く、水に常形無し。能く敵に因りて変化して勝を取る者、之を神と謂う。
出典: 虚実篇
訳: だから軍には決まった勢いがなく、水には決まった形がない。敵に応じて変化して勝利をつかめる者を、神業の持ち主という。
```

常勢（じょうせい）は決まった勢い、常形（じょうけい）は決まった形です。水は器が丸ければ丸く、四角ければ四角くなります。軍も同じように、相手の形に合わせて自分の形を変えます。そうして勝ちを取る者を、篇は「神」と呼びます。人間わざを超えたように見える見事さ、という意味です。

篇はこのあと、五行に常に勝つものはなく、四季に定まった位置はない、と自然の例を重ねて終わります。日は長くも短くもなり、月は満ちも欠けもします。変わり続けることのほうが自然の常態だ、という含みがあります。

前の篇で見た勢も、この一節で位置づけ直されます。勢は作るものですが、一度作った勢いを固定すれば、それは相手に読まれる型になります。勢篇の勢いを、虚実篇は「常勢無し」で動かし続けるのです。

水の比喩の少し前に、篇はこの考えを別の言葉で言い切っています。「故に兵を形するの極みは、無形に至る」。無形なら、深く入り込んだ間者も中を窺えず、知恵のある者も策を立てられない、と続きます。そして、人はみな勝った後の形は知っていても、その勝ちを作った形は知らない、と述べたうえで、こう結びます。

```quote
原文: 故其戰勝不復、而應形於無窮。
訓読: 故に其の戦い勝つや復びせずして、形に無窮に応ず。
出典: 虚実篇
訳: だから勝ち方を二度と繰り返さず、相手の態勢に合わせて限りなく形を変えて応じる。
```

勝った後の形は、誰の目にも見えます。どこに兵を置き、どこを突いたかは、結果として残るからです。しかし、その配置を選ばせた仕組み、つまり相手のどこが虚でなぜそうなったかの読みは、外からは見えません。

同じ勝ち方を繰り返すと何が起きるでしょうか。見えている形から、見えない仕組みを逆算されます。逆算されれば、こちらの形は相手に読まれる形になり、主導権は相手へ移ります。だから勝ち方は繰り返さない、と篇は言います。

「形に無窮に応ず」の無窮（むきゅう）は、終わりがないことです。勝ち方の引き出しを無限に用意せよ、という意味ではありません。相手の形が毎回違う以上、こちらの応じ方も毎回違ってくる、という意味です。水が器ごとに形を変えるのと同じ理屈です。

ここで、篇の冒頭と結びが一本の線でつながります。主導権は、先に着き、相手を動かすことで手に入りました。しかし、同じ形で勝ち続ければ、相手はやがてこちらの次の一手を先に読み、先回りして待つようになります。そのとき先に着いているのは相手です。勝ち方を繰り返さないことは、握った主導権を手放さないための条件なのです。

## 構造を図で見る

虚実篇の論理は、三つの段で整理できます。第一の段は主導権です。先に着き、相手の損得に働きかけ、相手を自分の選んだ場所と時に来させます。第二の段は情報の非対称です。相手には構えを見せさせ、自分は見せません。第三の段は兵力の配分です。読めない相手に対し、相手は全方位に備えて分散し、こちらは一点に集中します。

![図8 実を避け虚を撃つ — 一つにまとまった力が、分散した相手の備えの薄い一点へ、水のように流れ込む](figures/06-void-solid.svg)

図では、こちらの集中した力を一本の流れとして、相手の備えをいくつにも分かれた区画として描いています。備えの厚い所は高い所、薄い所は低い所として表し、流れは低い所へ向かいます。こうして見ると、虚は相手の側に最初からあるのではなく、第一と第二の段が相手に作らせたものだとわかります。

ただし、この図は一回の戦いを切り取った一枚にすぎません。相手の備えが変われば、低い所の位置も変わり、流れの道筋も引き直されます。図の形をそのまま覚えて次に使えば、それは「勝ち方を繰り返す」ことになります。図は答えではなく、毎回描き直す手順の見本として読んでください。

## 異分野への接続

```connect
title: 流体 — 水は抵抗の少ない道を見つける
水を高い所から流すと、水は低い所へ向かいます。地面に高低があれば、水は自然に溝を探し当て、そこを通って流れます。流れを決めているのは水の意志ではなく、高さの差、つまり圧力の差です。

配管の世界でも同じことが起きます。枝分かれした管に水を流すと、通りやすい管ほど多くの水が流れ、抵抗の大きい管には少ししか流れません。流れは、抵抗の少ない経路へ多く向かう性質を持っています。

なぜ兵の話と同じ形なのか。どちらも、限られた量の流れが、抵抗の大小に応じて行き先を決めるしくみだからです。高い所は実、低い所は虚に当たり、流れは虚へ向かうほど少ない力で遠くまで届きます。

違いも一つあります。水は地形を変えられませんが、軍は相手を動かして、低い所を自分で作り出せます。虚実篇の前半が述べていたのは、まさにこの「低い所の作り方」でした。
```

```connect
title: 情報セキュリティ — 攻撃面と守りの分散
情報セキュリティには「攻撃面」という考え方があります。攻撃面とは、外部から侵入を試みられる入口の総体のことです。公開している窓口、使っている部品、従業員の受信箱など、入口になりうるものすべてが含まれます。

守る側は、この入口すべてに備えなければなりません。一方、攻める側は、どれか一つを破れば目的を果たせます。守りの予算や人手には限りがあるので、入口が増えるほど一つあたりの備えは薄くなります。攻める側は、その中から最も薄い所を選んで力を集めます。

なぜ同じ形なのか。どちらも、限られた守りの資源を多くの地点に割り振る側と、地点を選んで集中できる側の対決だからです。虚実篇の「備えざる所無ければ、則ち寡ならざる所無し」は、この構図をそのまま言い当てています。

違いを一言添えると、守る側には別の手もあります。入口そのものを減らして攻撃面を縮めることです。守る範囲を狭めれば、同じ資源でも一か所あたりの備えは厚くなります。分散を強いられる側が取れる、数少ない反撃の手だといえます。
```

## 誤解されやすい点

```note
「勝は為すべきなり」は、形篇の「勝は知るべくして、為すべからず」と矛盾して見えますが、形篇の章で見たとおり、前提が違うので両立して読めます。なお、他本の一つは「勝は擅（ほしいまま）にすべし」と作ります。
```

```note
虚実の「虚」は「空っぽ」という意味ではありません。兵が一人もいない所ではなく、こちらがぶつける力に比べて備えが薄い所を指します。実と虚は絶対量ではなく、相手との比で決まる言葉です。
```

## この篇の一行

虚実篇を一文に縮めると、こうなります。相手には形を見せさせ、自分は形を見せずに、一つにまとめた力を相手の備えの薄い所へ流し込み、勝ち方は毎回作り直せ。前の篇で作った勢は、この篇で向かう先を得ました。石を転がす坂の向きを、相手の虚に合わせて選べるようになったのです。

主導権とは、力の強さではなく、相手の判断の材料と、ぶつかる場所と時を、こちらが用意できる立場のことでした。そしてその立場は、一度握れば終わりではなく、形を変え続けることでしか守れません。

ただ、ここまでの議論はまだ地図の上の話です。どこに虚があり、どう集中すればよいかがわかっても、実際に兵を動かせば時間がかかり、道は険しく、相手も動きます。では、握った主導権を保ったまま、実際に軍を動かすにはどうすればよいのでしょうか。
