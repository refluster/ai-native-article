## この本の読み方

『孫子』は、戦いの技術書である前に、不確実なものを前にして判断するための書物である。本書では各篇を「原文 → 訓読 → 現代語訳 → 接続」の順で読む。原文は引用カードに収め、訓読と訳を添える。

各章の冒頭には一つ、その篇を代表する一節を置く。読み飛ばしてもかまわないが、原文の短さそのものが、この古典の性格をよく表している。

```quote
原文: 兵者、國之大事、死生之地、存亡之道、不可不察也。
訓読: 兵は国の大事にして、死生の地、存亡の道なり。察せざるべからず。
出典: 始計篇
訳: 戦争は国家の重大事であり、生死と存亡を分ける道である。よくよく考えねばならない。
```

## 三つの約束

本書は次の三つを約束する。

1. 原文を省略しない。引用は必ず出典の篇名を添える。
2. 解釈が分かれる箇所は、分かれていると書く。
3. 「異分野への接続」は、比喩ではなく構造の対応として書く。

```connect
title: 品質工学の「事前に数える」
製造の現場では、量産の前に**ばらつきの源**を数え上げる。孫子の「計」も同じく、戦う前に勝敗を左右する要因を列挙し、比べる作業である。

- 要因を列挙する
- 自他を同じ物差しで比べる
- 比べた結果で、戦うかどうかを決める
```

## 用語について

本書では「兵」を文脈により「戦争」「軍隊」「用兵」と訳し分ける。原文の一字が、現代語では三つ以上の語に割れることがある。そのたびに注を付ける。

```note
「兵は拙速を貴ぶ」は後世の成語。原文は「兵聞拙速、未睹巧之久也」（作戦篇）。
```

## このリーダーの使い方（仮原稿）

ここから先の段落は、リーダーの組版と読書位置の保存を確かめるための仮の文章である。正式な原稿では、この節は差し替えられる。

画面の上には細い帯がある。左の矢印で表紙に戻り、右の「目次」で章の一覧を開き、「Aa」で文字の大きさ、紙の色、書体を変えられる。下へ読み進めると帯は引っ込み、少しでも上へ戻ると帯はまた現れる。帯が隠れていても、画面のいちばん上の細い線が、いまこの章のどのあたりを読んでいるかを示している。

読んだ位置は、この端末のブラウザにだけ保存される。昨日の続きから読みたいときは、表紙の「続きから読む」を押せばよい。読みかけの章の、読みかけの見出しのあたりへ戻る。文字の大きさを変えたあとでも、見出しを手がかりにして、おおよその位置に戻るように作ってある。

章の終わりまで読むと、その章は読了として印が付く。目次の右端の小さな丸がその印である。空の丸は未読、半分塗った丸は読みかけ、塗りつぶした丸は読了を表す。印は読み返しても消えない。いちど最後まで読んだ章は、上へ戻って読み直しても読了のままである。

キーボードがあるなら、左右の矢印キーで前後の章へ移れる。電車の中で片手で読むときは、章の終わりにある「次の章」のカードを押せばよい。目次は、電話では画面の左から引き出され、広い画面では本文の左に並んで開いたままにできる。

夜に読むときは「夜」の配色を選ぶとよい。紙の色を落とし、文字を少し暗くして、図の線や文字も同じ配色に従う。図は本文と同じ色の約束で描かれているので、配色を変えても読める。

一行の長さは、文庫本の一行に近い三十八字ほどにしてある。長い時間読んでも目が疲れにくい長さである。行間も広めにとってある。ゴシック体のほうが読みやすい人は、書体を切り替えられる。

## 本書の構成（仮原稿）

本書は三つの部分からなる。前編では十三篇の原文を一篇ずつ読む。各章は、その篇の要点となる一節の引用から始まり、訓読と現代語訳を添えて、語句の意味と篇全体の流れを追う。原文の解釈が分かれる箇所では、どの読みを採ったかと、その理由を書く。

中編では、篇をまたいで現れる考え方を取り出して並べる。たとえば「数える」「欺く」「速さ」「地形」といった主題ごとに、どの篇のどの一節がそれに触れているかを示し、互いの関係を図にする。前編を読み終えていなくても、関心のある主題から読み始められるようにしてある。

後編では、異分野への接続をまとめて扱う。経営の意思決定、ソフトウェアの設計、研究計画の立て方、品質管理、交渉など、孫子の構造がそのまま当てはまる場面と、当てはめると誤る場面の両方を書く。古典を現代に持ち込むときの落とし穴も、ここで正面から扱う。

巻末には、本文で引いた原文を篇の順にまとめた付録を置く。読み返したい一節を探すときは、付録から本文の該当章へ戻れる。

どの部から読んでもかまわない。ただ、前編の第一篇だけは先に読んでおくと、後の章で繰り返し出てくる「数える」という言葉の意味がつかみやすい。一章はおよそ十分から十五分で読める長さにしてある。通勤の行き帰りに一章ずつ読めば、二週間ほどで全体を読み終えられる。急ぐ必要はない。
