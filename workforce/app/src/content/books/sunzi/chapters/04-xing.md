# 形篇 — 勝ってから戦う

## 試験会場に入る前に

戦う前に勝ちが決まっている、と聞くと、手品のように聞こえるかもしれません。けれども私たちは、その状態をよく知っています。たとえば入学試験です。会場の席に着いた時点で、結果の大部分はもう決まっています。基礎問題を落とさない力があるか。時間配分の練習をしてきたか。体調を整えてきたか。これらはすべて、試験が始まる前に積み上がっているものです。

一方で、試験当日にどんな問題が出るか、ほかの受験者がどれだけできるかは、本人には決められません。得意な分野が出るかどうかは運に近く、合格点も他人の出来で動きます。準備の行き届いた受験者は、この二つを混ぜません。自分で決められる部分、つまり「取りこぼさない力」を先に固めます。そして決められない部分、つまり問題との相性は、来たときに逃さず拾う構えでいます。

形篇は、この区別を戦争について突き詰めた篇です。篇の名の「形（けい）」は、ここでは軍の態勢、つまり開戦前に整えておく布陣と力の配置を指します。孫子はこの篇で、勝敗の大部分は戦場ではなく、その前の準備の段階で決まると論じます。戦いの最中の駆け引きや勢いは、次の勢篇以降の主題です。形篇が見ているのは、その手前、静かに整えられる土台のほうです。

では、負けない態勢は、どうやって作るのか。篇の言葉を順に読んでいくと、その答えは三つの動作にまとまります。自分にできることと、できないことを分ける。分けたうえで、できることをやり尽くす。最後に、やり尽くした結果を測り、敵と比べる。この章では、この三つを原文に沿ってたどります。

## 原文を読む — 負けない形、勝てる隙

```quote
原文: 昔之善戰者、先為不可勝、以待敵之可勝。
訓読: 昔の善（よ）く戦う者は、先ず勝つべからざるを為して、以て敵の勝つべきを待つ。
出典: 形篇
訳: 昔の戦上手は、まず自軍を、敵が勝てない態勢に整えた。そのうえで、敵に勝てる隙が生じるのを待った。
```

形篇の冒頭の一文です。ここには二つの「勝」が出てきます。一つ目の「不可勝（勝つべからず）」は、敵の側から見て勝てない状態、つまり自軍が負けない状態を指します。二つ目の「敵之可勝（敵の勝つべき）」は、こちらから見て敵に勝てる状態、つまり敵の隙を指します。

注目したいのは順序です。「先ず」負けない態勢を作り、そのあとで「待つ」。孫子は、勝ちに行く前に負けを消せ、と言っています。勝ちを取りに行く動きは、しばしば自分の守りを薄くします。だから順序を逆にすると、隙を作るのは自分のほうになります。

もう一つ大事なのは「待つ」という動詞です。これは何もしないことではありません。負けない態勢を保ったまま、相手が崩れる瞬間を見張り続けることです。少し先で孫子は、善く戦う者は「敵の敗を失わず」、つまり敵が崩れる機会を逃さない、とも書いています。守りを固めることと、好機に即応することは、同じ構えの表と裏なのです。

```quote
原文: 不可勝在己、可勝在敵。
訓読: 勝つべからざるは己（おのれ）に在り、勝つべきは敵に在り。
出典: 形篇
訳: 負けない態勢をつくれるかは自分次第だが、勝てるかどうかは敵次第である。
```

前の一文の理由を、孫子はこう説明します。負けない態勢は自分の手の中にある。勝てる隙は敵の手の中にある。短い対句ですが、ここに形篇の考え方の土台があります。

組織の成果を研究する立場から見ると、この一文は「制御できる変数」と「制御できない変数」の区別そのものです。自軍の訓練、補給、布陣は、自分で決められます。敵の油断や判断ミスは、どれだけ望んでも自分では決められません。成果が伸び悩む組織は、この二つを混同しがちです。相手の出方に期待した計画を立て、外れると「運が悪かった」と総括してしまいます。

孫子は、自分の側の仕事を「不可勝」に限定します。勝ちそのものを自分の仕事の目標にはしていません。これは消極的に見えますが、実は責任の範囲をはっきりさせる考え方です。自分の手の中にあるものは、言い訳なくやり尽くす。手の外にあるものは、観察の対象にする。この線引きが、次の一文につながります。

```quote
原文: 故曰、勝可知、而不可為
訓読: 故に曰く、勝は知るべくして、為（な）すべからず。
出典: 形篇
訳: だから、勝てるかどうかは見通すことができても、勝ちを無理につくり出すことはできない。
```

「知る」と「為す」の対比です。勝ちは見通せる。けれども、意志の力で作り出すことはできない。前の二文から自然に導かれる結論で、孫子も「故に（だから）」でつないでいます。

ここで言う「知る」は、占いのような予言ではありません。自軍の態勢と敵の態勢を見比べれば、勝てる見込みがあるかどうかは分かる、という意味です。計篇で見た「数える」作業の延長にあります。一方、「為す」は、相手に隙がないのに力ずくで勝ちを奪いにいくことです。それはできない、と孫子は言い切ります。

この一文は、のちの虚実篇の「勝は為すべきなり」と矛盾して見えることで知られています。けれども文脈が違います。形篇は、敵が隙を見せない限り勝ちは作れない、という話です。虚実篇は、主導権を握って敵を分散させれば隙を作れる、という話です。形篇は土台を、虚実篇はその上での働きかけを語っている、と読めば両立します。

```quote
原文: 善守者、藏於九地之下
訓読: 善く守る者は、九地（きゅうち）の下に蔵（かく）る。
出典: 形篇
訳: 守りの上手な者は、大地の奥深くに隠れるように、自軍の態勢をまったく見せない。
```

ここから話は守りと攻めに移ります。直前で孫子は、負けない態勢とは守りのこと、勝てる状態とは攻めのことだ、と整理しています。守るのは力が足りないとき、攻めるのは力が余るときだ、とも述べます。

「九地」は、地の最も深いところを指す比喩です。九は数の極みで、九地は「これ以上はない深さ」を表します。後の九地篇に出てくる九種類の土地とは別の言葉なので、混同しないようにしましょう。

守りの要は、壁の厚さだけではありません。相手に攻撃の手がかりを与えないこと、つまり見えないことです。どこが弱いかが外から分からなければ、敵は狙いを定められません。負けない態勢とは、強いだけでなく、読まれない態勢でもあるのです。

```note
守りと攻めを論じた句には、テキストの異同があるとされます。通行本では「守るのは足りないとき、攻めるのは余るとき」と読めます。ところが、1972年に山東省の銀雀山（ぎんじゃくざん）の漢代の墓から竹簡本が出土しました。そこでは、足りる・余るの位置が入れ替わっている、と報告されています。どちらが古い形か、意味をどう取るかには諸説あります。本書は底本の読みに従います。
```

```quote
原文: 善攻者、動於九天之上、故能自保而全勝也。
訓読: 善く攻むる者は、九天（きゅうてん）の上に動く。故に能く自ら保ちて勝を全（まっと）うするなり。
出典: 形篇
訳: 攻めの上手な者は、天の最も高いところから襲いかかるように動く。だから自軍を保ったまま、完全な勝利を得られる。
```

守りの「九地」と対になるのが、攻めの「九天」です。地の底に隠れる守りに対して、攻めは天の高みから来ます。相手が見上げても届かない高さ、対応する暇のない速さで動く、という比喩です。

大切なのは文の後半です。「自ら保ちて勝を全うす」。自分を保ったまま、勝ちを完全なものにする。孫子にとって良い勝ちとは、ただ勝つことではありません。自軍を損なわずに勝つことです。謀攻篇の「全」の思想が、ここでも顔を出しています。

守りと攻めは、別々の技術として並べられているのではありません。深く隠れて負けを消し、高く動いて損なわずに勝つ。その二つがそろって、はじめて「全勝」になります。地の底と天の上という両極の比喩は、その振れ幅の大きさを伝えています。

```quote
原文: 是故勝兵先勝而後求戰、敗兵先戰而後求勝。
訓読: 是の故に勝兵は先ず勝ちて而（しか）る後（のち）に戦いを求め、敗兵は先ず戦いて而る後に勝ちを求む。
出典: 形篇
訳: だから勝つ軍は、まず勝てる態勢を整えてから戦いに臨む。負ける軍は、まず戦い始めてから勝ちを探す。
```

形篇で最もよく知られた一文で、この章の副題もここから取っています。勝つ軍と負ける軍の違いは、戦場での勇敢さではなく、順序にある、という主張です。

この一文の直前で、孫子は目立たない勝ちを称えています。誰の目にも明らかな勝ちを見抜くのは、名将の技ではない。本当に戦上手な者の勝ちは、当然の結果に見えるので、知恵の名声も勇気の手柄も残らない。そういう趣旨です。つまり「先に勝つ」とは、戦う前に差をつけすぎて、戦いそのものが確認作業になることを指します。

負ける軍は逆です。とりあえず戦いを始め、戦いの中で勝ち筋を探します。うまくいけば劇的な逆転として語られるでしょう。けれども孫子の目から見れば、それは準備の不足を現場の運で埋めようとした結果にすぎません。

組織の仕事にも、同じ二つの型が見られます。見込みの検証より先に着手の日付が決まり、走りながら勝ち筋を探す計画。そして、着手の前に必要な人と資源を測り、足りなければ始めない計画です。前者は、途中で問題が出るたびに現場の頑張りが求められます。後者は地味で、始まってからの見せ場もありません。孫子が「勝兵」と呼ぶのは、後者の側です。

では、戦う前に「勝っている」かどうかは、どうやって確かめるのでしょうか。孫子はこの問いに、測定の手順で答えます。

## 測って、比べて、落とす

篇の終わりで、孫子は兵法の五つの段階を挙げます。度、量、数、称、勝です。一般には次のように読まれています。度は土地の広さを測ること。量はその土地から得られる物資の量。数は養える兵の数。称は自軍と敵軍を天秤にかけて比べること。勝は、その比較から見える勝敗です。

孫子は、これらが順に生まれると書きます。地が度を生み、度が量を生み、量が数を生み、数が称を生み、称が勝を生む。勝ちは最後に出てくる結果であって、最初に置く目標ではありません。地面を測ることから始まる地道な連鎖の、いちばん下流にあるのです。

続けて孫子は、天秤の比喩を使います。勝つ軍は、重い分銅で軽い分銅を量るようなものだ、と。ここで使われる「鎰（いつ）」と「銖（しゅ）」は古代の重さの単位で、鎰は銖の数百倍にあたるとされます。勝つ軍と負ける軍の差は、五分五分の接戦ではなく、それほどの開きだということです。

ここで見落としやすいのは、四番目の「称」です。自軍の数を数えるだけでは、勝ちは見えません。同じ物差しで敵も測り、並べて比べたときにはじめて、差が分かります。自分の強さだけを誇る軍は、測定はしていても比較をしていないのです。形篇の連鎖は、自分を知り、相手を知るという謀攻篇の教えを、手順の形に置き直したものとも読めます。

そして篇は、こう結ばれます。勝つ者の戦いは、せき止めて溜めた水を、千仞（せんじん）の深い谷へ一気に切って落とすようなものだ。それが形である、と。仞は高さの単位で、千仞は「とてつもなく高い」の意味です。

ここで「形」の正体がはっきりします。形とは、溜めた水と谷底との落差です。水を溜めるのは、度から称までの地道な積み重ねです。谷の深さは、彼我の差の大きさです。落差が十分なら、水門を開けたあとの結果は、もう決まっています。

![図4 先勝の天秤 — 度・量・数・称の連鎖が天秤を傾け、溜めた水と谷底の落差が「形」になる](figures/04-balance.svg)

図4は、この篇の論理を一枚にしたものです。左から右へ、度・量・数・称の段階が順に生まれ、最後に天秤が大きく傾きます。その傾きが、右端で積水の落差として描かれています。図の要点は、勝ちが連鎖の最後にしか現れないことです。途中のどこかの測定を飛ばせば、天秤の傾きは見えなくなります。逆に言えば、勝てるかどうかを「知る」ことができるのは、この連鎖を最後までたどった者だけです。冒頭の「勝は知るべくして為すべからず」は、この手順によって裏づけられているのです。

## 異分野への接続 — 余裕と積み重ね

```connect
title: 安全工学の「安全余裕」と冗長性
**壊れないように作ってから使う**という点で、安全工学と形篇は同じ形をしています。どちらも、相手の出方が読めない部分を、自分で決められる余裕によって先に吸収しておく考え方だからです。

橋や建物を設計するとき、技術者は想定される最大の荷重ぴったりには作りません。想定の何倍かの荷重に耐えるように作ります。この倍率を安全率と呼び、想定と実際の耐力の差を安全余裕と呼びます。材料のばらつきや、想定外の荷重は、設計者には制御できません。だから制御できる強度の側に、あらかじめ余裕を積んでおくのです。

冗長性も同じ発想です。冗長性とは、一つが壊れても全体が止まらないように、同じ働きをする部品を複数持たせることです。たとえばエレベーターは、一般に複数の綱で籠を吊り、一本が切れても落ちないように作られます。

これは「不可勝在己」の工学版と言えます。壊れないことは設計者の側にあり、荷重がどれだけ来るかは外にあります。ただし違いもあります。橋に掛かる荷重には意志がなく、隙を狙ってはきません。孫子の敵は、こちらの弱点を探して隠れ、攻めてきます。だから形篇の守りには、強さに加えて「見せない」ことが求められるのです。
```

```connect
title: 複利 — 小さな優位が落差になる
**小さな差が積み重なって大きな落差になる**という点で、複利と度量数称勝の連鎖は同じ形をしています。どちらも、前の段階の成果が次の段階の元手になるからです。

複利とは、利息にもまた利息がつく仕組みです。元本に利息を足し、その合計にまた利率を掛ける。これを繰り返すと、増え方そのものが大きくなっていきます。一回あたり一%の増加でも、百回重ねると、元の約二・七倍になります。一回ごとの差は目に見えないほど小さくても、積み重ねると誰の目にも明らかな開きになります。

形篇の連鎖も同じです。土地の広さの差が物資の差を生み、物資の差が兵の数の差を生みます。一段ごとの差は小さくても、段を重ねるうちに、鎰と銖ほどの差に育ちます。名将の勝ちが当然に見えるのは、この積み重ねが戦う前に済んでいるからです。

違いは時間の扱いです。複利はただ積み上がり続け、どこかで一気に放つ瞬間を持ちません。形篇の積水は、溜めたうえで、ある瞬間に谷へ切って落とされます。溜めることと放つことの両方があって、はじめて兵法になるのです。
```

## この篇の一行

形篇を一文にまとめるなら、「負けない態勢は自分で作り、勝ちは測って確かめてから取りに行け」となるでしょう。自分にできることと、できないことを分ける。できることをやり尽くして、負けを消す。そのうえで彼我を測り、天秤が大きく傾いたときにだけ戦う。そうして生まれる、溜めた水と谷底との落差が「形」でした。

冒頭の試験の場面に戻れば、取りこぼさない力を固めた受験者は、すでに「不可勝」の側に立っています。どんな問題が出るかは、相変わらず本人には決められません。それでも、得意な問題が来たときに確実に拾える構えがあれば、結果は当日の運よりも、それまでの積み重ねに近づきます。形篇の教えは、勝ちを約束するものではありません。負けの多くを、戦う前に消しておく技術なのです。

ただし、落差はそれだけでは何も動かしません。水は水門を開けたときに、はじめて谷を下ります。いつ、どのように開けるのか。溜めた力を、どう一つの流れにまとめるのか。形篇はそこで筆を止め、次の篇にその問いを渡しています。形が落差なら、それを一気に流す力は——。
