# 後編 II プロジェクトの「計」— 始める前に勝算を数える

新しいプロジェクトは、たいてい熱意から始まります。誰かが良い案を思いつき、周りが乗り、気づけば人と予算が動いています。半年後に振り返ると、始めた時点ですでに勝ち目が薄かった、とわかることも少なくありません。この章では、計篇の「数える」という動作を、一般のプロジェクトの立ち上げに置き直します。何を数えるのか、どの場で数えるのか、数えた結果が悪ければどうするのか。この三つが本章の問いです。

ここでいう「プロジェクト」は、期限と目的のある一回きりの取り組みを指します。新製品の開発でも、社内の仕組みの入れ替えでも、地域の催しでもかまいません。共通するのは、始める前に資源を賭けるという点です。孫子が戦争について言ったことのうち、どこまでがそのまま写せて、どこからが写せないのか。それを一節ずつ確かめながら進みます。

## 原文を読み直す — 五つの軸と、数える場

計篇は、戦争を国の大事と呼んだあと、すぐに比べるための軸を立てます。前編で読んだ一節を、もう一度引きます。

```quote
原文: 故經之以五事、校之以計、而索其情、一曰道、二曰天、三曰地、四曰將、五曰法。
訓読: 故に之を経るに五事を以てし、之を校ぶるに計を以てして、其の情を索む。一に曰く道、二に曰く天、三に曰く地、四に曰く将、五に曰く法。
出典: 計篇
訳: そこで五つの基本事項で戦いを測り、比較の項目で彼我を比べて、実情を探る。五つとは、道・天・地・将・法である。
```

原文はこう言っています。戦いを測る軸は五つあり、それで自分と相手を比べて「情」、つまり実情を探れ、と。続く本文で、道は民と上の者が同じ思いを持つこと、天は陰陽・寒暑・時節、地は遠近・険しさ・広狭・生死を分ける地勢、将は智・信・仁・勇・厳、法は組織の編成や規則だと説明されます。さらに七つの問いが続きます。どちらの君主に道があるか、どちらの将が有能か、天地の利はどちらにあるか。法令はどちらが徹底しているか、兵はどちらが強いか、どちらがよく訓練されているか、賞罰はどちらが明らかか。

大事なのは、五事が「自分の点検表」ではなく「比較の軸」だという点です。「校（くら）ぶる」とあるとおり、相手と並べてはじめて意味を持ちます。自軍の将が有能でも、相手の将がより有能なら、その項目は負けです。点数の絶対値ではなく、差を見るための枠組みだと読めます。

この比較を、どこで行うのか。計篇の結びに答えがあります。

```quote
原文: 多算勝、少算不勝、而況於無算乎。
訓読: 算多きは勝ち、算少なきは勝たず。而るを況んや算無きに於いてをや。
出典: 計篇
訳: 勝算の多い方が勝ち、少ない方は勝てない。まして勝算がまったくなければ、言うまでもない。
```

この直前で孫子は、開戦前の廟算（びょうさん）で勝つと出る者は「算」が多いからだ、と述べています。廟算とは、祖先を祀る廟堂で開戦前に行う軍議のことです。「算」は数えるための木の棒、つまり勝つ条件の一つ一つを数えた結果だと解されています。

原文が言っているのは、二つのことです。一つは、勝敗の見通しは開戦の前に、決まった場で立てるということ。もう一つは、その見通しは条件を数えた量に比例するということです。「況んや算無きに於いてをや」の一句は、数えもせずに始めることへの強い戒めとして読めます。

ただし、原文は「数えれば必ず勝つ」とは言っていません。言っているのは「算の多い方が勝つ」という比較の話です。また、廟算は君主と重臣が集まる国家の意思決定の場であり、現場の担当者が個人で行う見積もりとは格が違います。この重さは、後で写し替えるときにも手放さないでおきます。

## 五事七計をプロジェクトに写す

では、五つの軸をプロジェクトに置き直してみます。ここからは「現代ではこう読める」の段です。

道は、目的と合意に当たります。何のためにやるのかが関係者のあいだで一致しているか、です。原文の道は「民と上が同じ思いを持ち、生死を共にできる」状態でした。プロジェクトでいえば、出資する側と手を動かす側が、同じ成功の姿を思い描いているかどうかです。天は時機と外部環境です。原文の天は季節や天候でした。いまなら規制の変更、景気、技術の成熟度など、自分では動かせない時間の条件に当たります。地は、市場と技術の地形です。顧客までの距離、参入の難しさ、競争の広さ狭さが、原文の遠近・険易・広狭と対応します。将は責任者の資質です。智・信・仁・勇・厳の五つは、判断力、約束を守ること、人への配慮、決断の勇気、規律の厳しさと読めます。法は体制とルールで、役割分担、意思決定の手順、予算の管理の仕方に当たります。

![図16 五事七計のプロジェクト写像 — 五つの軸を目的・時機・地形・責任者・体制に置き換え、七つの問いを競合・代替との比較表にする](figures/16-project-map.svg)

七つの問いは、そのまま比較表になります。孫子は「どちらが」と問いました。プロジェクトで比べる相手は、競合する他社の製品だけではありません。顧客がいま使っている代替手段も相手です。そして見落とされやすいのが、「何もしない」という選択肢です。

| 七計の問い | プロジェクトでの問い |
|---|---|
| どちらの君主に道があるか | どちらの目的が顧客と関係者の合意を得ているか |
| どちらの将が有能か | どちらの責任者が、この領域で判断を誤らないか |
| 天地の利はどちらにあるか | 時機と市場の地形は、どちらに有利か |
| 法令はどちらが徹底しているか | 決めたことが実際に守られる体制は、どちらか |
| 兵はどちらが強いか | 投入できる人と資金は、どちらが厚いか |
| どちらがよく訓練されているか | 必要な技能を、どちらがすでに持っているか |
| 賞罰はどちらが明らかか | 成果と失敗の評価基準が、どちらで明確か |

表を埋めるときの注意が二つあります。一つは、各欄に根拠を添えることです。「こちらが有利」と書くなら、その理由となる数字や観察を横に書きます。根拠のない欄は、算を数えたのではなく、願いを書いたにすぎません。もう一つは、「わからない」を正直に残すことです。わからない欄が多いなら、それ自体が一つの結果です。始める前に調べるべきことの一覧になります。計篇の言葉でいえば、「情を索む」、実情を探る作業がまだ終わっていないのです。

ただし、原文はこうは言っていません。孫子が比べた相手は、戦場で向き合う実在の敵です。顧客の代替手段や「何もしない」案は、原文の外から持ち込んだ相手です。また、五事は国家が戦争を始めるかどうかの軸であり、事業の採否を決めるための道具として書かれたものではありません。写せるのは「軸を先に決め、相手と並べて差を見る」という手順の形までです。

```connect
title: ステージゲート — 資源を投じる前に関門を置く
製品開発の実務では、開発をいくつかの段階に分け、段階の境目に「関門」を置く方法が広く使われています。ステージゲートと呼ばれる方法です。関門では、決める権限を持つ人たちが集まり、あらかじめ決めた評価項目で案件を見て、進むか止まるかを判定します。項目には、市場の魅力、技術の実現性、競争上の優位、自社の強みとの適合などが並びます。

これは廟算と同じ形をしています。決まった場で、決まった軸を使い、資源を本格的に投じる前に判定する、という形です。同じ形になるのは、投じる前の判断のほうが安く、しかも投じた後では、すでに使った費用への未練が判断を曲げるからです。賭け金が小さいうちに数えるほど、止める自由が残ります。

違いもあります。ステージゲートは段階ごとに何度も関門を置き、各段階で集めた新しい情報で見積もりを更新します。計篇が描く廟算は、開戦前の一回の軍議です。
```

## 撤退基準を先に書く — 聴かれない計の行方

計篇には、五事七計の比較のすぐ後に、短い一文があります。私の計を聴いて用いるなら必ず勝つので留まる、聴かずに用いるなら必ず敗れるので去る、という趣旨です。誰が留まり、誰が去るのかは、読み方が分かれます。

```note
この一文の「将」は、将軍のことだとする読みと、「もし」の意味に取る読みがあります。後者なら、孫子が仕える君主に向けて「私の計を聴くなら留まり、聴かないなら去る」と言っていることになります。前者なら、計に従う将軍を留め、従わない将軍を去らせる、と読めます。どちらを採るかは諸説あります。
```

どちらに読んでも、共通する形があります。計に従うかどうかで、関わり続けるか離れるかを、あらかじめ決めているという形です。勝算が立たないとわかった時点で、それ以上は付き合わないと宣言しているのです。

現代ではこう読めます。プロジェクトを始める前に、撤退基準を書いておく、ということです。たとえば「三か月で利用者が一定数に届かなければ止める」「主要な前提が一つ崩れたら評価会を開き直す」といった基準です。基準を始める前に書くのは、始めた後では書けなくなるからです。人と時間を注いだ後の計画は、それ自体が守るべきものに見えてきます。

ただし、原文はこうは言っていません。計篇のこの一文は、計を採用するかどうかについての話であり、始めた後の中止基準を定めたものではありません。そもそも孫子は、始めた戦争の止め方を計篇では論じていません。撤退基準は、「計に従わないなら去る」という事前の線引きの形を、時間の軸に延ばした読みです。

撤退基準を書くのに役立つのが、次の方法です。

```connect
title: プレモーテム — 失敗を先に起こしてみる
プレモーテムは、心理学者のゲーリー・クラインが広めた手法です。計画を決める前に、関係者に「一年後、このプロジェクトは大失敗に終わった」と仮定してもらいます。そのうえで、なぜ失敗したのかを各自が書き出し、全員で読み上げます。成功を前提に問うと出てこない懸念が、失敗を前提に問うと出てきやすくなります。

これは七計の問いと同じ形をしています。七計は「どちらが強いか」を相手の側から問い直させる装置であり、プレモーテムは「なぜ負けたか」を未来の側から問い直させる装置です。同じ形になるのは、計画を立てた人は成功の筋書きに引き寄せられ、自分に都合のよい算を数えがちだからです。視点を強制的に裏返す仕組みがないと、算は水増しされます。

違いは、比べる相手にあります。七計の相手は実在の敵ですが、プレモーテムの相手は想像上の失敗です。書き出された失敗の理由は、そのまま撤退基準の候補になります。
```

評価会の進め方も、ここで一つにまとまります。キックオフの前に、決める権限のある人を集める。五つの軸で比較表を埋める。プレモーテムで失敗の理由を出す。その中から撤退基準を選び、文書に残す。廟算を現代に写すなら、この順番が素直です。

## 「拙速」を小さな初回リリースに読む

数えて始めると決めたあと、どう始めるか。ここでよく引かれるのが「拙速」です。ただ、その一節を読む前に、作戦篇がその少し前に置いている前提を確かめておきます。

```quote
原文: 其用戰也、勝久則鈍兵挫銳、攻城則力屈、久暴師則國用不足。
訓読: 其の戦いを用うるや、勝つも久しければ則ち兵を鈍らせ鋭を挫き、城を攻むれば則ち力屈き、久しく師を暴せば則ち国用足らず。
出典: 作戦篇
訳: 戦いを行うにあたっては、たとえ勝っても長引けば軍は疲れて鋭さを失い、城攻めをすれば戦力が尽き、軍を長く野外にさらせば国の財政が足りなくなる。
```

作戦篇は、戦争の費用の話から始まります。戦車や武具をそろえ、遠くまで食糧を運び、十万の軍を動かせば、一日に千金が消えていく。その計算を示したうえで、この一節が来ます。注目したいのは「勝つも久しければ」という言い方です。負けている戦いが苦しいのは当然ですが、孫子は勝っている戦いでも、長引けば軍が鈍ると言っています。勝ち負けとは別の軸で、時間そのものが費用になるという見方です。

さらに本文は、こうして兵が疲れ財が尽きれば、周りの諸侯がその弱みに乗じて立ち上がり、知恵のある者がいても後始末ができなくなる、と続けます。長さの害は、自分の消耗だけで終わらず、外からの介入を呼び込むのです。計篇で数えた「天」や「地」の条件も、時間がたてば変わってしまいます。開戦前の算は、開戦の時点の算にすぎません。

その帰結として置かれるのが、次の一節です。

```quote
原文: 故兵聞拙速、未睹巧之久也。
訓読: 故に兵は拙速を聞くも、未だ巧の久しきを睹ざるなり。
出典: 作戦篇
訳: だから戦争では、多少まずくても素早く切り上げて成功した例は聞くが、巧みに長引かせて成功した例は見たことがない。
```

原文はこう言っています。戦争で、拙速（せっそく）、つまり出来は粗くても早く終えた例は聞くが、巧みに長引かせてうまくいった例は見たことがない、と。冒頭の「故に」は、いま見た長期戦の害の計算を受けています。「拙」と「巧」が対になり、「速」と「久」が対になっています。孫子が比べているのは出来の良し悪しではなく、戦いの長さです。警戒しているのは、粗さよりも長さです。

現代ではこう読めます。最初の版を小さく、早く出す、ということです。完成度を上げてから一度に出す計画は、出すまでのあいだ費用だけが積み上がります。その間に、天、つまり時機や外部環境は動きます。小さな初回の版を早く出せば、比較表に書いた見積もりが当たっていたかを、実際の反応で確かめられます。廟算の算を、現場の事実で数え直す機会が早く来るのです。

ただし、原文はこうは言っていません。孫子は「粗くてよいから急げ」とは勧めていません。言っているのは、長期戦の害の大きさです。「兵は拙速を貴ぶ」という形の言い回しは後世の成語で、原文にはありません。粗さを正当化するためにこの一節を引くと、原文から離れます。初回の版を小さくするのは、作業を雑にするためではなく、長引くことの損を避けるためです。この順序を取り違えないことが、写し替えの条件です。

## この章の一行

プロジェクトの「計」とは、始める前に、決まった場で、決まった軸で、相手と並べて差を数えることです。五事は目的・時機・地形・責任者・体制に、七計は競合と代替と「何もしない」案との比較表に、廟算はキックオフ前の評価会に写せます。数えた結果が悪ければ、去る基準も先に書いておきます。そして始めるときは、長引くことの損を避けるために小さく出します。原文が保証するのは「算の多い方が勝つ」という比較だけで、数えれば勝てるという約束ではありません。それでも、数えずに始めるより、ずっと多くのことが始める前にわかります。数えて始めると決めたら、次は『形』と『勢』をチームに作る。
