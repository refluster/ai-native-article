# 付録 名言集 — 十三篇の原文と訓読

本文で引いた原文を、篇の順にまとめました。原文は四庫全書本（武経七書系）の本文を底本とし、訓読は慣用の読みに従って本書のために新しく起こした書き下しです。各カードの「出典」から篇を確かめ、本文の該当章に戻って読み返せます。

## 01 計篇

```quote
原文: 兵者、國之大事、死生之地、存亡之道、不可不察也。
訓読: 兵は国の大事にして、死生の地、存亡の道なり。察せざるべからざるなり。
出典: 計篇
訳: 戦争は国家の重大事であり、人々の生死が決まる場、国が存続するか滅びるかの分かれ道である。徹底して考え抜かなければならない。
```

```note
『孫子』の冒頭句はこれ。「兵は詭道なり」から始まるとする説明は誤り。
```

```quote
原文: 故經之以五事、校之以計、而索其情、一曰道、二曰天、三曰地、四曰將、五曰法。
訓読: 故に之を経るに五事を以てし、之を校ぶるに計を以てして、其の情を索む。一に曰く道、二に曰く天、三に曰く地、四に曰く将、五に曰く法。
出典: 計篇
訳: そこで五つの基本事項で戦争を測り、（後段に挙げる）比較項目で彼我を比べて実情を探る。五つとは、道・天・地・将・法である。
```

```note
底本（四庫）と十一家注は「校之以計」で、「七」字がない。WS は「校之以七計」。「七計」は、後段の七つの問い（主孰有道…賞罰孰明）を指す通称として用いられる。
```

```quote
原文: 兵者、詭道也。
訓読: 兵は詭道なり。
出典: 計篇
訳: 戦争とは、相手を欺く行為である。
```

```note
「卑怯であれ」という勧めではなく、実戦での運用原理を述べた句。計篇の冒頭ではなく、五事・七計の比較を論じた後に置かれている。
```

```quote
原文: 故能而示之不能、用而示之不用、近而示之遠、遠而示之近。
訓読: 故に能なるも之に不能を示し、用うるも之に用いざるを示し、近くとも之に遠きを示し、遠くとも之に近きを示す。
出典: 計篇
訳: だから、できるのにできないように見せ、使うつもりなのに使わないように見せ、近くにいるのに遠いと思わせ、遠くにいるのに近いと思わせる。
```

```quote
原文: 攻其無備、出其不意。
訓読: 其の備え無きを攻め、其の不意に出づ。
出典: 計篇
訳: 敵が備えていないところを攻め、敵が予想していないところに打って出る。
```

```quote
原文: 夫未戰而廟算勝者、得算多也。未戰而廟算不勝者、得算少也。
訓読: 夫れ未だ戦わずして廟算して勝つ者は、算を得ること多ければなり。未だ戦わずして廟算して勝たざる者は、算を得ること少なければなり。
出典: 計篇
訳: 開戦前に廟堂での軍議で勝つと見通せるのは、勝つための条件（算）が多いからだ。勝てないと出るのは、その条件が少ないからだ。
```

```note
「廟算」は、祖先を祀る廟堂で開戦前に行う軍議のこと（ja.wikipedia「孫子 (書物)」）。
```

```quote
原文: 多算勝、少算不勝、而況於無算乎。
訓読: 算多きは勝ち、算少なきは勝たず。而るを況んや算無きに於いてをや。
出典: 計篇
訳: 勝算の多い方が勝ち、少ない方は勝てない。まして勝算がまったくなければ、言うまでもない。
```

## 02 作戦篇

```quote
原文: 其用戰也、勝久則鈍兵挫銳、攻城則力屈、久暴師則國用不足。
訓読: 其の戦いを用うるや、勝つも久しければ則ち兵を鈍らせ鋭を挫き、城を攻むれば則ち力屈き、久しく師を暴せば則ち国用足らず。
出典: 作戦篇
訳: 戦いを行うにあたっては、たとえ勝っても長引けば軍は疲れて鋭さを失い、城攻めをすれば戦力が尽き、軍を長く野外にさらせば国の財政が足りなくなる。
```

```note
底本（四庫）と十一家注は「勝久則鈍兵挫銳」（勝つも久しければ）。WS だけが「貴勝，久則鈍兵挫銳」（勝つを貴ぶ。久しければ…）と作る。
```

```quote
原文: 故兵聞拙速、未睹巧之久也。
訓読: 故に兵は拙速を聞くも、未だ巧の久しきを睹ざるなり。
出典: 作戦篇
訳: だから戦争では、多少まずくても素早く切り上げて成功した例は聞くが、巧みに長引かせて成功した例は見たことがない。
```

```note
「兵は拙速を尊ぶ」は原文にない、成語化した言い回しである。原文は「拙速の例は聞くが、巧久の例は見ない」という観察であり、「雑でも速ければよい」という一般論ではない。底本の翻刻は異体字の「覩」と作るが、字形表により「睹」に統一した。
```

```quote
原文: 故不盡知用兵之害者、則不能盡知用兵之利也。
訓読: 故に尽く用兵の害を知らざる者は、則ち尽く用兵の利を知ること能わざるなり。
出典: 作戦篇
訳: 戦争の害を知り尽くしていない者には、戦争の利益も本当にはわからない。
```

```quote
原文: 故智將務食於敵、食敵一鍾、當吾二十鍾。萁稈一石、當吾二十石。
訓読: 故に智将は務めて敵に食む。敵の一鍾を食むは、吾が二十鍾に当たり、萁稈一石は、吾が二十石に当たる。
出典: 作戦篇
訳: だから賢い将は、できるだけ敵地で食糧を調達する。敵から得た食糧一鍾は自国から運ぶ二十鍾に相当し、飼料一石は自国の二十石に相当する。
```

```quote
原文: 故兵貴勝、不貴久。
訓読: 故に兵は勝つことを貴びて、久しきを貴ばず。
出典: 作戦篇
訳: だから戦争では勝つことが大切で、長引かせることに価値はない。
```

```quote
原文: 故知兵之將、民之司命、國家安危之主也。
訓読: 故に兵を知るの将は、民の司命にして、国家安危の主なり。
出典: 作戦篇
訳: だから戦争を理解した将軍は、民の生死を握る者であり、国家の安危を左右する者である。
```

```note
十一家注は「生民之司命」。「司命」は命運をつかさどる者の意。
```

## 03 謀攻篇

```quote
原文: 夫用兵之法、全國為上、破國次之。全軍為上、破軍次之
訓読: 夫れ用兵の法は、国を全うするを上と為し、国を破るは之に次ぐ。軍を全うするを上と為し、軍を破るは之に次ぐ。
出典: 謀攻篇
訳: 戦争の原則として、敵国を無傷のまま降すのが最上で、打ち破るのはそれに劣る。敵軍についても、無傷で降すのが最上で、撃破するのはそれに劣る。
```

```note
底本（四庫）は「夫用兵之法」。十一家注と WS は「凡用兵之法」（凡そ用兵の法は）で、1935年『武経七書』訓読本も「凡そ」と読む。原文はこの後も、旅・卒・伍について同じ型で続く。
```

```quote
原文: 是故百戰百勝、非善之善者也
訓読: 是の故に百戦百勝は、善の善なる者に非ず。
出典: 謀攻篇
訳: だから、百回戦って百回勝つのは、最善の中の最善ではない。
```

```note
「百戦百勝」を理想とする意味で引かれることがあるが、原文はそれを最善ではないと否定している。
```

```quote
原文: 不戰而屈人之兵、善之善者也。
訓読: 戦わずして人の兵を屈するは、善の善なる者なり。
出典: 謀攻篇
訳: 戦わずに敵の軍を屈服させることこそ、最善の中の最善である。
```

```quote
原文: 故上兵伐謀、其次伐交、其次伐兵、其下攻城。
訓読: 故に上兵は謀を伐つ。其の次は交わりを伐つ。其の次は兵を伐つ。其の下は城を攻む。
出典: 謀攻篇
訳: 最上の戦い方は敵の計画を挫くこと、次は敵の同盟を断つこと、その次は敵の軍と戦うことであり、最も下策は城を攻めることである。
```

```quote
原文: 故用兵之法、十則圍之、五則攻之、倍則分之、敵則能戰之、少則能守之、不若則能避之。
訓読: 故に用兵の法は、十なれば則ち之を囲み、五なれば則ち之を攻め、倍なれば則ち之を分かち、敵しければ則ち能く之と戦い、少なければ則ち能く之を守り、若かざれば則ち能く之を避く。
出典: 謀攻篇
訳: 兵力が敵の十倍なら包囲し、五倍なら攻め、二倍なら敵を分断し、互角なら力を尽くして戦い、少なければ守りを固め、まったく及ばなければ戦いを避ける。
```

```note
十一家注は「少則能逃之」（少なければ則ち能く之を逃る）。
```

```quote
原文: 故知勝有五、知可以與戰不可以與戰者勝、識衆寡之用者勝、上下同欲者勝、以虞待不虞者勝、將能而君不御者勝。
訓読: 故に勝を知るに五有り。以て与に戦うべきと、以て与に戦うべからざるとを知る者は勝つ。衆寡の用を識る者は勝つ。上下欲を同じくする者は勝つ。虞を以て不虞を待つ者は勝つ。将能にして君御せざる者は勝つ。
出典: 謀攻篇
訳: 勝利を見通す条件は五つある。戦うべき時と戦うべきでない時を見分ける者、大軍と小勢それぞれの使い方を知る者、上下が同じ目標を共有する者、備えをもって備えのない敵を待つ者、有能な将に君主が口出ししない者が勝つ。
```

```note
底本（四庫）は「知可以與戰不可以與戰者勝」。十一家注と WS は「知可以戰與不可以戰者勝」。
```

```quote
原文: 故曰、知彼知己、百戰不殆。不知彼而知己、一勝一負。不知彼不知己、每戰必敗。
訓読: 故に曰く、彼を知り己を知れば、百戦して殆うからず。彼を知らずして己を知れば、一勝一負す。彼を知らず己を知らざれば、戦う毎に必ず敗る。
出典: 謀攻篇
訳: 敵を知り自分を知っていれば、何度戦っても危険はない。敵を知らず自分だけを知っていれば、勝ったり負けたりする。敵も自分も知らなければ、戦うたびに必ず敗れる。
```

```note
原文は「百戦百勝」ではなく「百戦殆うからず」（危うくない＝負けない）であり、この前半「知彼知己，百戰不殆」は三本とも同じ。末句は、底本（四庫）が「每戰必敗」、十一家注と WS が「每戰必殆」（戦う毎に必ず殆うし）。地形篇には「知彼知己，勝乃不殆」という別形がある（Q-10-07）。
```

## 04 形篇

```quote
原文: 昔之善戰者、先為不可勝、以待敵之可勝。
訓読: 昔の善く戦う者は、先ず勝つべからざるを為して、以て敵の勝つべきを待つ。
出典: 形篇
訳: 昔の戦上手は、まず自軍を敵が勝てない態勢に整え、そのうえで敵に勝てる隙が生じるのを待った。
```

```quote
原文: 不可勝在己、可勝在敵。
訓読: 勝つべからざるは己に在り、勝つべきは敵に在り。
出典: 形篇
訳: 負けない態勢をつくれるかは自分次第だが、勝てるかどうかは敵次第である。
```

```note
底本の翻刻は「已」と作るが、文意と他本により「己」に訂正した（sunzi-text.md の訂正一覧を参照）。十一家注は「巳」と作る。
```

```quote
原文: 故曰、勝可知、而不可為
訓読: 故に曰く、勝は知るべくして、為すべからず。
出典: 形篇
訳: だから、勝てるかどうかは見通せても、勝ちを無理につくり出すことはできない。
```

```note
虚実篇の「勝可為也」（Q-06-04）と矛盾して見える。形篇は「敵が隙を見せない限り勝ちは作れない」、虚実篇は「主導権を握り敵を分散させれば勝ちを作れる」という文脈で、そう読めば両立する。WS の虚実篇は「勝可擅也」。
```

```quote
原文: 善守者、藏於九地之下
訓読: 善く守る者は、九地の下に蔵る。
出典: 形篇
訳: 守りの上手な者は、大地の奥深くに隠れるように、自軍の態勢をまったく見せない。
```

```note
ここでの「九地」は「地の最も深い所」の比喩であり、九地篇の九種の地とは別物である。
```

```quote
原文: 善攻者、動於九天之上、故能自保而全勝也。
訓読: 善く攻むる者は、九天の上に動く。故に能く自ら保ちて勝を全うするなり。
出典: 形篇
訳: 攻めの上手な者は、天の最も高い所から襲いかかるように動く。だから自軍を保ったまま、完全な勝利を得られる。
```

```quote
原文: 故善戰者、立於不敗之地、而不失敵之敗也。
訓読: 故に善く戦う者は、不敗の地に立ちて、敵の敗を失わざるなり。
出典: 形篇
訳: だから戦上手は、自分は決して負けない立場に立ち、そのうえで敵が崩れる機会を逃さない。
```

```quote
原文: 是故勝兵先勝而後求戰、敗兵先戰而後求勝。
訓読: 是の故に勝兵は先ず勝ちて而る後に戦いを求め、敗兵は先ず戦いて而る後に勝ちを求む。
出典: 形篇
訳: だから勝つ軍は、まず勝てる態勢を整えてから戦いに臨む。負ける軍は、まず戦い始めてから勝ちを探す。
```

```note
新字体で「勝兵先勝而後求戦」と書かれることがあるが、原文の字形は「戰」。
```

## 05 勢篇

```quote
原文: 凡戰者、以正合、以奇勝。
訓読: 凡そ戦いは、正を以て合い、奇を以て勝つ。
出典: 勢篇
訳: およそ戦いは、正攻法で敵と対峙し、奇策で勝ちを決める。
```

```quote
原文: 故善出奇者、無窮如天地、不竭如江海。
訓読: 故に善く奇を出だす者は、窮まり無きこと天地の如く、竭きざること江海の如し。
出典: 勢篇
訳: だから奇策の上手な者は、天地のように尽きることがなく、大河や海のように涸れることがない。
```

```note
十一家注は「不竭如江河」。
```

```quote
原文: 戰勢不過奇正、奇正之變、不可勝窮也。
訓読: 戦勢は奇正に過ぎざるも、奇正の変は、勝げて窮むべからざるなり。
出典: 勢篇
訳: 戦いの勢いは奇と正の二つしかないが、その組み合わせが生む変化は数え尽くせない。
```

```quote
原文: 故善戰者、其勢險、其節短。勢如彍弩、節如發機。
訓読: 故に善く戦う者は、其の勢は険にして、其の節は短なり。勢は弩を彍くが如く、節は機を発するが如し。
出典: 勢篇
訳: だから戦上手は、勢いを鋭く高め、それを放つ間合いを短くする。勢いは引き絞った弩のようであり、間合いは引き金を引く一瞬のようである。
```

```quote
原文: 亂生於治、怯生於勇、弱生於強。
訓読: 乱は治に生じ、怯は勇に生じ、弱は強に生ず。
出典: 勢篇
訳: 混乱は秩序の中から生まれ、臆病は勇気の中から生まれ、弱さは強さの中から生まれる。
```

```note
「乱れたふりは、本当に整った軍にしかできない」と、偽装の意味で読む注釈もある。
```

```quote
原文: 故善戰者、求之於勢、不責之於人、故能擇人而任勢。
訓読: 故に善く戦う者は、之を勢に求めて、之を人に責めず。故に能く人を択びて勢に任ず。
出典: 勢篇
訳: だから戦上手は、勝利を全体の勢いに求め、個々の兵の能力に負わせない。だからこそ適材を選び、勢いに任せることができる。
```

```note
底本（四庫）は「不責之於人」。十一家注と WS は「不責於人」。
```

```quote
原文: 故善戰人之勢、如轉圓石於千仞之山者、勢也。
訓読: 故に善く人を戦わしむるの勢、円石を千仞の山に転ずるが如き者は、勢なり。
出典: 勢篇
訳: 兵をうまく戦わせる勢いとは、丸い石を高い山の上から転がすようなものである。これが勢である。
```

## 06 虚実篇

```quote
原文: 故善戰者、致人而不致於人。
訓読: 故に善く戦う者は、人を致して人に致されず。
出典: 虚実篇
訳: だから戦上手は、敵を思いどおりに動かし、自分が敵に動かされることはない。
```

```quote
原文: 故善攻者、敵不知其所守。善守者、敵不知其所攻。
訓読: 故に善く攻むる者には、敵其の守る所を知らず。善く守る者には、敵其の攻むる所を知らず。
出典: 虚実篇
訳: 攻めの上手な者が相手だと、敵はどこを守ればよいかわからない。守りの上手な者が相手だと、敵はどこを攻めればよいかわからない。
```

```quote
原文: 故形人而我無形、則我專而敵分。
訓読: 故に人を形せしめて我は無形なれば、則ち我は専らにして敵は分かる。
出典: 虚実篇
訳: 敵には態勢をさらけ出させ、自分は態勢を見せなければ、自軍は一つに集中でき、敵は分散する。
```

```quote
原文: 故曰、勝可為也。敵雖衆、可使無鬥。
訓読: 故に曰く、勝は為すべきなり。敵衆しと雖も、闘い無からしむべし。
出典: 虚実篇
訳: だから、勝利はつくり出すことができる。敵が多くても、戦えないようにさせられる。
```

```note
底本（四庫）と十一家注の読み。WS は「故曰：勝可擅也」で、本文注記に「一作『為』」とある。形篇の「勝可知，而不可為」（Q-04-03）と対照して読まれる。
```

```quote
原文: 故形兵之極、至於無形。
訓読: 故に兵を形するの極みは、無形に至る。
出典: 虚実篇
訳: だから軍の態勢づくりの極致は、形がまったく見えない状態に達することだ。
```

```quote
原文: 故其戰勝不復、而應形於無窮。
訓読: 故に其の戦い勝つや復びせずして、形に無窮に応ず。
出典: 虚実篇
訳: だから勝ち方を二度と繰り返さず、相手の態勢に合わせて限りなく形を変えて応じる。
```

```quote
原文: 夫兵形象水、水之形、避高而趨下。兵之形、避實而擊虚。
訓読: 夫れ兵の形は水に象る。水の形は高きを避けて下きに趨き、兵の形は実を避けて虚を撃つ。
出典: 虚実篇
訳: 軍の形は水に似ている。水が高い所を避けて低い所へ流れるように、軍は敵の充実した所を避けて手薄な所を撃つ。
```

```note
底本（四庫）と十一家注の読み。WS は「水之行，避高而趨下；兵之勝，避實而擊虚」。
```

```quote
原文: 故兵無常勢、水無常形、能因敵變化而取勝者、謂之神。
訓読: 故に兵に常勢無く、水に常形無し。能く敵に因りて変化して勝を取る者、之を神と謂う。
出典: 虚実篇
訳: だから軍には決まった勢いがなく、水には決まった形がない。敵に応じて変化して勝利をつかめる者を、神業の持ち主という。
```

```note
底本（四庫）と十一家注の読み。WS は「故兵無成勢，無恒形」で、「水」字がない。
```

## 07 軍争篇

```quote
原文: 軍爭之難者、以迂為直、以患為利。
訓読: 軍争の難きは、迂を以て直と為し、患を以て利と為す。
出典: 軍争篇
訳: 軍争の難しさは、回り道を近道に変え、不利な条件を有利に転じるところにある。
```

```quote
原文: 故迂其途、而誘之以利、後人發、先人至、此知迂直之計者也。
訓読: 故に其の途を迂にして、之を誘うに利を以てし、人に後れて発し、人に先んじて至る。此れ迂直の計を知る者なり。
出典: 軍争篇
訳: わざと遠回りの道をとり、利で誘って敵を足止めすれば、敵より後に出発しても先に着ける。これが迂直の計を知る者である。
```

```quote
原文: 故兵以詐立、以利動、以分合為變者也。
訓読: 故に兵は詐を以て立ち、利を以て動き、分合を以て変を為す者なり。
出典: 軍争篇
訳: 戦争は敵を欺くことで成り立ち、利益によって動き、兵力の分散と集中によって変化するものである。
```

```quote
原文: 故其疾如風、其徐如林、侵掠如火、不動如山、難知如陰、動如雷震。
訓読: 故に其の疾きこと風の如く、其の徐かなること林の如く、侵掠すること火の如く、動かざること山の如く、知り難きこと陰の如く、動くこと雷震の如し。
出典: 軍争篇
訳: 軍は、動くときは風のように速く、待つときは林のように静かに、攻めるときは火のように激しく、守るときは山のように動かず、隠れるときは暗闇のように捉えがたく、動き出せば雷鳴のように激しい。
```

```note
「風林火山」は、武田信玄の旗指物（古くは「孫子四如の旗」と呼ばれた）に記されたとされる前半四句の通称である。旗の字句は「疾如風、徐如林、侵掠如火、不動如山」と伝わる（ja.wikipedia「風林火山」）。原文はさらに「難知如陰，動如雷震」と続く。本パックの三本（四庫・十一家注・WS）はいずれも「雷震」だが、「雷霆」とする版もある（同記事の注記）。
```

```quote
原文: 善用兵者、避其銳氣、擊其惰歸、此治氣者也
訓読: 善く兵を用うる者は、其の鋭気を避けて、其の惰帰を撃つ。此れ気を治むる者なり。
出典: 軍争篇
訳: 用兵の上手な者は、敵の士気が盛んなときは避け、士気が緩んで帰りたがっているところを撃つ。これが士気を制する方法である。
```

```note
十一家注と WS は冒頭に「故」がある。
```

```quote
原文: 以近待遠、以佚待勞、以飽待饑、此治力者也
訓読: 近きを以て遠きを待ち、佚を以て労を待ち、飽を以て饑を待つ。此れ力を治むる者なり。
出典: 軍争篇
訳: 戦場の近くに陣取って遠くから来る敵を待ち、休養十分の状態で疲れた敵を待ち、満腹の状態で飢えた敵を待つ。これが戦力を制する方法である。
```

```note
ja.wikipedia は、東郷平八郎が日本海海戦で丁字戦法を採った背後にこの句（「逸を以て労を待ち、飽を以て飢を待つ」）があったという説を、「要出典」付きで紹介している。伝承として扱うこと。
```

```quote
原文: 歸師勿遏、圍師必闕、窮寇勿追
訓読: 帰師は遏むる勿かれ、囲師は必ず闕き、窮寇は追う勿かれ。
出典: 軍争篇
訳: 本国へ引き上げる軍を遮ってはならない。包囲するときは必ず逃げ道を一つ空けておく。追い詰められた敵を追撃してはならない。
```

```note
底本（四庫）は「窮寇勿追」。十一家注と WS は「窮寇勿迫」（窮寇には迫る勿かれ）。九地篇の「投之亡地然後存」（自軍を死地に置いて死力を引き出す。Q-11-06）と表裏の関係にある。
```

## 08 九変篇

```quote
原文: 途有所不由、軍有所不擊、城有所不攻、地有所不爭、君命有所不受。
訓読: 途に由らざる所有り、軍に撃たざる所有り、城に攻めざる所有り、地に争わざる所有り、君命に受けざる所有り。
出典: 九変篇
訳: 通ってはならない道があり、攻撃してはならない敵軍があり、攻めてはならない城があり、奪い合ってはならない土地があり、受けてはならない君主の命令もある。
```

```note
君主への不服従一般を正当化する句ではなく、戦場での判断を将に委ねるべきだという文脈である。『史記』孫子伝の「宮中の美女を練兵した」逸話でも同趣旨の言葉が語られるが、この逸話の史実性には疑問が出されている（ja.wikipedia「孫武」）。
```

```quote
原文: 是故智者之慮、必雜於利害、雜於利而務可信也、雜於害而患可解也。
訓読: 是の故に智者の慮りは、必ず利害に雑う。利に雑えて務め信ぶべきなり。害に雑えて患い解くべきなり。
出典: 九変篇
訳: だから知恵ある者は、必ず利益と損害の両面を合わせて考える。不利な状況でも利の面を考えるから事をやり遂げられ、有利な状況でも害の面を考えるから災いを未然に解ける。
```

```quote
原文: 是故屈諸侯者以害、役諸侯者以業、趨諸侯者以利
訓読: 是の故に諸侯を屈する者は害を以てし、諸侯を役する者は業を以てし、諸侯を趨らす者は利を以てす。
出典: 九変篇
訳: だから他国を屈服させるには害を示し、他国を疲れさせるには手間のかかる事業を負わせ、他国を奔走させるには利で釣る。
```

```quote
原文: 故用兵之法、無恃其不來、恃吾有以待之。無恃其不攻、恃吾有所不可攻也。
訓読: 故に用兵の法は、其の来たらざるを恃むこと無く、吾が以て待つ有るを恃む。其の攻めざるを恃むこと無く、吾が攻むべからざる所有るを恃むなり。
出典: 九変篇
訳: 用兵の原則は、敵が来ないことを当てにせず、敵が来ても対応できる自分の備えを当てにすること。敵が攻めてこないことを当てにせず、攻められても崩れない自分の態勢を当てにすることである。
```

```note
十一家注は「恃吾有以待也」。
```

```quote
原文: 故將有五危、必死、可殺。必生、可虜。忿速、可侮。廉潔、可辱。愛民、可煩。
訓読: 故に将に五危有り。必死は殺すべく、必生は虜にすべく、忿速は侮るべく、廉潔は辱むべく、愛民は煩わすべし。
出典: 九変篇
訳: 将には五つの危険な性向がある。死ぬ覚悟ばかりの者は討ち取られ、生き延びることばかり考える者は捕らえられ、短気な者は挑発に乗せられ、清廉さにこだわる者は侮辱で動かされ、民を思いやりすぎる者は振り回される。
```

```note
「廉潔」「愛民」のような美徳でも、度を越せば弱点になるという指摘であり、美徳そのものを否定してはいない。底本（四庫）は各句末に「也」がない（十一家注と WS は「必死，可殺也」など）。
```

```quote
原文: 覆軍殺將、必以五危、不可不察也。
訓読: 軍を覆し将を殺すは、必ず五危を以てす。察せざるべからざるなり。
出典: 九変篇
訳: 軍が全滅し将が討たれるのは、必ずこの五つの危険からである。よく考えなければならない。
```

## 09 行軍篇

```quote
原文: 客絕水而來、勿迎之於水內、令半渡而擊之、利
訓読: 客、水を絶りて来たらば、之を水の内に迎うる勿く、半ば渡らしめて之を撃つは、利なり。
出典: 行軍篇
訳: 敵が川を渡って攻めてくるときは、水の中で迎え撃たず、半分ほど渡らせたところを撃てば有利である。
```

```note
底本（四庫）は「令半渡而擊之」。十一家注と WS は「令半濟而擊之」（意味は同じ）。
```

```quote
原文: 凡軍好高而惡下、貴陽而賤陰
訓読: 凡そ軍は高きを好みて下きを悪み、陽を貴びて陰を賤しむ。
出典: 行軍篇
訳: およそ軍は、高い所を好んで低い所を嫌い、日当たりのよい所を重んじて日陰を避ける。
```

```quote
原文: 鳥起者、伏也。獸駭者、覆也
訓読: 鳥起つ者は、伏なり。獣駭く者は、覆なり。
出典: 行軍篇
訳: 鳥が飛び立つのは伏兵がいるからであり、獣が驚いて逃げ出すのは奇襲部隊が迫っているからである。
```

```note
源義家が、鳥の飛び立つところに伏兵がいるという兵法の教えで伏兵を見破った話（『古今著聞集』）は、この教えの実践として語られる。ただし同書は後三年の役の約170年後に成立したもので、その兵法が『孫子』だとは書かれていない（ja.wikipedia「孫子 (書物)」）。
```

```quote
原文: 夫惟無慮而易敵者、必擒於人。
訓読: 夫れ惟だ慮り無くして敵を易る者は、必ず人に擒にせらる。
出典: 行軍篇
訳: 深く考えもせずに敵を侮る者は、必ず敵に捕らえられる。
```

```quote
原文: 卒未親附而罰之、則不服、不服則難用也。卒已親附而罰不行、則不可用也。
訓読: 卒未だ親附せずして之を罰すれば、則ち服せず。服せざれば則ち用い難きなり。卒已に親附して罰行われざれば、則ち用うべからざるなり。
出典: 行軍篇
訳: 兵がまだ将になついていないうちに罰すれば、心服しない。心服しなければ使いにくい。兵がすでになついているのに罰を行わなければ、やはり使いものにならない。
```

```quote
原文: 故令之以文、齊之以武、是謂必取。
訓読: 故に之に令するに文を以てし、之を斉うるに武を以てす。是を必取と謂う。
出典: 行軍篇
訳: だから兵には恩愛と道理で命じ、規律と刑罰で統制する。これを必ず勝ちを取る道という。
```

## 10 地形篇

```quote
原文: 凡此六者、非天地之災、將之過也。
訓読: 凡そ此の六者は、天地の災いに非ず、将の過ちなり。
出典: 地形篇
訳: これら六種類の敗北は、天災や地の災いによるものではなく、将の過失によるものである。
```

```note
「六者」は走・弛・陥・崩・乱・北の六つの敗兵を指す（同篇前段の「凡此六者，地之道也」とは別）。底本（四庫）は「非天地之災」、十一家注と WS は「非天之災」。
```

```quote
原文: 夫地形者、兵之助也。料敵制勝、計險阨遠近、上將之道也。
訓読: 夫れ地形は、兵の助けなり。敵を料りて勝を制し、険阨遠近を計るは、上将の道なり。
出典: 地形篇
訳: 地形は戦いの補助にすぎない。敵情を見積もって勝利への道筋を立て、地形の険しさや距離を計算することこそ、優れた将の務めである。
```

```quote
原文: 故戰道必勝、主曰無戰、必戰可也。戰道不勝、主曰必戰、無戰可也。
訓読: 故に戦道必ず勝たば、主は戦う無かれと曰うとも、必ず戦いて可なり。戦道勝たずんば、主は必ず戦えと曰うとも、戦う無くして可なり。
出典: 地形篇
訳: 戦いの道理から見て必ず勝てるなら、君主が戦うなと言っても戦ってよい。勝てないなら、君主が必ず戦えと言っても戦わなくてよい。
```

```quote
原文: 故進不求名、退不避罪、惟民是保、而利於主、國之寶也。
訓読: 故に進みて名を求めず、退きて罪を避けず、惟だ民を是れ保ちて、主に利あるは、国の宝なり。
出典: 地形篇
訳: だから、進撃しても名誉を求めず、退却しても処罰を恐れず、ただ民を守ることだけを考え、それが君主の利益にもなる将こそ、国の宝である。
```

```note
底本（四庫）は「惟民是保，而利於主」で、冒頭に「是」がない。十一家注は「唯人是保，而利合於主」、WS は「是故…唯民是保，而利合於主」。
```

```quote
原文: 視卒如嬰兒、故可與之赴深谿。視卒如愛子、故可與之俱死。
訓読: 卒を視ること嬰児の如し、故に之と深谿に赴くべし。卒を視ること愛子の如し、故に之と倶に死すべし。
出典: 地形篇
訳: 兵を赤ん坊のようにいたわれば、兵は深い谷底へも一緒に行ってくれる。兵をわが子のように慈しめば、生死を共にしてくれる。
```

```note
直後に「愛して令すること能わず…譬えば驕子の如し」と続き、甘やかしは否定される（Q-10-06）。WS は「故可以與之赴深溪」（「以」字あり、「溪」）。
```

```quote
原文: 愛而不能令、厚而不能使、亂而不能治、譬如驕子、不可用也。
訓読: 愛して令すること能わず、厚くして使うこと能わず、乱れて治むること能わずんば、譬えば驕子の如く、用うべからざるなり。
出典: 地形篇
訳: 可愛がるだけで命令できず、手厚く遇するだけで仕事をさせられず、乱れても統制できないなら、わがままな子どものようなもので、使いものにならない。
```

```note
底本（四庫）は「愛而不能令，厚而不能使」の順で、「譬如驕子」と作る。十一家注と WS は「厚而不能使，愛而不能令」の順で、「譬若驕子」と作る。
```

```quote
原文: 故曰、知彼知己、勝乃不殆。知天知地、勝乃可全。
訓読: 故に曰く、彼を知り己を知れば、勝乃ち殆うからず。天を知り地を知れば、勝乃ち全うすべし。
出典: 地形篇
訳: 敵を知り自分を知っていれば、勝利は危うくない。さらに天の時と地の利を知れば、勝利は完全なものになる。
```

```note
十一家注は「勝乃不窮」（勝乃ち窮まらず）。謀攻篇の「知彼知己，百戰不殆」（Q-03-07）とは別の句で、こちらは「天・地」を加えている。
```

## 11 九地篇

```quote
原文: 是故散地則無戰、輕地則無止、爭地則無攻、交地則無絕、衢地則合交、重地則掠、圮地則行、圍地則謀、死地則戰
訓読: 是の故に散地には則ち戦うこと無く、軽地には則ち止まること無く、争地には則ち攻むること無く、交地には則ち絶つこと無く、衢地には則ち交わりを合わせ、重地には則ち掠め、圮地には則ち行き、囲地には則ち謀り、死地には則ち戦う。

```

```quote
原文: 兵之情主速、乘人之不及、由不虞之道、攻其所不戒也。
訓読: 兵の情は速を主とす。人の及ばざるに乗じ、虞らざるの道に由り、其の戒めざる所を攻むるなり。
出典: 九地篇
```

```note
WS は冒頭に「故」がある。
```

```quote
原文: 投之無所往、死且不北。
訓読: 之を往く所無きに投ずれば、死すとも且つ北げず。
出典: 九地篇

```

```quote
原文: 故善用兵者、譬如率然。率然者、常山之蛇也。擊其首則尾至、擊其尾則首至、擊其中則首尾俱至。
訓読: 故に善く兵を用うる者は、譬えば率然の如し。率然とは、常山の蛇なり。其の首を撃てば則ち尾至り、其の尾を撃てば則ち首至り、其の中を撃てば則ち首尾倶に至る。
出典: 九地篇
訳: 用兵の上手な者の軍は、率然という蛇のようである。率然とは常山にいる蛇で、頭を打てば尾が助けに来て、尾を打てば頭が来て、胴を打てば頭と尾がともに来る。
```

```quote
原文: 夫吳人與越人相惡也、當其同舟濟而遇風、其相救也、如左右手。
訓読: 夫れ呉人と越人とは相悪むも、其の舟を同じくして済り、風に遇うに当たりては、其の相救うや左右の手の如し。
出典: 九地篇
訳: 呉の人と越の人は互いに憎み合っているが、同じ舟で川を渡っているときに大風に遭えば、左右の手のように助け合う。
```

```note
成語「呉越同舟」の出典である。原文の主旨は「敵同士が同席すること」ではなく、「已むを得ない状況に置かれれば協力し合う」ことであり、兵を率然のように一体化させる方法の例えとして置かれている。底本（四庫）は「當其同舟濟而遇風」、十一家注と WS は「當其同舟而濟，遇風」。
```

```quote
原文: 投之亡地然後存、陷之死地然後生。
訓読: 之を亡地に投じて然る後に存し、之を死地に陥れて然る後に生く。
出典: 九地篇
訳: 兵は、滅亡するしかない状況に投げ込まれてこそ生き残り、死ぬしかない状況に陥れられてこそ生き延びる。
```

```note
無謀な冒険の勧めではなく、兵の心理を利用した将の統率術として述べられている。軍争篇の「圍師必闕，窮寇勿追」（Q-07-07）と表裏の関係にある。
```

```quote
原文: 是故始如處女、敵人開戶。後如脫兔、敵不及拒。
訓読: 是の故に始めは処女の如くにして、敵人戸を開き、後には脱兎の如くにして、敵拒ぐに及ばず。
出典: 九地篇
訳: だから、初めは乙女のようにおとなしく振る舞って敵に戸を開かせ、その後は逃げ出す兎のような勢いで動けば、敵は防ぐことができない。
```

```note
原文の字形は「脫兔」で、新字体では「脱兎」。「脱兎の如く」は「逃げ足が速い」意味で使われることが多いが、原文では攻撃に転じる素早さを言う。
```

## 12 火攻篇

```quote
原文: 凡火攻有五、一曰火人、二曰火積、三曰火輜、四曰火庫、五曰火隊。
訓読: 凡そ火攻に五有り。一に曰く人を火く、二に曰く積を火く、三に曰く輜を火く、四に曰く庫を火く、五に曰く隊を火く。
出典: 火攻篇
訳: 火攻めには五種類ある。兵営の人員を焼く、野積みの物資を焼く、輸送車両を焼く、倉庫を焼く、そして「隊」を焼くことである。
```

```note
「火隊」の「隊」は、部隊とも輸送路とも解される（諸説あり）。
```

```quote
原文: 夫戰勝攻取、而不修其功者凶、命曰「費留」
訓読: 夫れ戦い勝ち攻め取りて、其の功を修めざる者は凶なり。命けて費留と曰う。
出典: 火攻篇
訳: 戦いに勝ち、城や土地を攻め取っても、その成果を固めて目的を果たさないのは凶である。これを「費留」という。
```

```note
「費留」の語義には諸説ある（費用ばかりが流れ出て留まらない、の意とする解が多い）。
```

```quote
原文: 非利不動、非得不用、非危不戰。
訓読: 利に非ざれば動かず、得るに非ざれば用いず、危うきに非ざれば戦わず。
出典: 火攻篇
訳: 利益がなければ動かず、得るものがなければ兵を用いず、危機が迫っていなければ戦わない。
```

```quote
原文: 主不可以怒而興師、將不可以慍而致戰。
訓読: 主は怒りを以て師を興すべからず、将は慍りを以て戦いを致すべからず。
出典: 火攻篇
訳: 君主は怒りに任せて軍を起こしてはならず、将は憤りに任せて戦いを仕掛けてはならない。
```

```quote
原文: 怒可以復喜、慍可以復悅、亡國不可以復存、死者不可以復生。
訓読: 怒りは以て復た喜ぶべく、慍りは以て復た悦ぶべきも、亡国は以て復た存すべからず、死者は以て復た生くべからず。
出典: 火攻篇
訳: 怒りはやがて喜びに変わり、憤りもまた楽しさに戻る。しかし滅びた国は二度と立て直せず、死んだ者は二度と生き返らない。
```

```quote
原文: 故曰、明主慎之、良將警之、此安國全軍之道也。
訓読: 故に曰く、明主は之を慎み、良将は之を警む。此れ国を安んじ軍を全うするの道なり。
出典: 火攻篇
訳: だから賢明な君主は開戦に慎重であり、優れた将は軽率な戦いを戒める。これが国を安泰にし、軍を保全する道である。
```

```note
底本（四庫）は「故曰：明主慎之」（翻刻の字は異体字の「愼」で、字形表により「慎」とした）。WS は「故明主慎之」、十一家注は「故明君慎之」。同篇前段の「明主慮之，良將修之」とは別の句。
```

## 13 用間篇

```quote
原文: 相守數年、以爭一日之勝、而愛爵祿百金、不知敵之情者、不仁之至也
訓読: 相守ること数年、以て一日の勝を争う。而るに爵禄百金を愛しみて、敵の情を知らざる者は、不仁の至りなり。
出典: 用間篇
訳: 何年も対峙したうえで、たった一日の決戦の勝ちを争うのに、間諜に与える爵位・俸禄・百金を惜しんで敵情を知ろうとしないのは、民を思う心を欠いた最たるものである。
```

```quote
原文: 故明君賢將、所以動而勝人、成功出於衆者、先知也。
訓読: 故に明君賢将の、動きて人に勝ち、成功の衆に出づる所以の者は、先知なればなり。
出典: 用間篇
訳: 賢明な君主や優れた将が、動けば敵に勝ち、人並み外れた成功を収めるのは、前もって敵情を知っているからである。
```

```quote
原文: 先知者、不可取於鬼神、不可象於事、不可驗於度、必取於人、而知敵之情者也。
訓読: 先知なる者は、鬼神に取るべからず、事に象るべからず、度に験すべからず。必ず人に取りて、敵の情を知る者なり。
出典: 用間篇
訳: 事前に知ることは、神霊や占いからは得られず、過去の事例からの類推でも得られず、天体の運行などの計測からも得られない。必ず人から得て、敵の実情を知るのである。
```

```note
「度」を天体の度数（星占いの類）と解するのは、注釈上の一説である。底本（四庫）は「必取於人，而知敵之情者也」と「而」字がある（十一家注と WS にはない）。
```

```quote
原文: 故用間有五、有鄉間、有內間、有反間、有死間、有生間。
訓読: 故に間を用うるに五有り。郷間有り、内間有り、反間有り、死間有り、生間有り。
出典: 用間篇
訳: 間諜の使い方には五種類ある。敵国の住民を使う郷間、敵の役人を使う内間、敵の間諜を寝返らせる反間、偽情報を敵に伝えて命を落とす死間、生還して報告する生間である。
```

```note
十一家注は「因間」（因間有り…）と作る。
```

```quote
原文: 非聖智不能用間、非仁義不能使間、非微妙不能得間之實。
訓読: 聖智に非ざれば間を用うること能わず、仁義に非ざれば間を使うこと能わず、微妙に非ざれば間の実を得ること能わず。
出典: 用間篇
訳: すぐれた知恵がなければ間諜を活用できず、思いやりと正しさがなければ間諜を働かせられず、細やかな洞察力がなければ間諜のもたらす情報の真偽を見抜けない。
```

```quote
原文: 微哉。微哉。無所不用間也。
訓読: 微なるかな、微なるかな、間を用いざる所無きなり。
出典: 用間篇
訳: 実に微妙なものだ。間諜を使わない場面などどこにもない。
```

```quote
原文: 故明君賢將、能以上智為間者、必成大功。此兵之要、三軍之所恃而動也。
訓読: 故に明君賢将の、能く上智を以て間と為す者は、必ず大功を成す。此れ兵の要にして、三軍の恃みて動く所なり。
出典: 用間篇
訳: だから賢明な君主や優れた将で、最高の知性の持ち主を間諜とすることのできる者は、必ず大きな功績を挙げる。これこそ用兵の要であり、全軍がそれを頼りにして動くものである。
```

```note
直前に、殷（商）が興ったとき伊摯が夏におり、周が興ったとき呂牙が商（殷）にいたという例が挙げられている（底本は「呂牙在商」、十一家注と WS は「在殷」）。建国の功臣をも「間」の例として扱っている点が特徴的である。十一家注は冒頭に「惟」がある。
```
