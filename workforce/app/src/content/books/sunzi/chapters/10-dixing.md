# 地形篇 — 地と将の責任

## 負けたのは、地のせいか

前の篇では、鳥の飛び立ち方や使者の口ぶりから敵の動きを読む方法を見ました。この篇は、その目を足もとの地面に向けます。山の高さや道の狭さは、誰にも変えられない条件です。では、その条件のもとで負けたとき、負けは誰のものになるのでしょうか。

たとえば、ある登山隊が下山中に遭難したとします。報告書には「天候の急変」と書かれるかもしれません。ところが調べてみると、悪天候の予報は前日から出ていました。引き返す地点も、地図の上で選べたはずです。雨は確かに降りましたが、雨の中に居続けると決めたのは人の判断です。天候のせいにした報告書からは、次の登山で生かせる教訓が出てきません。原因を外に置くと、直せる部分が見えなくなるからです。

地形篇（ちけいへん）は、この問いに正面から答える篇です。前半で地形を六つの型に分け、型ごとの戦い方を示します。続けて敗北も六つの型に分け、それらは天地の災いではないと言い切ります。地を知ることは欠かせません。しかし地は、負けの言い訳にはなりません。この篇の筋はそこにあります。

本章では、地の分類から始めて、将の責任、兵との関係へと進みます。最後に、謀攻篇の有名な一句がこの篇でどう広がるかを確かめます。

## 六つの地形と、六つの負け方

篇の冒頭は、地形の分類です。孫子は地形を通・掛・支・隘・険・遠の六つに分けました。分ける基準は、山か川かという見た目ではありません。自軍と敵軍がそこへ出入りしやすいかどうか、という関係です。

| 地形 | どんな地か | 対処 |
|---|---|---|
| 通（つう） | 我も彼も行き来できる | 先に高く日の当たる所を占め、補給路を守る |
| 掛（かい） | 行けるが戻りにくい | 敵に備えがなければ出て勝つ。あれば出ない |
| 支（し） | どちらが出ても不利 | 誘われても出ず、退いて敵を半ば出させて撃つ |
| 隘（あい） | 入口が狭い | 先に占めたら兵で満たして待つ |
| 険（けん） | 険しく高低差がある | 先に高所を占める。敵が先なら退く |
| 遠（えん） | 両軍の陣が遠い | 勢いが互角なら、挑んでも不利 |

表を見ると、対処の多くが「先に着いたか、後か」で分かれています。同じ地でも、誰が先に占めたかで正解が逆になるのです。孫子はこれを「地の道」と呼び、見極めることを将の至任（しにん、最も重い任務）としました。

続いて孫子は、負け方にも六つの型があると述べます。走（そう）・弛（し）・陥（かん）・崩（ほう）・乱（らん）・北（ほく）です。走は、勢いが互角なのに一で十に当たり、兵が逃げ散る負けです。弛は、兵が強く吏（り、現場の指揮官）が弱いため、軍がたるむ負けです。陥はその逆で、吏が強く兵が弱いため、兵がついていけずに崩れ落ちます。崩は、上級の幹部が将に服さず、恨みから勝手に戦い、将がその力量を知らない負けです。乱は、将に厳しさがなく、教えが曖昧で、陣が乱れる負けです。北は、将が敵を見積もれず、少数で多数に当たって敗走する負けです。

```quote
原文: 凡此六者、非天地之災、將之過也。
訓読: 凡そ此の六者は、天地の災いに非ず、将の過ちなり。
出典: 地形篇
訳: これら六つの敗北は、天や地がもたらす災いではない。将の過ちである。
```

この一句の要点は、六つの敗北の原因がすべて人の側にあることです。六つを並べ直すと、それがよく分かります。走と北は、敵との力の差を見積もれなかった失敗です。弛・陥・崩・乱は、軍の内部の上下関係が噛み合っていない失敗です。どれも、地形や天候の欄には書き込めません。

特に弛と陥の対は、よくできた観察です。兵が強すぎても、吏が強すぎても、軍は負けます。問題は強さの総量ではなく、上と下の釣り合いです。その釣り合いを整えるのは、人を選び、配置する将の仕事です。だから孫子は、これも将の過ちに数えます。

注目したいのは、この断定が地形の話の直後に置かれていることです。孫子は六つの地形を丁寧に説いた、その同じ口で「負けは地のせいではない」と言います。地形が勝敗に効くことを、孫子は否定していません。効くからこそ、それを読み違えた責任は読む者にある、という順序です。

篇の前段にも「凡そ此の六者は、地の道なり」という似た句があります。そちらは地形の六類を指し、この句は敗兵の六類を指します。二つの「六者」が対になって、地の道と敗の道を左右に並べているのです。なお伝本によっては「天地の災い」を「天の災い」と作るものもあります。どちらで読んでも、責任の所在は変わりません。

## 地は助け、判断は将のもの

では、地形はどれほど重いのでしょうか。孫子の答えは、意外なほど控えめです。

```quote
原文: 夫地形者、兵之助也。料敵制勝、計險阨遠近、上將之道也。
訓読: 夫れ地形は、兵の助けなり。敵を料りて勝を制し、険阨遠近を計るは、上将の道なり。
出典: 地形篇
訳: 地形は戦いの助けにすぎない。敵の実情を見積もって勝ち筋を定め、地の険しさや遠近を計算することこそ、優れた将の道である。
```

「助け」という言葉が、この篇の重心を決めています。地形は主役ではなく、脇役です。主役は、敵を料（はか）る、つまり見積もる判断のほうです。険阨（けんやく、険しく狭い地）も遠近も、計算に入れる材料にすぎません。

ここで順序に注意すると、孫子はまず「敵を料る」と言い、次に「険阨遠近を計る」と言っています。地の計算は、敵の見積もりと組み合わさってはじめて意味を持ちます。前節の表で、同じ隘形でも敵が先か後かで対処が逆になったことを思い出してください。地だけを見ても、正解は出ないのです。

この句のすぐ後に、孫子はさらに踏み込みます。戦いの道理から見て必ず勝てるなら、君主が戦うなと言っても戦ってよい。勝てないなら、君主が戦えと言っても戦わなくてよい。判断の基準を、上の意向ではなく勝敗の見通しに置け、という主張です。そうなると、将は誰の意向にも頼れません。その覚悟を述べたのが、次の一句です。

```quote
原文: 故進不求名、退不避罪、惟民是保、而利於主、國之寶也。
訓読: 故に進みて名を求めず、退きて罪を避けず、惟だ民を是れ保ちて、主に利あるは、国の宝なり。
出典: 地形篇
訳: 進んでも名誉を求めず、退いても処罰を恐れず、ただ民を守ることだけを考え、それが結果として君主の利にもなる。そういう将こそ国の宝である。
```

この句は、前の句と組で読むと意味がはっきりします。君主の命に逆らって戦えば、勝っても「勝手をした」と言われかねません。命に逆らって退けば、罪に問われるかもしれません。それでも名誉のために進まず、処罰を恐れて留まらない。判断の物差しは、ただ民を保つことだけです。

「惟（た）だ」という一字が強く効いています。将の評判や身の安全は、物差しから外されています。そして孫子は、その物差しで動くことが結局は主の利にもなる、と付け加えます。君主への忠誠と民の安全が、ここでは対立していません。

前節の「将の過ち」と合わせると、この篇の将の像が見えてきます。負ければ地のせいにせず、自分の過ちとして引き受ける。勝つためなら命令にも逆らい、その責めも引き受ける。責任を逃げない人にだけ、判断の自由が渡されているのです。

## 慈しむことと、甘やかすこと

篇の後半で、孫子は将と兵の関係に話を移します。ここには、温かい句と冷たい句が並んでいます。

```quote
原文: 視卒如嬰兒、故可與之赴深谿。視卒如愛子、故可與之俱死。
訓読: 卒を視ること嬰児の如し、故に之と深谿に赴くべし。卒を視ること愛子の如し、故に之と倶に死すべし。
出典: 地形篇
訳: 兵を赤ん坊のようにいたわれば、兵は深い谷底へも共に行ってくれる。兵をわが子のように慈しめば、生死を共にしてくれる。
```

嬰児（えいじ）は赤ん坊、深谿（しんけい）は深い谷のことです。赤ん坊を見る目とは、相手の弱さや危うさに気づく目でしょう。わが子を見る目とは、その将来まで案じる目です。孫子は、兵をそう見る将にだけ、兵は極限まで付いてくると言います。

この句は、前節の「惟だ民を是れ保つ」と同じ方向を向いています。将の物差しが民と兵を守ることにあるなら、兵もそれを感じ取ります。深い谷へ赴くのは、命令の強さによってではなく、信頼によってです。

ただし孫子は、ここで話を終えません。すぐ次の句で、同じ愛情が軍を壊すこともあると続けます。

```quote
原文: 愛而不能令、厚而不能使、亂而不能治、譬如驕子、不可用也。
訓読: 愛して令すること能わず、厚くして使うこと能わず、乱れて治むること能わずんば、譬えば驕子の如く、用うべからざるなり。
出典: 地形篇
訳: 可愛がるだけで命令できず、手厚く遇するだけで仕事を任せられず、乱れても正せないなら、わがままに育った子のようなもので、使いものにならない。
```

三つの「能わず」が並んでいます。令する、使う、治める。どれも、愛情とは別の働きです。愛しているのに命じられない、厚遇しているのに任せられない、乱れているのに正せない。そうなった軍を、孫子は驕子（きょうし）にたとえます。

```note
「驕子」は甘やかされた子のことです。愛されていないのではなく、愛されたうえで規律を与えられなかった子を指します。
```

前の句と並べると、孫子の考えがよく見えます。慈しみそのものは否定されていません。否定されているのは、慈しみが命令や統制と切り離されることです。慈しみと規律は、どちらか一方を選ぶものではなく、同時に持つものとされています。前の篇で見た「文と武の併用」が、ここでは親子のたとえで言い直されているとも読めます。

## 彼を知り、天地を知る

篇の結びで、孫子は「勝ちの半分」という言い方をします。自軍が撃てると知っていても、敵が撃てない状態だと知らなければ、勝ちは半分です。敵が撃てると知っていても、自軍が撃てない状態だと知らなければ、やはり半分です。両方を知っていても、地形が戦いに向かないと知らなければ、まだ半分です。

```quote
原文: 故曰、知彼知己、勝乃不殆。知天知地、勝乃可全。
訓読: 故に曰く、彼を知り己を知れば、勝乃ち殆うからず。天を知り地を知れば、勝乃ち全うすべし。
出典: 地形篇
訳: 敵を知り自分を知れば、勝利は危うくならない。そのうえ天の時と地の利を知れば、勝利は完全なものになる。
```

この一句は、謀攻篇の「彼を知り己を知れば、百戦して殆うからず」とよく似ています。殆（あや）うからずとは、危うくない、負けないという意味です。けれども二つは同じ句ではありません。謀攻篇は彼我の二つで止まっていました。地形篇はそこに天と地を加え、「全うす」まで言っています。

前半の「勝乃ち殆うからず」は、負けない状態です。後半の「勝乃ち全うすべし」は、勝ちが欠けずにそろう状態です。彼我を知ることで底が固まり、天地を知ることで勝ちが完成する、という二段の構えになっています。

この句の直前で、孫子は「兵を知る者は、動いて迷わず、事を起こして行き詰まらない」とも述べています。四つの知がそろった将は、迷う理由を持ちません。逆に言えば、迷いが生じるのは、どれかの知が欠けている合図です。勝ちの半分という言い方は、その欠けを数えるための物差しになっています。

ここで篇全体を振り返ると、筋が一本につながります。地形は勝ちを全うするために欠かせない知です。しかしそれは「助け」であり、負けたときの言い訳にはなりません。地を知る責任を負うのは、将だからです。

![図10 六地形と六敗 — 地の型は対処を変え、敗の型はすべて将の過ちに帰る](figures/10-terrain.svg)

図の左には六つの地形を、右には六つの敗北を並べました。左の六つは、どれも「先に占めたか」「出入りできるか」で対処が分かれます。右の六つは、敵の見積もり違いと、軍の内部の不和に分けられます。そして右の六つから出る矢印は、すべて中央の「将」に集まります。地の型が多くても、責任の行き先は一つだという構造です。

図の左右は対称に見えますが、意味は対称ではありません。左の六つは、将が選べない条件です。右の六つは、将が選んだ結果です。選べない条件を正しく読み、選べる行動を誤らない。この篇が将に求めるのは、その二つを取り違えないことだと言えます。

## 異分野への接続

```connect
title: 市場の「地形」——参入障壁と乗り換えの費用
事業の世界にも、地形にあたる条件があります。参入障壁（新しい会社が市場に入るときの壁）や、スイッチングコスト（客が他社に乗り換えるときの手間や費用）です。これらが高いか低いかで、取るべき手は大きく変わります。

参入障壁が高く、入口の狭い市場は隘形に似ています。先に入った会社が販路を満たしていれば、後から追うのは不利です。満たし切れていなければ、入る余地があります。逆に、入るのはたやすいが撤退に大きな費用がかかる市場は掛形に似ています。相手に備えがなければ勝てますが、備えがあれば戻れずに消耗します。

同じ形になるのは、どちらも「動きの損得が、出入りのしやすさと先に占めた者の有無で決まる」からです。違いは、市場の地形は時間とともに動き、参加者自身が作り変えられる点です。山は動きませんが、障壁は低くも高くもなります。
```

```connect
title: 組織心理——安心と要求は別の軸
組織心理学者エドモンドソンらは、職場の状態を二つの軸で捉えました。発言しても罰せられないという心理的安全性と、仕事に求める水準の高さです。安全性が高く水準も高い職場は、学びが進みます。安全性は高いが水準が低い職場は、居心地がよいだけで成果が伸びにくいとされます。

この図式は、孫子の嬰児と驕子の対比と同じ形をしています。どちらも、相手を大切にすることと、相手に求めることを、別々の軸として扱っています。片方だけを高めると、配慮は甘やかしになり、要求は恐怖になります。甘やかしと放任が違うのも、ここから分かります。放任は配慮も要求も低い状態で、驕子は配慮だけが高い状態です。

同じ形になるのは、人が力を出すには「守られている感覚」と「求められている感覚」の両方が要るからです。違いは目的にあります。孫子が求めたのは死地まで共に赴く献身であり、現代の研究が見ているのは、学びと率直な発言です。
```

この篇を一行にまとめるなら、こうなります。地は勝ちを助けるが、負けの理由にはならない。地を読み、兵を慈しみつつ律し、その結果をすべて自分で引き受けるのが将の仕事です。ただ、地形篇の将は、まだ地を外から眺めて選んでいます。では、逃げ場のない地に置かれたとき、兵の心はどう変わるのでしょうか。地形を知る次は、状況そのものが人を変えるという話。
