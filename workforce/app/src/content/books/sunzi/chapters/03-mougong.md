# 謀攻篇 — 戦わずに勝つ

## 勝ち方にも値段がある

戦いが高くつくものなら、勝ち方にも安いものと高いものがあるはずです。作戦篇は、戦いを長引かせることの値段を数えました。謀攻篇はその先へ進み、勝ち方そのものに順位をつけます。

身近な場面で考えてみましょう。同じ通りに、似たパン屋が二軒あるとします。片方が値下げを仕掛け、もう片方も応じます。半年後、一軒が店を閉めました。残った側は「勝った」ことになります。けれども手元に残ったのは、安値に慣れた客と、削れた利益と、疲れた職人です。

別の終わり方もあります。値下げ合戦が始まる前に、片方が相手の店主と話し、店ごと引き継いだとします。職人も常連客も窯も、無傷のまま手に入ります。どちらも「勝ち」ですが、二つの値段はまるで違います。

篇名の「謀攻」とは、謀（はかりごと）によって攻めることです。力ずくではなく、計略で相手を屈させることを指します。この篇の問いは一つです。最善の勝ち方とは何か。孫子の答えは「戦わずに、壊さずに手に入れる」ことです。ただしそれは、戦いを避けて祈ることではありません。比率で手を選び、上流で手を打ち、現場に任せ、自分と相手を知る。そうした地味な手順の積み重ねとして語られます。順に読んでいきましょう。

## 壊さずに、丸ごと手に入れる

```quote
原文: 夫用兵之法、全國為上、破國次之。全軍為上、破軍次之
訓読: 夫れ用兵の法は、国を全うするを上と為し、国を破るは之に次ぐ。軍を全うするを上と為し、軍を破るは之に次ぐ。
出典: 謀攻篇
訳: 戦争の原則として、敵国を無傷のまま降すのが最上で、打ち破るのはそれに劣る。敵軍についても、無傷で降すのが最上で、撃破するのはそれに劣る。
```

篇の冒頭は、勝ち方を測る物差しを示します。「全（まっと）うする」とは、相手を傷つけずに丸ごと保つことです。「破る」は、打ち壊して勝つことです。どちらも勝ちですが、孫子は前者を「上」、後者を「次」と格付けします。

原文はこの後も同じ型をくり返します。国、軍、旅、卒、伍と、単位がだんだん小さくなります。旅・卒・伍は古代の軍の編成単位で、伍は五人ほどの最小の班です。国という最大の単位から五人の班まで、どの規模でも物差しは変わらない。そう念を押しているのです。

なぜ壊さない方が上なのでしょうか。理由は前の篇から読み取れます。壊せば、自分も傷つきます。そして勝ったあとに手に入るのは、壊れた国と散った兵です。丸ごと降せば、相手の土地も民も兵も、そのまま自分の力に加わります。勝利の値打ちを、得たものと払った代価の差で測る。そう考えると、全うするのが上という順位は自然に出てきます。

なお、本書の底本はこの句を「夫用兵之法」で始めますが、他の主な本は「凡用兵之法」（凡そ用兵の法は）と作ります。意味はほとんど変わりません。

```quote
原文: 是故百戰百勝、非善之善者也
訓読: 是の故に百戦百勝は、善の善なる者に非ず。
出典: 謀攻篇
訳: だから、百回戦って百回勝つのは、最善の中の最善ではない。
```

ここは『孫子』の中でも、とくに誤解されやすい一節です。「百戦百勝」は、日本語では理想の強さを表す言葉として使われます。けれども原文は、それを最善ではないと退けています。

理由は前の句から続いています。百回勝ったということは、百回戦ったということです。戦うたびに兵は傷つき、物資は減り、時間が過ぎます。作戦篇で数えた戦いの値段を、百回払っているのです。しかも百回戦わねばならなかったのは、それだけ相手が屈しなかったからでもあります。

原文はこの直後に、最善の姿を続けます。「不戰而屈人之兵、善之善者也」。戦わずして人の兵を屈（くっ）するは、善の善なる者なり、と読みます。戦闘そのものを要らなくすることこそ、最善の中の最善だというのです。

「善の善」という言い方にも目を留めておきましょう。孫子は百戦百勝を「悪い」とは言っていません。善ではあるが、その上にもう一段ある、と言っているのです。これは強さの否定ではありません。強さの使い道の格付けです。

## 上流ほど安い——四つの段と兵力の比

```quote
原文: 故上兵伐謀、其次伐交、其次伐兵、其下攻城。
訓読: 故に上兵は謀を伐つ。其の次は交わりを伐つ。其の次は兵を伐つ。其の下は城を攻む。
出典: 謀攻篇
訳: 最上の戦い方は敵の計画を挫くこと、次は敵の同盟を断つこと、その次は敵の軍と戦うことであり、最も下策は城を攻めることである。
```

では、戦わずに屈させるには何をすればよいのでしょうか。孫子は、手を打つ場所を四つの段に分けます。「伐（う）つ」は、討って挫くことです。

最上は「謀を伐つ」。相手の計画や意図そのものを挫くことです。相手が攻めようと考えた段階で、その考えが成り立たないようにしてしまいます。次は「交わりを伐つ」。相手の同盟や味方を切り離すことです。三番目が「兵を伐つ」、つまり軍と軍の戦闘です。最も下が「城を攻む」、城攻めです。

原文はこの後で、城攻めの値段を具体的に数えています。攻城用の大盾や車をそろえるのに三か月かかります。城壁に迫る土の山を築くのに、また三か月かかります。将が待ちきれずに兵を蟻のように城壁へ取り付かせると、兵の三分の一を失っても城は落ちません。孫子はこれを攻めの災いと呼び、城攻めはやむを得ないときの手段だとしています。

四つの段を並べると、一つの傾きが見えてきます。手を打つ場所が上流、つまり相手の頭の中に近いほど、払う代価は小さくなります。下流、つまり石と土でできた拠点に近いほど、代価は大きくなるのです。

![図3 上兵伐謀の四段階 — 謀・交・兵・城と、段を下るほど増えるコスト](figures/03-four-levels.svg)

図3は、この四つの段を階段として描いたものです。いちばん上が謀、その下に交、兵、城と続きます。段を一つ下りるごとに、払う代価は増えていきます。謀の段で払うのは、主に情報と思考です。交の段では、外交の手間と、相手の味方への働きかけが加わります。兵の段では兵の命と物資を払い、城の段ではそれに加えて何か月もの時間を払います。

この図で大事なのは、上の段が下の段の代わりになることです。謀で勝てば、交も兵も城も要りません。上の段でしくじったときだけ、一つ下の段へ下りる。謀攻篇の戦い方は、この「下りる順番」として読むことができます。

```quote
原文: 故用兵之法、十則圍之、五則攻之、倍則分之、敵則能戰之、少則能守之、不若則能避之。
訓読: 故に用兵の法は、十なれば則ち之を囲み、五なれば則ち之を攻め、倍なれば則ち之を分かち、敵しければ則ち能く之と戦い、少なければ則ち能く之を守り、若かざれば則ち能く之を避く。
出典: 謀攻篇
訳: 兵力が敵の十倍なら包囲し、五倍なら攻め、二倍なら敵を分断し、互角なら力を尽くして戦い、少なければ守りを固め、まったく及ばなければ戦いを避ける。
```

とはいえ、いつも上の段で片がつくわけではありません。実際にぶつかるときの手の選び方を、孫子は兵力の比で示します。「敵（ひと）しければ」は兵力が等しいこと、「若（し）かざれば」は遠く及ばないことです。

十倍なら囲み、五倍なら攻め、二倍なら相手を分ける。互角なら力を尽くして戦い、少なければ守り、とても及ばなければ避ける。手の選び方が、気合いや勇気ではなく、比率という一つの数で決まっていく点が目を引きます。

包囲が十倍のときに限られるのは、囲むには兵を薄く広く配る必要があるからだと考えられます。二倍程度でそのまま当たれば、互いに大きな損害が出ます。そこで相手を分け、その一部に対して数の優位をつくるのです。

原文はこの段を、小勢が意地を張って踏みとどまれば大軍の捕虜になるだけだ、という一句で結びます。劣勢での正面決戦は、勇敢さではなく計算違いとして扱われます。避けることも、比率から導かれる正しい手の一つなのです。

## 君主と将——勝ちを見通す五つの条件

謀攻篇の後半は、話の舞台を戦場から宮廷へ移します。孫子はまず、将を国の輔（たす）けだと言います。輔けとは、支えて補う者のことです。将と国がしっかり噛み合えば国は強く、隙間があれば国は弱くなります。

そのうえで孫子は、君主が軍を害する三つの形を挙げます。

- 一つ目は、進めない状況を知らずに「進め」と命じ、退けない状況を知らずに「退け」と命じることです。軍を縄で縛るようなものだとして、「縻軍（びぐん）」と呼ばれます。
- 二つ目は、軍の内情を知らないまま、軍の行政に口を出すことです。兵は何に従えばよいのか惑います。
- 三つ目は、臨機の判断の仕組みを知らないまま、指揮の任に口を出すことです。兵は命令を疑うようになります。

惑いと疑いが軍に広がれば、隣の諸侯がその隙を突いてきます。孫子はこれを、自分の軍を乱して相手に勝ちを引き寄せることだと言います。三つに共通するのは、現場を知らない者が現場の判断を奪うことです。なお、この段の書き出しは、底本と他の主な本とで語順が入れ替わっています。ただし三つの害の中身は同じです。

```quote
原文: 故知勝有五、知可以與戰不可以與戰者勝、識衆寡之用者勝、上下同欲者勝、以虞待不虞者勝、將能而君不御者勝。
訓読: 故に勝を知るに五有り。以て与に戦うべきと、以て与に戦うべからざるとを知る者は勝つ。衆寡の用を識る者は勝つ。上下欲を同じくする者は勝つ。虞を以て不虞を待つ者は勝つ。将能にして君御せざる者は勝つ。
出典: 謀攻篇
訳: 勝利を見通す条件は五つある。戦うべき時と戦うべきでない時を見分ける者、大軍と小勢それぞれの使い方を知る者、上下が同じ目標を共有する者、備えをもって備えのない敵を待つ者、有能な将に君主が口出ししない者が勝つ。
```

五つの条件を一つずつ見ると、ここまでの内容をまとめ直していることがわかります。一つ目は、戦うべき時とそうでない時を見分けることです。前段の、比率で手を選ぶ考え方そのものです。二つ目は、衆寡（しゅうか）、つまり大軍と小勢の使い分けを知ることです。これも兵力比の話です。

三つ目は、上下が同じものを欲することです。君主と将と兵の目標がそろっている状態を指します。四つ目は、虞（ぐ）、すなわち備えをもって、備えのない相手を待つことです。そして五つ目が、有能な将に君主が御（ぎょ）さない、つまり口を出さないことです。この最後の条件は、前段の三つの害をちょうど裏返したものになっています。

「勝を知る」という言い方には注意が要ります。これは勝つための秘訣ではなく、勝つかどうかを前もって見通す物差しです。戦う前にこの五つで自分と相手を点検すれば、勝負の行方はかなり見えてきます。計篇の廟算と同じく、勝敗を戦場の外で読む発想です。

```quote
原文: 故曰、知彼知己、百戰不殆。不知彼而知己、一勝一負。不知彼不知己、每戰必敗。
訓読: 故に曰く、彼を知り己を知れば、百戦して殆うからず。彼を知らずして己を知れば、一勝一負す。彼を知らず己を知らざれば、戦う毎に必ず敗る。
出典: 謀攻篇
訳: 敵を知り自分を知っていれば、何度戦っても危うくない。敵を知らず自分だけを知っていれば、勝ったり負けたりする。敵も自分も知らなければ、戦うたびに必ず敗れる。
```

篇の最後に置かれたのは、日本でもっともよく知られた『孫子』の一句でしょう。彼を知り己（おのれ）を知れば、百戦して殆（あや）うからず。「殆うからず」は、危うくない、という意味です。

この句は三段の比較になっています。相手も自分も知っていれば、危うくない。自分だけ知っていれば、勝ったり負けたりする。どちらも知らなければ、戦うたびに必ず敗れる。知っていることの量と、結果の確かさが、きれいに比例しています。

ここで、篇の初めの百戦百勝を思い出しましょう。孫子は百戦百勝を最善ではないと退けました。そして篇の終わりに置いたのは、百戦百勝ではなく「百戦殆うからず」です。目指すのは、勝ちを積み上げることではなく、危うさを消すことなのです。知ることで負け筋を消し、勝てない戦いは避ける。だから危うくない。前段の「避く」や「勝を知る」とも、ぴたりと噛み合います。

```note
「知彼知己、百戰不殆」は、しばしば「彼を知り己を知れば百戦百勝」と言い換えられます。しかし原文に「百勝」の字はありません。「不殆」は、危うくない、負けない、という意味です。同じ篇の前半で孫子は百戦百勝を最善ではないと退けていますから、この言い換えは篇の論理を逆さにしてしまいます。なお、地形篇にはよく似た「知彼知己、勝乃不殆」という別の句があり、こちらとも混同されがちです。
```

## 同じ形をした現代の現象

```connect
title: 交渉論——合意しない場合の最善策
交渉の研究には、BATNA という言葉があります。交渉が決裂したときに取れる最善の代わりの手を指す略語で、日本語では「合意しない場合の最善策」と訳されます。1981年に出た交渉術の書物、邦題『ハーバード流交渉術』が広めた考え方です。

たとえば転職の条件交渉で、すでに別の会社から良い内定を得ている人を考えます。この人は、条件が合わなければ席を立てばよいだけです。相手もそれを知っているので、強く値切ることができません。交渉の席で言葉を戦わせる前に、条件の大枠はもう決まっているのです。

これが謀攻篇と同じ形なのは、どちらも勝負がぶつかり合う前に、手の内にある選択肢の強さで決まるからです。強い代わりの手は、相手の「押し切る」という計画そのものを成り立たなくさせます。上兵伐謀の、謀の段で勝っている状態です。

違いもあります。交渉論の目的は、双方が受け入れられる合意を作ることです。孫子の目的は、あくまで相手を屈させることにあります。形は同じでも、向かう先は同じではありません。
```

```connect
title: 規格争い——標準が決まった時点で終わる勝負
同じ働きをする製品に、互いに互換性のない方式が二つ以上あると、どれが標準になるかをめぐる争いが起きます。これを規格争いと呼びます。規格争いの特徴は、使う人が多い方式ほど価値が上がることです。対応する製品や作品が増え、それがさらに利用者を呼びます。

この仕組みのもとでは、勝負は店頭に並んだ製品の出来よりも先に決まります。部品を作る会社、売る店、作品を供給する会社など、どれだけ多くの味方を早く自分の陣営に集めたかで決まるのです。いったん標準が決まると、負けた方式がどれほど優れていても、あとから覆すのはきわめて難しくなります。

1970年代後半から80年代にかけての家庭用ビデオの規格争い（ベータ方式と VHS 方式）は、その例としてよく挙げられます。VHS 方式が広く普及し、ベータ方式の陣営にいた企業も、やがて VHS 方式の機器を作るようになりました。

これが謀攻篇と同じ形なのは、戦場の手前にある「交」、つまり味方の数で勝負が決まるからです。負けた側が勝った側の規格に加わる様子は、相手を壊さずに取り込む「全」にも通じます。違いは、規格争いの勝ちが一人の知恵者の計略で決まるとは限らないことです。多くの企業と利用者の選択が積み重なり、結果として決まることが多いのです。
```

## この篇の一行

謀攻篇を一文に縮めれば、「勝ち方には値段があり、いちばん安いのは戦う前に勝つことだ」となるでしょう。壊さずに手に入れ、上流で手を打ち、比率で手を選び、現場に任せ、彼と己を知る。どれも、ぶつかり合いの手前で勝敗を決めるための工夫です。けれども、相手に働きかける前に、まず自分の側が崩れない構えを持っていなければ、どの段の策も成り立ちません。では、戦う前に勝ちを決めてしまう『形』とは何でしょう。
