# 終章 — 孫子が語らなかったこと

ここまで十三篇を原文で読み、現代の仕事に置き直してきました。読み替えるたびに、「ただし原文はこうは言っていない」と書き添えてきました。この章では、向きを逆にします。原文が語らなかったこと、語れなかったことを数えます。古典の限界を知っておくことは、古典を正しく使うための条件だからです。

## 相手が敵とは限らない

『孫子』のすべての篇は、利害の対立する相手がいることを前提にしています。彼を知り、彼の備えのない所を攻め、彼の計画をくじく。話題が変わっても、向こう側には必ず「敵」がいます。同盟でさえ例外ではありません。謀攻篇は、敵の同盟を断つことを、計画をくじくことに次ぐ策に数えました。九変篇は、他国を害で屈服させ、利で奔走させよと説きます。他者は、動かす対象として描かれています。

ただし、孫子が争いを好んだわけではありません。謀攻篇は戦わずに屈服させるのを最善とし、火攻篇は利がなければ動くなと戒めました。孫子は、争いをできるだけ安く済ませる方法を考えた人です。それでも、争いのない状態をどう作り、どう保つかは、孫子の問いの外にありました。

現代の仕事の多くは、この前提に収まりません。共同研究や業界の標準づくり、部署どうしの協業では、相手の得が自分の損になるとは限りません。両方が得をする道を一緒に探すことが、仕事の中身そのものです。こうした場面に『孫子』の型をそのまま当てはめると、話し合いの席が駆け引きの場に変わります。相手も同じ型で応じれば、本来は分け合えた利益を、互いに削り合うことになります。

呉越同舟の一節は、協力を語っているように見えます。しかし原文の主旨は、逃げ場のない状況に置けば敵同士でも助け合う、という統率の技術でした。協力は、状況によって引き出すものとして扱われています。信頼から協力を育てる道筋は、十三篇の外にあります。

## 欺くことの値段

```quote
原文: 兵者、詭道也。
訓読: 兵は詭道なり。
出典: 計篇
訳: 戦争とは、相手を欺く行為である。
```

詭道とは、相手の認識を操り、判断を誤らせるやり方です。計篇はこの句のあとに、できるのにできないふりをし、近いのに遠いと思わせよ、と続けます。戦場では、これは理にかなっています。欺かれた相手の信頼を取り戻す必要が、繰り返し取引する場ほどには大きくないからです。

しかし、同じ相手と何度も取引する関係では、計算が変わります。一度欺いたことが知られると、その後の言葉はすべて割り引いて聞かれます。約束のたびに確認の手間が増え、取り決めの文書は厚くなり、話は遅くなります。欺いて得た一回の利益より、失った信頼を埋める費用のほうが大きくなりがちです。信頼で動く組織とは、この確認の手間を省けるからこそ速く動ける組織のことです。

注意すべき点が、もう一つあります。九地篇は、将は兵の耳目をふさいで何も知らせず、高い所に登らせて梯子を外すように動かせ、とも書いています。欺く先は敵だけでなく、味方の兵にも及んでいるのです。地形篇は兵をわが子のように慈しめと説くので、孫子が兵を軽んじたわけではありません。それでも、仲間に事情を伏せて動かすことを統率の技術に含めている点は、現代の組織とは相容れません。

## 一度の見積もりと、絶え間ない観測

『孫子』の知は、戦う前に集めるものとして書かれています。計篇の廟算は、開戦前の軍議でした。用間篇の「先知」も、文字どおり先に知ることです。間諜を放って敵情を集め、そのうえで動きます。知ることと動くことは、順番に並んでいます。

もちろん、孫子は変化を軽んじてはいません。虚実篇は、勝ち方を繰り返さず、相手の形に応じて限りなく変えよと説きます。行軍篇は、進軍中の鳥や獣の動きから兆候を読みます。ただ、そこで観測される対象はいつも敵です。自分の打った手の結果を測り、その数字で計画そのものを書き直す。小さく試し、外れたらすぐ引き返す。こうした手順は、十三篇にまとまった形では出てきません。

たとえば、新しい商品を出す場面を考えます。孫子の型なら、出す前に市場を調べ尽くし、勝てると見積もってから出します。けれども、買い手の反応は出してみるまでわからないことが多いものです。そこで小さな版を先に出し、反応を測り、次の版を直します。これは見積もりを捨てることではなく、見積もりを短い間隔で何度も更新することです。廟算を一度で終えず、毎週開き直すと言い換えてもよいでしょう。

今日の仕事では、見積もりは一度では終わりません。市場も道具も数週間で変わり、始める前に知り尽くすことはできないからです。だから、動きながら測り続ける仕組みが要ります。『孫子』の「数える」は残したまま、数える回数と対象を増やす必要があります。

## 死地に投ずる、という一行

```quote
原文: 投之亡地然後存、陷之死地然後生。
訓読: 之を亡地に投じて然る後に存し、之を死地に陥れて然る後に生く。
出典: 九地篇
訳: 兵は、滅亡するしかない状況に投げ込まれてこそ生き残り、死ぬしかない状況に陥れられてこそ生き延びる。
```

亡地も死地も、逃げ場のない場所のことです。九地篇は、退路がなければ兵は死力を尽くすと見て、その状況を将が意図して作ることを説いています。ここで退路を断つのは、兵自身ではなく将です。前の節で見たとおり、兵は事情を知らされないまま、その場所へ連れて行かれます。軍争篇は、包囲した敵には逃げ道を一つ空けておけと説きました。退路のない者は死力を尽くすという同じ観察を、敵には使わせず、味方には使うのです。九地篇の死地は、その裏返しにあたります。

この一節が効くのは、逃げ道が本当に閉じているからです。現代の組織では、その前提が成り立ちません。人は辞めることができ、辞める自由は守られるべきものです。退路を断つような圧力をかけても、返ってくるのは死力ではなく、離職か、悪い知らせを隠す沈黙になりがちです。そもそも、成員を本人の知らないまま危険に置くことは、成果の大小にかかわらず許されません。

用間篇の「死間」も、同じ種類の問題を含みます。偽の情報を持たせて敵に伝えさせ、命を落とすことを織り込んだ間諜です。孫子は情報への投資を説いた点で先を見ていましたが、その勘定には人の命が入っていました。読み替えるとき、ここは持ち帰らない部分です。

## それでも残るもの

```quote
原文: 不可勝在己、可勝在敵。
訓読: 勝つべからざるは己に在り、勝つべきは敵に在り。
出典: 形篇
訳: 負けない態勢をつくれるかは自分次第だが、勝てるかどうかは敵次第である。
```

限界を並べたあとでも、手放さずに済むものがあります。この句はその芯を示しています。自分の手で作れるのは負けない形であり、勝ちは相手と状況に左右されます。だから、まず自分で制御できることに力を注げ、という順序です。向き合う相手が敵ではなく、協業の相手や市場であっても、この区別はそのまま使えます。

形篇の言う「負けない」は、相手を打ち負かすことではなく、相手に崩す手がかりを与えないことでした。協業の場で言えば、守れる範囲だけを約束し、資金や人手に余裕を残しておくことにあたります。そうしておけば、相手の出方がどうであれ、自分の側が崩れることはありません。勝ちを急いで無理を重ねるより、崩れない側に立ち続けるほうが、長い付き合いでは強いのです。

残るものを、四つにまとめておきます。一つめは、動く前に数えることです。勢いで始めず、条件を同じ物差しで比べます（計篇）。二つめは、負けない形を先に作ることです（形篇）。三つめは、知ることへの投資を惜しまないことです。用間篇は、情報への出費を渋る者を「不仁の至り」とまで責めました。四つめは、怒りで決めないことです。火攻篇は、怒りは収まっても、滅んだ国と死者は戻らないと書きました。

どれも、敵がいなくても成り立つ原則です。欺くことも、退路を断つことも必要としません。『孫子』から持ち帰るべきなのは、この四つの規律のほうです。

## 読書案内と、この本の作り方

本書を読み終えたら、別の本で同じ原文を読み直してみると、理解が立体的になります。本書は要所の句を選んで読みましたが、十三篇を通して読むと、句と句のつながりが見えてきます。手がかりとして、本書の調べものが事実の確かめ先に挙げた二冊を記しておきます。まず、金谷治『新訂 孫子』（岩波文庫）があります。次に、平田昌司『『孫子』――解答のない兵法』（岩波書店）も、あわせて読みたい一冊です。

本書は四庫全書本を底本にしたので、ほかの本と字句の違う箇所に出会うことがあります。違いに出会ったら、誤りと決めつけず、伝わってきた系統の違いを疑ってみてください。どの版のどの字かを確かめながら読むことは、本書がいちばん大切にしてきた作法です。

本書の作り方は、同じサイトの Docs にある『本をつくる工程』に記しました。企画から調査、執筆、校閲まで、どの段で何を確かめたかを残してあります。

『孫子』は、戦争は国の大事であり、考え抜かなければならない、という一文で始まりました。考え抜くとは、書かれたことを鵜呑みにすることではありません。古典が語ったことと語らなかったことを分け、使える部分を自分の手で確かめることです。数え、備え、先に知り、怒りで決めない。その規律を手元に残して、この本を閉じます。
