# 九変篇 — 原則を破る原則

## この篇が答える問い

前の篇は「窮した敵を追うな」「囲んだら逃げ道を空けよ」といった禁止の一覧で閉じられていました。七つの篇をかけて、孫子は戦い方の原則をほぼ並べ終えたことになります。ところが第八の篇に入ると、その原則が自分の手で揺さぶられます。

身近な場面で考えてみます。カーナビが最短経路として示した道が、大雨で冠水していたとします。案内の規則は「最短の道を選べ」で、ふだんはそれで正しく動きます。けれども目の前の水を見ている運転者は、案内に従わないほうが正しいと知っています。規則を作った側には、この水が見えていないからです。

九変篇が扱うのは、まさにこの瞬間です。「変」とは、定石を状況に合わせて変えることを指します。篇の冒頭で孫子は、通りにくい土地（圮地）には宿営しない、交通の要所では外交を結ぶ、逃げ場のない土地では戦う、といった土地ごとの定石を手短に示します。そしてすぐに、その定石の外側へ踏み出します。

九変篇は全十三篇の中でも短い篇です。それでも、規則と例外の関係についての議論が、短い分だけ凝縮されています。この章の問いは一つです。ルールはいつ破ってよいのか。孫子の答えは「いつでも」ではありません。破ってよい条件と、破る者が自分に向けるべき警戒の両方を、短い篇の中に詰め込んでいます。

## 原文を読む

```quote
原文: 途有所不由、軍有所不擊、城有所不攻、地有所不爭、君命有所不受。
訓読: 途に由（よ）らざる所有り、軍に撃たざる所有り、城に攻めざる所有り、地に争わざる所有り、君命に受けざる所有り。
出典: 九変篇
訳: 通ってはならない道があり、攻撃してはならない敵軍があり、攻めてはならない城があり、奪い合ってはならない土地があり、受けてはならない君主の命令もある。
```

五つの句はすべて「〜に、〜しない所が有る」という同じ形をしています。道は通るためにあり、敵軍は撃つためにあり、城は攻めるためにあります。その当たり前を一つずつ取り上げ、例外があると告げているのです。ここで言う「例外」とは、規則が想定した前提が崩れている場合のことです。

五つ目だけが性質を異にします。前の四つは戦場の対象についての例外ですが、最後の一句は命令そのものについての例外です。君主は都にいて、戦場の地形も敵の動きも見えていません。見えている者が判断し、見えていない者の命令は退けることもある。これが一句の骨組みです。

ただし、この句は君主への不服従一般を認めたものではありません。篇の書き出しは、将が君主から命令を受けて軍を編成する場面です。命令系統は前提として残っています。そのうえで、現場の判断を将に委ねる余地を残せと言っているのです。なお、導入で触れた『史記』の女官の練兵の逸話でも、同じ趣旨の言葉が語られます。

篇は続けて、こう述べます。九変の利に通じた将こそが用兵を知る者であり、地形をよく知っていても九変に通じなければ、地の利は得られない。地形の知識は地図のようなもので、地図を持っていることと、地図にない水たまりを避けられることは別の能力だ、という指摘です。

篇はさらに、兵を治めるのに九変の術に通じなければ、五つの利を知っていても人を十分に働かせられない、とも続けます。ここでの「五利」が何を指すかには諸説あり、直前の五つの「しない」を指すという読み方がよく知られています。どの読み方をとっても、要点は同じです。規則の一覧を覚えることと、規則を外すべき場面を見抜くことは、別々に身につける必要があるということです。

```quote
原文: 是故智者之慮、必雜於利害、雜於利而務可信也、雜於害而患可解也。
訓読: 是の故に智者の慮（おもんぱか）りは、必ず利害に雑（まじ）う。利に雑えて務め信（の）ぶべきなり。害に雑えて患い解くべきなり。
出典: 九変篇
訳: だから知恵ある者は、必ず利益と損害の両面を合わせて考える。不利な状況でも利の面を考えるから事をやり遂げられ、有利な状況でも害の面を考えるから災いを未然に解ける。
```

では、例外を見分ける目はどこから来るのか。孫子はそれを「雑」という一字で答えます。雑とは、二つのものを混ぜ合わせることです。利だけを見る判断も、害だけを見る判断も、片目で見ているのと同じだと言っているのです。

前半は、苦しい状況の中にも利を探せということです。害ばかりを見ていると、手を打つ前に諦めてしまいます。後半はその逆で、順調なときこそ害を探せということです。利ばかりを見ていると、災いの芽に気づくのが遅れます。

この考え方は、最初の一節とまっすぐにつながっています。「通るべき道」は利の面から見た規則です。そこに害を混ぜて見るから、「通ってはならない道」が見えてきます。原則を破る判断は、気分や反抗心からではなく、利害の両面を同時に数えた結果として出てくるべきものです。篇はこのあと、害を示せば他国は屈し、利で釣れば奔走する、と相手の利害計算を動かす方法にも触れます。利害を両面で見る目は、自分の判断にも相手の操作にも使えるということです。

```quote
原文: 故用兵之法、無恃其不來、恃吾有以待之。無恃其不攻、恃吾有所不可攻也。
訓読: 故に用兵の法は、其の来たらざるを恃（たの）むこと無く、吾が以て待つ有るを恃む。其の攻めざるを恃むこと無く、吾が攻むべからざる所有るを恃むなり。
出典: 九変篇
訳: 用兵の原則は、敵が来ないことを当てにせず、敵が来ても対応できる自分の備えを当てにすること。敵が攻めてこないことを当てにせず、攻められても崩れない自分の態勢を当てにすることである。
```

原則を破る篇の中に、ここだけは破ってはならない原則が置かれています。「恃む」とは、頼りにすること、安心の根拠にすることです。孫子は、安心の根拠をどこに置くかを問題にしています。

「敵は来ないだろう」という見込みは、敵の行動に安心を預けています。敵の行動は自分では決められません。「敵が来ても待ち受ける用意がある」という状態は、自分の手の内にあります。前者は外れたときに何も残りませんが、後者は外れても崩れません。

例外を認める篇で、この一節が置かれる理由はここにあります。現場で裁量を使えば、予想外の事態に出会う機会は増えます。そのとき頼れるのは予想の正しさではなく、備えの厚さです。なお十一家注本では、前半の末尾を「待つ也」とする本文が伝わります。意味はほぼ変わりません。

```quote
原文: 故將有五危、必死、可殺。必生、可虜。忿速、可侮。廉潔、可辱。愛民、可煩。
訓読: 故に将に五危有り。必死は殺すべく、必生は虜（とりこ）にすべく、忿速（ふんそく）は侮るべく、廉潔は辱（はずかし）むべく、愛民は煩（わずら）わすべし。
出典: 九変篇
訳: 将には五つの危険な性向がある。死ぬ覚悟ばかりの者は討ち取られ、生き延びることばかり考える者は捕らえられ、短気な者は挑発に乗せられ、清廉さにこだわる者は侮辱で動かされ、民を思いやりすぎる者は振り回される。
```

篇の最後で、孫子は視線を敵から将自身へ移します。「五危」とは、将の性格に潜む五つの危険です。並べ方が巧みで、必死と必生は正反対の性向なのに、どちらも危険に数えられています。

必死、つまり死ぬ覚悟は、ふつうは勇気として称えられます。けれども死を恐れない将は、無謀な突撃に誘い出されて討たれます。必生、つまり生き延びることへの執着は、慎重さに見えます。けれども命を惜しむ将は、ここぞという場面で退き、捕らえられます。忿速は怒りっぽく性急なことで、挑発すれば動きます。決断の速さは本来、将の長所の一つです。それが怒りと結びつくと、相手が決めた時機に動かされることになります。

注目すべきは残りの二つです。廉潔、つまり清廉さと、愛民、つまり民への思いやりは、どちらもはっきりした美徳です。清廉な将は名誉を傷つけられると冷静さを失い、民を思う将は民を苦しめられると軍を動かさずにいられません。孫子は美徳そのものを否定してはいません。度を越した美徳は、敵にとって操作のための取っ手になると言っているのです。

```quote
原文: 覆軍殺將、必以五危、不可不察也。
訓読: 軍を覆（くつがえ）し将を殺すは、必ず五危を以てす。察せざるべからざるなり。
出典: 九変篇
訳: 軍が全滅し将が討たれるのは、必ずこの五つの危険からである。よく考えなければならない。
```

篇の結びは強い言い切りです。軍の壊滅は「必ず」五危による、と孫子は書きます。直前では、この五つは将の過ちであり、用兵の災いであるとも述べています。敗因を敵の強さや天候ではなく、指導者の内側に求めているのです。

この結びは、篇の前半と一対になっています。前半で孫子は、将に君命すら退ける裁量を認めました。裁量が大きいほど、判断する者の偏りは結果に直結します。命令に縛られた将なら、性格の偏りは命令が吸収してくれます。命令から自由な将は、自分の偏りを自分で見張るしかありません。

だから九変篇は、原則を破る自由を与える篇であると同時に、その自由を使う者への警告の篇でもあります。原則を破ってよいのは、利害を両面で見て、備えに安心を置き、自分の性向を疑える者だけだ、というのが篇全体の構えです。

## 構造を図で見る

九変篇の論理は、二つの層でできています。外側の層は「規則と例外」です。五つの「しない」は、規則の前提が崩れた場面を見分けよという指示でした。内側の層は「例外を扱う者の資格」です。利害を混ぜて考える目、来ないことではなく備えを恃む姿勢、そして自分の美徳が過ぎていないかを疑う習慣が、その資格にあたります。

図10はこの内側の層の最後の部分、五危を一枚にしたものです。美徳や長所に見える五つの性向と、それが過ぎたときの危険を対にして並べています。必死と必生のように正反対の性向が、どちらも危険の側に落ちる構造に注目してください。

![図10 将の五危 — 五つの性向と、過ぎたときに敵が突く弱点の対](figures/08-five-dangers.svg)

対の危険の側を原文で読むと、すべて敵が将に対して行う動作になっています。殺す、虜にする、侮る、辱める、煩わす。五危とは、敵が将の性格を読んで仕掛ける手の一覧でもあるのです。

```connect
title: ソフトウェアの例外処理
プログラムは、ふつう「正常系」を中心に書かれます。正常系とは、入力が想定どおりで、外部の仕組みも期待どおりに応える場合の処理の流れです。けれども実際には、通信が切れたり、ファイルが見つからなかったりします。そこで想定外の事態を「例外」として扱う仕組みが用意されています。

設計の要点は、例外をどこで受け止めるかです。よく言われる原則は、意味のある対処ができるだけの情報を持った場所で受け止めよ、というものです。低い層で起きた失敗を、事情を知らない上の層が一律に処理すると、的外れな対応になります。

これは九変篇の君命の一句と同じ形をしています。どちらも、前もって書かれた規則は書き手が知らない状況を扱えないので、状況が見えている場所に判断を預けるという構造だからです。冠水した道を見ているのは運転者であり、切れた通信を知っているのはその通信を扱う部分です。

逆の失敗も同じ形です。あらゆる例外を黙って握りつぶす処理は、どんな命令も受けない将に似ています。裁量の範囲は狭く、例外は記録して上に知らせる。この規律があって初めて、例外処理は役に立ちます。

違いもあります。プログラムの例外は、多くの場合あらかじめ種類が列挙されています。設計者が想定した「想定外」の一覧だと言えます。孫子の九変は、列挙しきれない事態を人の判断で扱うことを前提にしています。
```

```connect
title: リスク管理 — 想定ではなく備え
リスク管理の実務では、一つのリスクを「起きる確率」と「起きたときの影響」の二つに分けて見積もります。確率が低いからと影響の大きいリスクを放置するのは、典型的な失敗とされています。

事業継続計画は、この考えを形にしたものです。主要な仕入れ先が止まったら、拠点が使えなくなったら、どうやって業務を続けるか。計画が問うのは「止まらないだろうか」ではなく、「止まっても続けられるか」です。

これは「其の来たらざるを恃むこと無く、吾が以て待つ有るを恃む」と同じ形をしています。どちらも、安心の根拠を自分では動かせない相手の行動から、自分で整えられる備えへ移すという操作だからです。来るか来ないかは敵が決めますが、待ち受ける用意は自分が決められます。

この形の強みは、予測が外れても崩れないことです。確率の見積もりは、情報が乏しいときほど当てになりません。備えの厚さは、見積もりの誤差に左右されません。

違いもあります。リスク管理では、すべてに備える費用は払えないので、確率を使って備えの優先順位をつけます。九変篇のこの一節は、備えの費用や優先順位には触れていません。
```

## 誤解されやすい点

```note
九変の「九」は、九つという数を指すのではなく、「多くの」「あらゆる」という意味で読むのが一般的です。古代中国語では、九が数の極みとして「きわめて多い」ことを表す用法があります。実際、篇の冒頭に並ぶ土地の定石は五つ、続く「しない」も五つで、九つには揃いません。後世の注釈家たちは九つを数え上げようと試みてきましたが、数え方には諸説あります。
```

## この篇の一行

九変篇を一文にすれば、「原則は破ってよいが、破る資格は、利害を両面で見て、備えに安心を置き、自分の美徳を疑う者にしかない」となります。

前の七篇が「何をすべきか」を教えたとすれば、この篇は「それをしない判断」を誰に、どの条件で許すかを教えました。そして許された者には、最も厳しい自己点検を課しています。

ただし、判断を許されたことと、判断の材料を持っていることは別です。冠水した道を避けられるのは、水が見えている運転者だけでした。現場の将に裁量を預ける意味は、将が現場を見ているところにあります。見ていなければ、裁量はただの気まぐれになります。では、現場の将は、何を見て判断すればよいのでしょうか。
