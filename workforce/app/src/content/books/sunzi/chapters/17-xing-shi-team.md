# 後編 III 「形」と「勢」をつくる — 勝ってから着手するチーム

前章では、数えたうえで「始める」と決めるところまでを読みました。ここから先は、決めたことをどう実行に移すかという話です。

よくある場面を一つ置きます。あるチームが新しい仕組みづくりを任され、月曜日に着手しました。ところが最初の二週間は、作業環境の権限待ち、誰が仕様を決めるのかの確認、予算の承認で過ぎていきます。三週目に動き出したころには、締め切りまでの余裕がほとんど残っていません。メンバーは懸命に働きますが、遅れは個人の努力では取り戻せない形で積み上がっていきます。

この場面で欠けていたのは、意欲でも能力でもありません。着手の前に整えておくべき態勢と、着手の後に力を流す仕組みです。『孫子』はこの二つを、形篇の「形（けい）」と勢篇の「勢（せい）」として論じています。形とは、戦う前に整えておく態勢のことです。勢とは、整えた態勢を動かしたときに生まれる力のことです。この章では二つの篇から四つの一節を選び、一般のプロジェクトとチームに当てはめて読みます。その際、原文が何を言い、現代にどう読め、原文が何を言っていないかを、毎回分けて書きます。

## 勝ってから着手する — 「先勝」の順序

```quote
原文: 是故勝兵先勝而後求戰、敗兵先戰而後求勝。
訓読: 是の故に勝兵は先ず勝ちて而る後に戦いを求め、敗兵は先ず戦いて而る後に勝ちを求む。
出典: 形篇
訳: だから勝つ軍は、まず勝てる態勢を整えてから戦いに臨む。負ける軍は、まず戦い始めてから勝ちを探す。
```

形篇の後半に置かれた一節です。「而る後に」は「そうしてから」という意味です。直前で孫子は、本当の戦上手の勝利は目立たず、智謀の名声も勇敢の功績も残らないと述べています。勝つ条件がすでに揃っているので、勝利が当たり前に見えるからです。この一節はその結論で、勝敗は開戦の前にほぼ決まっているという順序の主張です。

原文はこう言っています。勝つ軍は勝てる態勢を先につくり、負ける軍は戦いながら勝ち筋を探す、と。現代では、チームが着手日を決める前に、勝てる条件を揃えておくことと読めます。ただし原文は、準備さえすれば必ず勝てるとは言っていません。次の一節が示すとおり、勝ちの半分は相手の側にあります。また原文が語るのは軍の態勢であり、会議や作業手順のことは書かれていません。

チームの「先勝」に当たる準備は、おおむね三つに分けられます。

- 環境：作業に必要な道具、権限、データに、初日から手が届く状態
- 合意：何を作り、誰が決め、何をもって終わりとするかが言葉になっている状態
- 資源：人の時間と予算が、名目ではなく実際に確保されている状態

冒頭のチームは、この三つを着手の後に探しに行きました。形篇の言葉を借りれば、「先ず戦いて而る後に勝ちを求む」側に立っていたことになります。

三つが揃っているかどうかは、着手の前に確かめられます。たとえば着手日の前日に、初日に最初の作業を誰が何から始めるかを、具体的に言えるかを問います。答えが「権限が届いたら」「方針が決まったら」で始まるなら、まだ形はできていません。この確認は手間に見えますが、着手後に同じことを探す手間に比べれば小さなものです。準備の不足は、着手してから見つかるほど高くつきます。

## 自分で制御できる部分を先に固める

```quote
原文: 不可勝在己、可勝在敵。
訓読: 勝つべからざるは己に在り、勝つべきは敵に在り。
出典: 形篇
訳: 負けない態勢をつくれるかは自分次第だが、勝てるかどうかは敵次第である。
```

形篇の冒頭近くの一節です。「勝つべからざる」は、敵がこちらに勝てない状態、つまり負けない態勢を指します。孫子はすぐ後で、善く戦う者でも負けない態勢はつくれるが、敵を必ず勝てる状態にさせることはできない、と続けます。そこから「勝は知るべくして、為すべからず」という言葉が出てきます。勝てるかどうかは見通せても、無理につくり出すことはできない、という意味です。さらに負けない側は守り、勝てる側は攻めに対応づけられます。なお底本の翻刻はこの「己」を「已」と作っており、本書は文意と他本によって「己」に改めた本文を使っています。

原文はこう言っています。負けない態勢は自分の手の内にあり、勝てる隙は相手の側にある、と。現代では、チームが制御できる部分と制御できない部分を分け、制御できる部分から先に固めることと読めます。手順の確認、引き継ぎの仕組み、品質の点検は前者です。市場の反応、顧客の判断、他部署の決定は後者です。ただし原文は、相手次第の部分を放っておけとは言っていません。勝ちは「知るべく」、つまり観察して見通すものです。待つことは、見ずに待つことではありません。

組織の仕事を観察すると、計画の遅れが「制御できない部分」の読み違いよりも、「制御できた部分」の手当て漏れから生じている場面がよく見られます。権限の申請、レビューの担当者、障害時の連絡先は、どれもチームの内側で決められることです。形篇の順序に沿えば、この内側を先に固め、そのうえで外側を観察することになります。

外側を観察する仕組みも、内側で用意できます。顧客の声を定期的に聞く場を決める、他部署の予定を早めに知る窓口を置く、といった工夫です。相手の隙そのものはつくれませんが、隙が見えたときに気づける目は、自分の側でつくれます。形篇の「不敗の地に立ちて、敵の敗を失わざる」という句は、守りを固めることと、相手の崩れを逃さないことを並べて述べています。チームに置き換えれば、固めることと見張ることは、どちらも着手前の仕事です。

## 「勢」は配置とタイミングから生まれる

```quote
原文: 故善戰者、其勢險、其節短。勢如彍弩、節如發機。
訓読: 故に善く戦う者は、其の勢は険にして、其の節は短なり。勢は弩を彍くが如く、節は機を発するが如し。
出典: 勢篇
訳: だから戦上手は、勢いを鋭く高め、それを放つ間合いを短くする。勢いは引き絞った弩のようであり、間合いは引き金を引く一瞬のようである。
```

勢篇は、形篇でつくった態勢を、戦場での力に変える方法を説く篇です。この一節の直前には二つのたとえがあります。激しい流れが石を押し流すのが「勢」、猛禽が一撃で獲物を砕くのが「節」です。弩は機械仕掛けの弓で、彍くは弦を引き絞ること、機は引き金です。「険」は鋭く高いこと、「節」は力を放つ間合いのことです。つまり勢は溜められた力で、節はそれを一瞬で解き放つ時機を指します。

原文はこう言っています。戦上手は勢いを高く溜め、放つ間合いを短くする、と。現代では、役割の配置と仕事の順序で力を溜め、リリース日や判断の会議という節目で短く放つことと読めます。ただし原文は、締め切りを短くせよとも、会議を減らせとも言っていません。節の短さは溜めた力を逃がさない放ち方のことで、仕事全体の期間の長短とは別の話です。

チームに置き換えると、勢をつくる要素は二つあります。一つは役割の配置です。勢篇の終わりには、木や石は平らな所では止まり、傾いた所では動き、角ばったものは止まり、丸いものは転がる、という観察があります。人にも、置かれた位置で自然に動ける場所と、止まってしまう場所があります。もう一つは仕事の順序です。調査が終わる前に設計の会議を開けば、議論は堂々巡りになります。材料が揃った直後に会議を置けば、決定は短く済みます。

そして節は、その力を放つ一点です。リリース日、判断の会議、顧客への提示などが当たります。節が長いとは、リリースを小出しに延ばしたり、結論の出ない会議を重ねたりすることです。そのあいだに、溜めた力は少しずつ抜けていきます。

節を短くするには、節の前に何を済ませておくかを決めておく必要があります。リリース日の前に点検と告知の準備を終えておけば、当日の作業は切り替えだけで済みます。判断の会議の前に資料と選択肢を配っておけば、会議の時間は決めることだけに使えます。節が短いチームとは、節の前が厚いチームのことです。ここで勢篇は、形篇の「先勝」とつながります。

この篇には、見落とされやすい一句もあります。「乱は治に生じ、怯は勇に生じ、弱は強に生ず」です。混乱は秩序の中から、臆病は勇気の中から、弱さは強さの中から生まれる、という意味です。現代では、整って見えるチームほど、その見え方に安心して点検を怠り、乱れの芽を育てやすいと読めます。ただし原文は「過信に注意せよ」とは言っていません。続く文は「治乱は数なり」で、治まるか乱れるかは編制という数の問題だ、と述べるだけです。

この読み方を実務に移すなら、見え方を管理することになります。進捗表がすべて順調を示している時期こそ、その表が何を数えていないかを点検します。作業の完了数は数えていても、未解決の問いの数は数えていないかもしれません。会議で反対意見が出なくなったときは、合意が深まったのか、言い出しにくくなったのかを確かめます。整った見え方は、それ自体が成果ではなく、点検の対象の一つです。

```note
「乱は治に生ず」には、整った軍だからこそ乱れたふりができる、と偽装の意味で読む注釈もあります。本章の「見え方の管理」という読み方は現代の当てはめであり、原文の唯一の解釈ではありません。
```

## 人を責めず、仕組みに求める

```quote
原文: 故善戰者、求之於勢、不責之於人、故能擇人而任勢。
訓読: 故に善く戦う者は、之を勢に求めて、之を人に責めず。故に能く人を択びて勢に任ず。
出典: 勢篇
訳: だから戦上手は、勝利を全体の勢いに求め、個々の兵の能力に負わせない。だからこそ適材を選び、勢いに任せることができる。
```

勢篇の結びに近い一節です。「之（これ）」は勝利、つまり成果を指します。「責めず」はここでは、非難しないという意味よりも、「負わせない」「求めない」という意味に近い語です。直後に、勢に任せる者が兵を戦わせるさまは木や石を転がすようだと続きます。篇は「円石を千仞の山に転ずる」というたとえで終わります。千仞はきわめて高いことで、丸い石も高い山の上に置けば、小さな力で止められない運動になります。なお十一家注本などの他本は「不責於人」と作り、「之」の字がありませんが、意味は変わりません。

原文はこう言っています。戦上手は成果を勢に求め、個々の兵に負わせない、と。現代では、失敗や遅れが起きたとき、個人の努力不足や落ち度を問う前に、配置と順序と節目を見直すことと読めます。ただし原文は、人は誰でもよいとも、責任を問うなとも言っていません。同じ文の中に「人を択びて」とあり、人を選ぶことは前提です。人を選んだうえで、その人に個人の奮闘を求めずに済む状況をつくる、という順序です。

冒頭のチームに戻ります。三週目から懸命に働いたメンバーにもっと頑張れと求めても、遅れは縮みません。変えるべきは、権限が着手後に届く段取りであり、決める人が決まっていない合意の形です。振り返りの場で個人の名前ではなく仕組みの名前を挙げることは、勢篇の考え方に近い習慣です。

一方で、「人を択びて」の半分を忘れると、この読み方は崩れます。仕組みを整えても、丸い石を置くべき場所に角ばった石を置けば転がりません。誰がどの役割で自然に動けるかを見て配置することは、勢をつくる仕事の一部です。人を選び、選んだ人を傾いた場所に置き、あとは勢に任せる。現代のチームに置き換えれば、勢篇の結びはこの三つの手順として読めます。

## 構造を図で見る — 形から勢、勢から節へ

![図19 形→勢→節 — 着手前に固める態勢、配置と順序が溜める力、短く放つ節目](figures/17-form-momentum.svg)

図19は、この章の流れを三段で示しています。最初の段が「形」で、環境・合意・資源という、自分で制御できる部分を着手前に固めます。次の段が「勢」で、役割の配置と仕事の順序によって、固めた態勢を動く力に変えます。最後の段が「節」で、リリース日や判断の会議という一点で、その力を短く放ちます。形篇と勢篇を順に読むと、この一本の流れになります。

```connect
title: 製造業の段取り替え
工場で一台の機械を別の製品向けに切り替える作業を、段取り替えと呼びます。日本の工場では、この切り替え時間を大きく縮める手法が磨かれてきました。要点は、作業を二つに分けることです。機械を止めなければできない作業を「内段取り」、機械が動いているうちにできる作業を「外段取り」と呼びます。

改善の第一歩は、内段取りだと思われていた作業のうち、外に出せるものを洗い出すことです。次の金型を機械の脇に運んでおく。必要な工具を使う順に並べておく。調整の値を前もって測っておく。こうして準備を前に出すと、機械を止める時間そのものが短くなります。止まる時間が短ければ、ラインの流れは途切れません。

段取り替えと形篇・勢篇が同じ形をしているのは、どちらも決定的な一瞬の前に、自分で制御できる準備をすべて済ませ、その一瞬を短くする構造だからです。外段取りは「先ず勝つべからざるを為す」に当たり、短い停止は「其の節は短なり」に当たります。違いは、工場の段取り替えには相手がいないことです。孫子は態勢を整えたうえで相手の隙を待ちますが、工場は準備が終われば自分の都合で切り替えを始められます。
```

## この章の一行

形篇と勢篇をチームの言葉で一文にすると、こうなります。自分で制御できる部分を着手前に固め、配置と順序で力を溜め、短い節目で放ち、うまくいかないときは人ではなく仕組みを見直す。原文が語っているのは軍の態勢と勢いであり、この一文は現代への当てはめです。それでも、勝ってから着手するという順序は、規模を問わずチームの仕事に通じます。ただし、態勢と勢いが整っても、力を放つ場所が悪ければ勝ちは得られません。では、整えた力を、どこへ向ければよいのでしょうか。
