# 火攻篇 — 道具と自制

## 強い道具を手にしたとき

道具の話は、火から始まります。古代の戦場で、火はもっとも威力の大きい道具のひとつでした。いったん燃え広がれば、兵の数や陣形の巧拙に関係なく、敵の宿営も食料も焼き尽くします。しかも火は、放った側にも完全には制御できません。

この篇でいちばん目を引くのは、火の技術そのものではありません。篇の後半で話題が急に変わり、「戦いを始めてよいのはいつか」という問いに移ることです。火攻めの手順を細かく述べたあとで、篇は怒りに任せて軍を動かすなと書きます。

この並びには意味があると読めます。強い道具を持つほど、使いたくなる場面は増えます。そして、使ったあとに取り返せないことも増えます。性能の高い道具ほど、結果を左右するのは使う側の判断の質なのです。

では、強い道具を手にした人を止めるものは何か。火攻篇はその答えを、技術の外側に置いています。止めるのは道具の欠点ではなく、使う人の「慎み」です。火の技術から順に、その慎みがどう組み立てられているかを読んでいきます。

## 原文を読む

篇は、火攻めの対象を五つに分けるところから始まります。

- 火人：敵の宿営にいる兵員を焼く
- 火積：野に積んだ食料や物資を焼く
- 火輜：輜重（しちょう）、つまり物資を運ぶ車両を焼く
- 火庫：倉庫を焼く
- 火隊：「隊」を焼く。部隊とも輸送路とも解され、諸説あります

並べてみると、兵員を直接狙うのは火人と、解釈によっては火隊だけです。残りは兵站（へいたん）、つまり軍を養い動かす仕組みに向いています。火は、敵の体よりも、敵が戦い続ける力を断つ道具として考えられています。

続いて篇は、火を放つには条件があると述べます。火種と道具は前もって備えておくこと。時期は空気の乾いた季節を選ぶこと。日は風の起こる日を選ぶこと。月が特定の星宿にある日を風の日とする、古代の天文の知識も添えられています。さらに、敵陣の中で火が上がったら外から素早く呼応すること、風上で燃えているのに風下から攻めないこと、と運用の注意が続きます。

ここから見えるのは、強い道具ほど「使える時」が狭いということです。乾き、風、内と外の呼応。条件がそろわなければ、火はただの火事か、自分に返ってくる炎になります。

技術の部分の締めくくりに、篇は火と水を比べます。火で攻撃を助けるのは「明」、水で助けるのは「強」だというのです。そして、水は敵を断ち切ることはできても、奪うことはできない、と続けます。

水は堤を切れば敵を分断し、孤立させられます。しかし水が引けば、敵の資源はそこに残ります。火は違います。焼いたものは戻りません。「明」には、効果がはっきり目に見えるという意味を読む解釈があります。

ここに、篇の後半への伏線があります。火の強さは、その不可逆性（元に戻せない性質）にあります。そして元に戻せないことは、使う側にとっても同じです。

```quote
原文: 夫戰勝攻取、而不修其功者凶、命曰「費留」
訓読: 夫れ戦い勝ち攻め取りて、其の功を修めざる者は凶なり。命けて費留と曰う。
出典: 火攻篇
訳: 戦いに勝ち、城や土地を攻め取っても、その成果を固めて本来の目的につなげなければ、凶である。これを「費留」という。
```

この一節から、篇は技術の話を離れます。「修める」は、得た成果を整え、本来の目的の達成までつなげることです。戦いに勝つことと、勝った結果を国の利益に変えることは別の仕事だ、という指摘です。

「費留（ひりゅう）」の語義には諸説あります。費用ばかりが流れ出て、手元に何も留まらない、と取る解釈が多く見られます。いずれにしても、勝利が浪費に変わる状態に付けられた名前です。

火攻めの直後にこの一節が置かれていることは示唆的です。火は勝つための強力な手段です。しかし手段が強いほど、勝つこと自体が目的にすり替わりやすくなります。焼いた、奪った、という手応えが、「それで何を得たのか」という問いを押しのけるのです。

組織の研究でも、測りやすい指標が本来の目標と取り違えられる現象が報告されています。成果の手応えは、目的の代わりにはなりません。この一節は、その取り違えに「凶」という強い言葉で警告を発しています。

```quote
原文: 非利不動、非得不用、非危不戰。
訓読: 利に非ざれば動かず、得るに非ざれば用いず、危うきに非ざれば戦わず。
出典: 火攻篇
訳: 利益がなければ動かず、得るものがなければ兵を用いず、危機が迫っていなければ戦わない。
```

三つの短い句が、三つの関門のように並んでいます。動く、兵を用いる、戦う。行動が重くなるにつれて、求められる理由も「利がある」「得るものがある」「危機が迫っている」と厳しくなる、と読むことができます。

とくに最後の「危うきに非ざれば戦わず」は強い言い方です。戦うのは、戦わなければ危うくなるときだけだ、という意味になります。勝てそうだから戦う、という発想とは向きが逆です。

篇は少し後でも、利に合えば動き、合わなければ止まる、と同じ趣旨を繰り返します。ここで基準になっているのは利であって、勢いや面子ではありません。言い換えると、行動を起こす側に説明の責任があるという構えです。何もしないことには理由が要らず、動くことにだけ理由が要るのです。

```quote
原文: 主不可以怒而興師、將不可以慍而致戰。
訓読: 主は怒りを以て師を興すべからず、将は慍りを以て戦いを致すべからず。
出典: 火攻篇
訳: 君主は怒りに任せて軍を起こしてはならず、将は憤りに任せて戦いを仕掛けてはならない。
```

「師」は軍隊のことです。君主には戦争を始める決定が、将には個々の戦闘を始める決定があります。この一節は、その二つの層それぞれに、感情を引き金にするなと言っています。

「怒」と「慍（うん）」は使い分けられています。怒はかっと燃え上がる怒り、慍は胸の内にくすぶる不満や恨み、と説明されることが多い字です。急な怒りも、長く溜まった憤りも、どちらも開戦の理由にはならないということです。

注意したいのは、この一節が感情を持つこと自体を否定していない点です。君主も将も怒ります。禁じられているのは、その怒りを「興す」「致す」という行動の起点にすることです。

行動科学の研究では、怒りの状態にある人は先行きを楽観的に見積もり、危険を小さく感じやすいと報告されています。怒りは、慎重さを削る方向に働きやすい感情です。その意味で、この禁止は精神論ではなく、判断の誤りが起きやすい条件を名指ししたものと読めます。

```quote
原文: 怒可以復喜、慍可以復悅、亡國不可以復存、死者不可以復生。
訓読: 怒りは以て復た喜ぶべく、慍りは以て復た悦ぶべきも、亡国は以て復た存すべからず、死者は以て復た生くべからず。
出典: 火攻篇
訳: 怒りはやがて喜びに変わり、憤りも晴れて楽しさに戻る。しかし滅びた国は二度と立て直せず、死んだ者は二度と生き返らない。
```

四つの句が、二つずつ対になっています。前の二つは「戻れるもの」、後の二つは「戻れないもの」です。「復」は「ふたたび」「元に戻る」という字で、四句すべてに置かれています。同じ字を並べることで、戻れるかどうかの違いがくっきり浮かび上がります。

この一節の要点は、時間のずれにあります。怒りは時間がたてば喜びに戻ります。ところが、怒っているあいだに下した決定の結果は戻りません。一時的な状態で、永続する結果を生む決定を下す。そこに危うさの核心があります。

前の一節と合わせると、論理はこうなります。感情は戻る。戦争の結果は戻らない。だから戻るものを理由に、戻らないものを始めてはならない。火の不可逆性を語った篇が、最後に人の命と国の存続という、もっとも不可逆なものに行き着いているのです。

```quote
原文: 故曰、明主慎之、良將警之、此安國全軍之道也。
訓読: 故に曰く、明主は之を慎み、良将は之を警む。此れ国を安んじ軍を全うするの道なり。
出典: 火攻篇
訳: だから賢明な君主は開戦に慎重であり、優れた将は軽率な戦いを戒める。これが国を安泰にし、軍を保全する道である。
```

篇の結びです。君主には「慎む」、将には「警む」という動詞が割り当てられています。慎むは、始める前に立ち止まること。警むは、軽はずみな戦いを自らに禁じることです。前の一節と同じく、二つの層に一つずつの役目が置かれています。

「軍を全うする」の「全」は、謀攻篇が重んじた、相手も自分も損なわずに目的を果たすという考え方と響き合います。勝つことではなく、国と軍を保つことが目的だと、篇はここで改めて確かめています。

火攻篇の答えは明快です。強い道具を持つ人を止めるのは、道具の限界ではありません。戻れない結果を前にして立ち止まる、使う人の慎みです。

## 構造を図で見る

![図14 可逆と不可逆 — 怒りは喜びに戻れるが、滅んだ国は存続に戻れない](figures/12-irreversible.svg)

図14は、戻れるものと戻れないものを左右に並べたものです。左側では、怒りが喜びへ、憤りが悦びへと矢印が戻っています。右側では、亡国から存続へ、死者から生へと向かう矢印が途中で断たれています。

二つの列のあいだにあるのが「決定」です。感情は左の列に属し、時間とともに元の位置へ帰ってきます。決定の結果は右の列に属し、一度動けば帰ってきません。図の要点は、左の列の状態で右の列の扉を開けてはならない、という一点です。

篇の前半にある火と水の対比も、同じ図の上に置けます。水は断つが奪わない、つまり戻せる余地を残します。火は焼き尽くし、戻せません。火攻篇は、技術の話から開戦の是非まで、一本の軸で貫かれているのです。

## 異分野への接続

```connect
title: 意思決定の「一方通行の扉」
経営の世界には、決定を二種類の扉にたとえる考え方があります。一度くぐると引き返せない「一方通行の扉」と、くぐっても戻ってこられる「戻れる扉」です。ある企業経営者が株主への手紙で広めた比喩として知られます。

戻れる扉なら、小さく早く試し、まずければ引き返せばよい。一方通行の扉なら、時間をかけ、情報を集め、慎重に決める。決定の重さを、結果を元に戻せるかどうかで測るという発想です。失敗の多くは、戻れる扉の前で迷い続けることと、一方通行の扉を軽く開けることから生まれる、と説かれます。

火攻篇と同じ形をしているのは、慎重さの量を「戻せるかどうか」で配分するという構造が共通しているからです。違いは、孫子が扉の種類だけでなく、扉の前に立つ人の状態を問題にした点です。どれほど扉を正しく分類できても、怒りの中ではその分類を見誤ります。
```

```connect
title: 「熱い状態」と「冷たい状態」のずれ
行動科学には、感情が高ぶった「熱い状態」と、落ち着いた「冷たい状態」のあいだで、人が互いを正しく想像できないという知見があります。落ち着いているときは、怒りや空腹が自分の判断をどれほど動かすかを小さく見積もります。逆に高ぶっているときは、その感情がずっと続くかのように振る舞います。

この「ずれ」への対策として、社会はいくつかの仕組みを作ってきました。訪問販売などの契約を一定期間内なら取り消せるクーリング・オフ制度はその代表です。怒りのままに書いたメールは一晩おいてから送る、という職場の知恵も同じ発想です。熱い状態で下した決定を、冷たい状態で見直す機会を確保しているのです。

火攻篇と同じ形なのは、一時的な状態が永続する結果を生む、という時間差の構造が共通しているからです。違いは、クーリング・オフが決定を後から戻せる仕組みを用意できるのに対し、戦争にはそれが無いことです。だから孫子は、出口ではなく入口で止めるしかなかったのです。
```

## 誤解されやすい点

```note
火攻篇の末尾は、火という篇の主題を超えた一般論になっています。そのため、この部分を兵法全体の結語として読む解釈があります。用間篇がこのあとに続くため配置としては最後ではありませんが、戦争そのものへの態度を述べた締めくくりとして重く見られてきました。
```

```note
篇の結びの少し前に「明主は之を慮（おもんぱか）り、良将は之を修む」という似た句があり、混同されやすい箇所です。結びの句は「慎」と「警」で、別の句です。また、結びの句の字句は、十一家注本では「明主」が「明君」となるなど、わずかな異同があります。
```

## この篇の一行

火攻篇を一文にまとめるなら、こうなります。強い道具ほど、戻れない結果を生むのだから、戻る感情で使ってはならない。

篇は五つの火と、時と日の選び方から始まりました。そして勝利を固めることの大切さ、利と得と危という三つの関門、怒りと慍りの禁止を経て、明主の慎みと良将の警めに至ります。技術を語り尽くしたあとで、その技術を使わない理由を語る。この順序そのものが、道具と自制の関係を示しています。

ただし、慎むためには、何が利で何が危かを見分けなければなりません。敵は何を考え、どこが弱いのか。それが分からなければ、動くべきか止まるべきかも決められません。最後の篇は、ここまでのすべての前提、つまり「知る」ことを扱います。敵の実情は、どうすれば手に入るのでしょうか。
