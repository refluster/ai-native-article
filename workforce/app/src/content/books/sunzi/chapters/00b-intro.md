# 孫子とは何か — 人・本・時代

## 春秋の終わり、呉の国で

『孫子』という本の向こうには、一人の人物と一つの時代があります。著者とされるのは、孫武（そんぶ）という人です。書名の「子」は先生を意味する敬称で、『孫子』とは「孫先生の書」という意味になります。『論語』の孔子や『老子』と同じ呼び方です。時代は紀元前6世紀の終わりごろ、中国の春秋時代の末期にあたります。春秋時代とは、周王朝の権威が弱まり、多くの国が並び立って争った時代のことです。孫武は斉（せい）の出身と伝えられますが、呉の人とする説もあります。

伝記の主な出どころは、前漢の司馬遷が書いた歴史書『史記』です。その「孫子呉起列伝」によれば、孫武は呉王闔閭（こうりょ）に仕えました。闔閭の即位は前515年で、重臣の伍子胥（ごししょ）が孫武を推薦したとされます。

『史記』には有名な逸話があります。闔閭に腕前を試された孫武は、宮中の女官たちを兵に見立てて訓練しました。号令に笑って従わない女官たちを前に、隊長役に立てた王の寵姫二人を斬らせたといいます。すると女官たちは、一糸乱れず動くようになったという筋です。

ただし、この話は説話的で、史実とは考えにくいとする見方が有力です。さらに、同時代の記録である『春秋左氏伝』には孫武の名が見えません。このため南宋の学者・葉適（しょうせき）以来、孫武の実在そのものを疑う説もあります。この論争は、いまも決着していません。

本の成立は、紀元前5世紀中ごろから前4世紀中ごろと推定されています。孫武の残した原型に、後継者たちが手を加えていったと考えられています。『孫子』は、一人の天才が一気に書き上げた本ではなさそうです。何世代かの手を経て磨かれた思考の結晶と見るほうが、実態に近いでしょう。

```note
本書では、確証のない年代や人物の事績を「〜と伝えられます」「諸説あります」と書き分けます。孫武が呉王に仕えたこと、女官を練兵した逸話、その生没年は、いずれも確かな史料では裏づけられていません。『史記』の記述は、史実と伝説の両方を含むものとして読んでください。
```

## 二千年を旅した本文

古代中国の本は、紙ではなく竹の札に書かれていました。これを竹簡（ちっかん）と呼びます。細長い札に文字を書き、紐で綴じて巻いたものです。紐が切れれば札はばらばらになり、順序が乱れることもありました。

前漢の宮廷の蔵書目録である『漢書』芸文志（げいもんし）は、「呉孫子兵法」を82篇・図9巻と記録しています。いま読まれている13篇よりも、はるかに大きな本でした。現在の13篇の形は、後漢末の曹操が整理して注をつけた『魏武注孫子』（200年ごろ）にもとづきます。注とは、本文の語句に添えた解説のことです。三国志で知られる曹操は、みずから軍を率いた武将でした。実戦を指揮する人が手を入れた本文が、その後の基準になったわけです。私たちが読む13篇は、この時点で形がほぼ定まったと考えてよいでしょう。

その後、唐と宋の注釈者たちの解説を集めた「十一家注」（十家注とも）が成立します。北宋では1072年に、武官の採用試験で兵書が出題されるようになりました。1083年ごろには『孫子』『呉子』『六韜』など7つの兵書が「武経七書」として校訂されます。校訂とは、複数の写本を比べて本文を定める作業です。清代になると、学者の孫星衍（そんせいえん）が十家注本（1797年）と平津館本（1800年）を刊行しました。こうして、注釈を集めた系統と、武経七書の系統という二つの大きな流れができあがります。本書が底本、つまり本文の拠りどころに使う四庫全書本は、武経七書の系統に属します。

1972年には大きな発見がありました。山東省臨沂（りんぎ）の銀雀山（ぎんじゃくざん）にある前漢の墓から、竹簡の『孫子』が出土したのです。これにより、伝わってきた『孫子』が古い形をほぼ保っていることが確かめられました。

本文が二千年残るとは、写し手が何十代にもわたって写し継いだということです。そのたびに、書き誤りや言い換えが入る余地がありました。それでも骨格が崩れなかったのは、多くの人が実用の書として繰り返し読み、比べ合ってきたからでしょう。系統ごとの細かな字句の違いは今も残っており、本書でも各章で紹介します。

```connect
ソフトウェアでは、ある時点のプログラムから別の版が枝分かれし、それぞれに修正が積み重なります。二つの版を並べれば、どの行がどう違うかという「差分」を取り出せます。写本も同じです。親本を写した子本が生まれ、その子本からさらに孫本が生まれます。写すたびの一字の違いが、差分として残っていきます。

たとえば謀攻篇のある一節は、四庫全書本では「夫用兵之法」、十一家注では「凡用兵之法」と始まります。有名な「知彼知己」の句の結びも、「每戰必敗」と「每戰必殆」の二通りが伝わります。校訂者の仕事は、こうした差分を並べて、どちらを採るかを判断することです。これは、枝分かれした版を一つにまとめる統合の作業によく似ています。銀雀山の竹簡は、失われていた古い版が見つかったようなものです。

違いは一点です。ソフトウェアの版管理では、誰がいつ何を変えたかが記録されています。写本にはその履歴がありません。文献学者は、残された差分から系譜を逆算するしかないのです。
```

## 十三篇の地図

『孫子』は13の篇からできています。篇とは、章にあたるまとまりです。本書では、日本で通りのよい篇名を使います。計篇・作戦篇・謀攻篇・形篇・勢篇・虚実篇・軍争篇・九変篇・行軍篇・地形篇・九地篇・火攻篇・用間篇の13篇です。底本の篇題では計篇を「始計」、形篇を「軍形」、勢篇を「兵勢」と呼ぶため、その名で見かけることもあります。

13篇は、内容から四つの群に分けると見通しがよくなります。この分け方は原文にあるものではなく、本書の読み方です。

- 戦う前に考える（計篇・作戦篇・謀攻篇）：開戦を判断し、費用を見積もり、戦わずに勝つ道を探ります。
- 力の原理（形篇・勢篇・虚実篇）：負けない態勢、勢いの生み方、主導権の握り方を論じます。
- 戦場で動く（軍争篇・九変篇・行軍篇・地形篇・九地篇）：行軍、地形、臨機応変の判断を扱います。
- 特別な手段（火攻篇・用間篇）：火による攻撃と、間諜（かんちょう、スパイ）による情報収集を説きます。

全体は、判断から原理へ、原理から現場へ、そして特別な手段へと進みます。最初が戦場ではなく「戦うかどうか」の判断で始まり、最後が情報の篇で終わります。この並びに、この本の性格がよく表れています。

![図1 十三篇の構造 — 判断・原理・現場・特別な手段の四群に分けた十三篇の流れ](figures/00b-structure.svg)

ここで、『孫子』の言葉として最もよく引かれる句の一つを、予告として見ておきます。

```quote
原文: 兵者、詭道也。
訓読: 兵は詭道なり。
出典: 計篇
訳: 戦争とは、相手を欺く行為である。
```

「兵」はここでは兵士ではなく、戦争や軍事そのものを指します。「詭」は偽る・欺くという意味で、「詭道（きどう）」は欺きの方法のことです。わずか五文字ですが、『孫子』の性格を象徴する句として広く知られています。

注意したいのは、この句の置かれた場所です。『孫子』の冒頭はこの句ではなく、「兵は国の大事」という一節から始まります。戦争は国の存亡を分けるので、よく考え抜けという前置きです。そのあと、勝敗を見積もる五つの軸と七つの問いが並び、欺きの話はその後に出てきます。

つまり順序は、まず冷静に数え、そのうえで実戦を欺きによって運用する、というものです。この句は「卑怯であれ」という勧めではありません。相手の見積もりを誤らせることが戦いの運用原理だ、という観察です。続く文では、できるのにできないように見せる、近いのに遠いと思わせる、といった型が並びます。詳しくは計篇の章で読みます。

## 日本での読まれ方

『孫子』が日本へいつ、誰の手で伝わったかは、はっきりしません。遣唐使として唐に渡った吉備真備（きびのまきび）が兵法を学び、持ち帰ったという話があります。しかしこれは推測にとどまり、伝説として扱うべきものです。

史料で確かめられる最古の受容は、『続日本紀（しょくにほんぎ）』の天平宝字4年（760年）の記事です。大宰府にいた吉備真備のもとへ、『孫子』の兵法を学ばせるために下級の武官が派遣されたと記されています。少なくともこの時点で、真備が『孫子』を教えられる立場にあったことはわかります。

中世の合戦は、武士一人ひとりの技量の集まりという性格が強いものでした。そのため中国の兵書としては、むしろ『六韜（りくとう）』や『三略』が重んじられました。

戦国時代には、武田信玄が軍争篇の一節を旗に記したとされます。これが「風林火山」として知られる言葉です。旗の字句は「疾如風、徐如林、侵掠如火、不動如山」と伝わり、古くは「孫子四如の旗」と呼ばれました。ただし原文はここで終わらず、「難知如陰、動如雷震」と続きます。風林火山は、六つの比喩のうち前の四つを抜き出したものなのです。

江戸時代に入ると、1606年に伏見版として初めて印刷されました。その後、林羅山の『孫子諺解』、山鹿素行の『孫子諺義』、荻生徂徠の『孫子国字解』など、50を超える注釈書が生まれます。『孫子』は、江戸の兵学を支える柱の一つになりました。大きな合戦の絶えた泰平の世に、兵書がこれほど熱心に注釈されたことになります。実戦の手引きである以上に、学問の対象として読み込まれたのです。

明治以降、軍の教育は西洋式に改められましたが、『孫子』は古典として読み継がれます。戦後は教養書やビジネス書として広く読まれるようになりました。防衛大学校などでは、クラウゼヴィッツの『戦争論』と並ぶ教材とされています。

## 世界へ、そして現代へ

『孫子』の翻訳の歴史も長いものです。現存する最古の翻訳は、12世紀ごろの西夏語訳です。18世紀初頭には、清朝で満洲語訳とモンゴル語訳が作られました。

西洋への入口は、イエズス会の宣教師アミオでした。アミオは満洲語版にもとづく抄訳を、1772年にパリで刊行しました。英訳は1905年のカルスロップ訳が最初で、1910年にはジャイルズ訳が出ています。

ナポレオンがアミオの仏訳を愛読した、という話は広く流布しています。しかしこの話は、1922年にフランス軍のショレ大佐が初めて言及したもので、裏づけはないとされます。伝説として受け取るのが妥当です。ドイツ皇帝ヴィルヘルム2世が退位後に読み、「20年早く読んでいれば」と悔やんだという逸話もあります。こちらも、いつのことかには諸説あります。

20世紀には、英国の軍事史家リデル・ハートが『戦略論』の巻頭に『孫子』を引きました。リデル・ハートはクラウゼヴィッツと対比して、正面からぶつからない間接的な戦略を称えました。中国では毛沢東が『矛盾論』や『持久戦論』で『孫子』を引用しています。現代では、経営戦略論やゲーム理論の分野でも論じられています。

これほど多くの言語と時代を越えられた理由の一つは、本文の書き方にあると考えられます。『孫子』には、特定の合戦の記録や武将の手柄話がほとんど出てきません。語られるのは、比べる、見積もる、隠す、集める、といった判断の型です。固有の場面に縛られない分、読み手は自分の置かれた状況に引き寄せて読むことができました。その反面、原文に無い意味まで読み込まれやすいという危うさもあります。本書が原文から読むことにこだわるのは、そのためです。

## 兄弟の兵書たち

最後に、『孫子』の周りにある兵書との関係を整理しておきます。銀雀山の墓からは、『孫子』と一緒に『孫臏兵法（そんぴんへいほう）』も出土しました。孫臏は戦国時代の斉の軍師で、出土したのは竹簡440枚、全30篇です。出土以前は、現行の『孫子』の著者を孫臏とみる説が有力でした。二つが別々の書物として出てきたことで、孫武を著者とする説が有力になりました。

『呉子』は、呉起（またはその門人）の兵書です。『韓非子』に「孫・呉の書を蔵する者は家ごとに之有り」とあり、戦国後期にはすでに「孫呉」と並び称されていました。現存するのは6篇です。『六韜』は、太公望呂尚が周の文王・武王に兵学を説くという設定の兵書です。実際の作者が太公望の名に託した、いわゆる仮託の書と考えられています。文・武・龍・虎・豹・犬の六つの巻からなり、「虎の巻」の語源とされます。『呉子』と『六韜』は武経七書に入っていますが、『孫臏兵法』は入っていません。兄弟の兵書と比べると、『孫子』の簡潔さと抽象度の高さがいっそう際立ちます。

人と本と時代の輪郭が、これで見えてきました。最初の問いは、戦うかどうかをどう決めるか、です。それでは第一篇、計篇から読みはじめます。
