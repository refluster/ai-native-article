# 勢篇 — 勢いをつくる

## 同じ人数で、なぜ結果が違うのか

その力に、孫子は「勢（せい）」という名を与えました。前の篇で語られたのは、戦う前に勝てる態勢を整えることでした。高い所に水をためるように、有利な落差を先に作っておく話です。けれども、ためた水はそこにあるだけでは何も動かしません。落差を、実際に相手を押し流す力へ変える仕組みが要ります。

身近な例として、学校の大縄跳び大会を考えてみます。同じ三十人のクラスでも、続けて跳べる回数は大きく違います。運動の得意な子が多いクラスが勝つとは限りません。並び順、回し手の位置、跳び込む合図の声がそろったクラスは、一人ひとりの脚力を合わせた以上に跳び続けます。

記録が伸びないとき、私たちはつい「あの子が引っかかったから」と個人を責めたくなります。人は失敗の原因を、状況よりも本人の性質に求めがちです。しかし、引っかかる子がいつも同じ位置で出るなら、問題は子どもではなく並び方のほうにあります。

勢篇が答える問いは、まさにこれです。同じ兵力で、なぜ結果が違うのか。孫子の答えは、兵の勇気や能力の差を探す前に、全体の配置とタイミングが生む力を見よ、というものです。この章では、その力がどう作られ、どう放たれるのかを、原文の順に読んでいきます。

## 原文を読む

勢篇は、勢そのものを語る前に、四つの基礎技術を並べるところから始まります。大軍を小部隊のように扱うための技術です。

- 分数（ぶんすう）：部隊を何人ずつに分けるかという編制のこと。大勢を少人数と同じように治められるのは、これによります。
- 形名（けいめい）：旗や太鼓などの指揮信号のこと。大勢を少人数と同じように戦わせられるのは、これによります。
- 奇正（きせい）：正攻法と奇策の組み合わせのこと。全軍が敵の攻撃を受けても負けないのは、これによります。
- 虚実（きょじつ）：手薄な所と充実した所のこと。砥石を卵に投げつけるような一方的な打撃は、これによります。

この並びには順序があります。まず組織を分け、次に信号でつなぎ、そのうえで正と奇を使い分け、最後に相手の弱い所へ力を集めます。勢は、この四つが積み重なった上に初めて生まれます。気合いや根性という言葉は、この一覧のどこにも出てきません。

```quote
原文: 凡戰者、以正合、以奇勝。
訓読: 凡そ戦いは、正を以て合い、奇を以て勝つ。
出典: 勢篇
訳: およそ戦いは、正攻法で敵と向き合い、奇策で勝ちを決める。
```

「正」は、定石どおりに正面から相手を受け止める動きです。「奇」は、側面や時間差など、相手の予想の外から決着をつける動きです。「合う」は、敵と向き合って組み合うことを指します。

大事なのは、二つが分業になっている点です。奇策だけで勝とうとすると、相手は落ち着いて対処できます。正面の部隊が相手をしっかり受け止め、注意と兵力をそこへ引きつけるからこそ、奇が効きます。

行動の面から見ても、これは筋が通っています。人の注意は、一度にすべての方向へは向きません。正面の圧力が強いほど、相手の目はそこに吸い寄せられ、脇が空きます。つまり奇の成功は、正の働きに支えられています。

もう一つ見落とされやすいのは、正が決して「地味な脇役」ではないことです。正面で相手を受け止め続けるには、崩れない規律が要ります。先ほどの分数と形名、つまり編制と信号が整っていなければ、正はすぐに押し返されます。奇の華やかさは、正の地道さの上に成り立っています。

ここで「正は表の部隊、奇は裏の部隊」と固定して覚えると、次の一節で足をすくわれます。孫子は、この二つが互いに入れ替わり続けるものだと続けるからです。

```quote
原文: 戰勢不過奇正、奇正之變、不可勝窮也。
訓読: 戦勢は奇正に過ぎざるも、奇正の変は、勝げて窮むべからざるなり。
出典: 勢篇
訳: 戦いの勢いは奇と正の二つしかないが、その組み合わせが生む変化は数え尽くせない。
```

この一節の直前で、孫子は身近な例を三つ並べています。音の基本は五つしかないのに、その組み合わせは聞き尽くせません。色の基本も五つ、味の基本も五つですが、その変化は見尽くせず、味わい尽くせません。戦いも同じで、要素は奇と正の二つだけなのに、組み合わせは無限だというのです。

さらに原文は、奇と正は互いを生み、端のない輪のように巡ると述べます。奇策を上手に出す者は天地のように尽きず、大河や海のように涸れない、とも言います。ある一手が奇として効くのは、相手がそれを予想していないあいだだけです。一度見せた奇は、次からは相手にとって想定内の正になります。そう読むと、奇正は部隊の名前ではなく、相手の予想との関係を表す言葉だとわかります。

「勝（あ）げて窮（きわ）むべからず」は、数え上げて終わりにすることはできない、という意味です。手の数が尽きないのは、手持ちの要素が多いからではありません。少ない要素を、相手の予想に合わせて組み替え続けるからです。

相手の側から見ると、この仕組みはさらにはっきりします。同じ型が何度か続くと、人はそれを規則として学び、次も同じだろうと身構えます。学んだ規則が強いほど、そこから外れた一手は大きく効きます。正を続けることは、相手に規則を覚えさせ、奇の効き目を高める準備にもなっているのです。

```quote
原文: 故善戰者、其勢險、其節短。勢如彍弩、節如發機。
訓読: 故に善く戦う者は、其の勢は険にして、其の節は短なり。勢は弩を彍くが如く、節は機を発するが如し。
出典: 勢篇
訳: だから戦上手は、勢いを鋭く高め、それを放つ間合いを短くする。勢いは引き絞った弩のようであり、間合いは引き金を引く一瞬のようである。
```

この一節の前に、孫子は二つの絵を置いています。激しい水の流れが、重い石まで押し流してしまう。これが勢です。猛禽が急降下して、一撃で獲物を打ち砕く。これが節です。

「節（せつ）」は、力を放つ間合い、区切りの一瞬を指します。「険（けん）」は、坂が急で鋭いことです。「弩（ど）」は、機械仕掛けで矢を放つ大型の弓、いしゆみです。「彍（ひ）く」は弦をいっぱいに引き絞ること、「機（き）」は引き金を指します。

勢と節は、別の働きをしています。勢は時間をかけて溜めるもので、高く、鋭いほどよい。節は放つ瞬間で、短いほどよい。弦を引き絞っても、引き金がゆっくり動くなら矢は弱々しく飛びます。猛禽も、獲物の手前でためらえば逃げられます。

間合いが長いと、相手に身構える時間を与えてしまいます。同じ力でも、相手が準備を終える前に届くかどうかで、効き目はまったく違ってきます。溜めは長く、放ちは一瞬。この非対称こそが勢篇の中心にある考え方です。

なぜ普通の弓ではなく、弩が喩えに選ばれたのでしょうか。弓は、引き絞った状態を人の腕で保たなければならず、長くは溜めておけません。弩は仕掛けで弦を留めておけるので、溜めることと放つことを切り離せます。力を蓄える時間と、放つ時間を別々に設計できる。勢と節の関係を示すには、ちょうどよい道具だったと読めます。

```quote
原文: 亂生於治、怯生於勇、弱生於強。
訓読: 乱は治に生じ、怯は勇に生じ、弱は強に生ず。
出典: 勢篇
訳: 混乱は秩序の中から生まれ、臆病は勇気の中から生まれ、弱さは強さの中から生まれる。
```

直前の原文は、乱戦の場面を描いています。旗が入り乱れ、混戦に見えても、整った軍は乱されません。渾然として形がつかめないようでも、陣が丸くまとまっていれば崩れません。そのうえでこの一節が来ます。「怯（きょう）」は、おびえ、臆病のことです。

読み方は二通りあります。一つは、秩序も勇気も強さも固定した性質ではなく、条件しだいで反転する状態だという読みです。勝って気が緩めば、秩序はそこから崩れます。もう一つは、偽装の読みです。乱れたふりや弱いふりは、本当に整い、強い軍にしかできないというものです。

どちらの読みでも、見え方は作れる、という点は共通しています。原文はこの後、治乱は編制の問題、勇怯は勢の問題、強弱は形の問題だと整理します。勇気も臆病も、個人の性格というより、置かれた流れの結果だというのです。行動科学の目で見ても、同じ人が集団の流れしだいで勇敢にも臆病にもなることは、珍しくありません。

さらに孫子は、敵を動かすのが上手な者は、形を見せて相手を従わせ、餌を与えて取らせると続けます。利で相手を動かし、こちらは備えて待つのです。

```quote
原文: 故善戰者、求之於勢、不責之於人、故能擇人而任勢。
訓読: 故に善く戦う者は、之を勢に求めて、之を人に責めず。故に能く人を択びて勢に任ず。
出典: 勢篇
訳: だから戦上手は、勝利を全体の勢いに求め、個々の兵の能力に負わせない。だからこそ適材を選び、勢いに任せることができる。
```

「責（せ）む」は、ここでは叱ることではなく、結果を負わせる、求めるという意味です。勝利を一人ひとりの奮闘に求めない。全体の流れの中に求める。これが前半の主張です。

後半の「人を択びて勢に任ず」を読み落とすと、誤解が生まれます。孫子は、人はどうでもよいと言っているのではありません。人は選ぶ。そのうえで、選んだ人を勢に乗せる、という順序です。個人に頼らないからこそ、個人を適所に置く余裕が生まれます。

大縄跳びの例に戻ります。「あの子のせいだ」と責めても、次の回の記録はほとんど変わりません。並び順を変え、合図をそろえれば、同じ顔ぶれのまま記録が伸びることがあります。個人を責めると、構造の問題が視界から消えてしまうのです。

なお、この一節は流布本では「不責於人」の形で知られています。本書が底本とする四庫全書本では「不責之於人」で、意味はほぼ変わりません。

```quote
原文: 故善戰人之勢、如轉圓石於千仞之山者、勢也。
訓読: 故に善く人を戦わしむるの勢、円石を千仞の山に転ずるが如き者は、勢なり。
出典: 勢篇
訳: 兵をうまく戦わせる勢いとは、丸い石を高い山の上から転がすようなものである。これが勢である。
```

篇の結びです。この直前で孫子は、木や石の性質を説明しています。平らな所に置けば静かで、傾いた所に置けば動き出す。四角ければ止まり、丸ければ転がる。勢に任せる者は、兵をこの木石のように扱うと言います。

「円石（えんせき）」は丸い石、「千仞（せんじん）」はきわめて高いことを表す言葉です。仞は古い長さの単位で、一仞の長さには諸説あります。

この喩えには、勢篇の要素がすべて入っています。石の重さは、どこに置いても変わりません。変わるのは、置く場所と石の形です。高い所に置くことは、前の篇の「形」が作る落差にあたります。丸い形は、指揮信号と編制によって、全体が一つに動ける状態を指すと読めます。そして転がす一押しが「節」です。石そのものを鍛えるのではなく、石の置き場所と形を整える。同じ兵力で結果が違う理由が、ここに一枚の絵として示されています。

## 構造を図で見る

![図5 奇正の循環と節 — 斜面に置いた円石と、それを放つ一瞬](figures/05-momentum.svg)

図5は、勢篇の論理を一枚にまとめたものです。左から右へ、三つの段階に分かれています。

左側の土台は、分数と形名です。部隊を分け、信号でつなぐことで、大軍が一つの塊として動けるようになります。これが、石を丸く整える作業にあたります。

中央の斜面は、前の篇の形が作った落差です。丸い石は坂の上に置かれ、まだ止まっています。動いていなくても、この時点ですでに勢は蓄えられています。斜面の脇に描いた輪は、奇と正が互いを生みながら巡る様子です。どちらから押し出すかは、相手の予想に合わせて選びます。

右側の一点が節、つまり石を放つ瞬間です。溜めの時間は長く、放つ時間は短い。この対比が図の要点です。人を責める前に、石の形、坂の高さ、放つ一瞬のどこが欠けているかを確かめる。図はそのための点検表としても使えます。

図の石は一つですが、実際の戦いでは、同じ坂の上にいくつもの石が並びます。どの石を先に放ち、どれを後に残すかが、奇正の組み替えにあたります。一つの勢を使い切らず、次の勢を坂の上に残しておくことも、尽きない奇の一部です。

## 異分野への接続

```connect
title: 物理——位置エネルギーは「置く」ことで蓄え、「放す」ことで動く
物理学では、高い所にある物体は位置エネルギーを持つと考えます。位置エネルギーとは、置かれた位置のおかげで、物体が後で仕事をする能力のことです。その大きさは、重さと高さを掛けたものに比例します。

ボールを棚の上に持ち上げても、その瞬間には何も起きません。けれども、手を離せばボールは落ち、蓄えられたエネルギーは運動に変わります。同じボールでも、床の高さから落とすか、二階から落とすかで、着地の衝撃はまったく違います。

勢篇と同じ形をしているのは、力が物そのものではなく、置かれた位置から生まれる点です。どちらも「置く」段階で力を蓄え、「放す」段階で運動に変えるという二段の仕組みを持っています。前の篇の形が「置く」に、この篇の勢が「放す」にあたります。さらに、角ばった石は摩擦で止まり、丸い石は転がり続けるという点も、円石の喩えと重なります。

違いもあります。物理のエネルギーは保存され、放せば計算どおりに運動へ変わります。戦場の勢は、相手が身構えていれば削がれ、坂の向きを読まれれば空振りします。勢は、相手との関係の中でしか値が決まらないのです。
```

```connect
title: 音楽——拍と「節」、同じ音でも入る瞬間で効果が変わる
合奏で、全員が同じ大きさで同じ音を鳴らす場面を考えます。拍の頭にぴたりとそろえば、一つの大きな響きになります。わずかにずれれば、音量は同じでも響きは濁り、迫力は失われます。効果を決めるのは音の量ではなく、入る瞬間です。

音楽には、聴き手の予想をずらす技法もあります。シンコペーションとは、本来は弱いはずの拍に強さを置き、拍の感覚をずらすことです。聴き手は規則正しい拍を予期しているので、そのずれが驚きと推進力を生みます。また、大きな音の直前に置かれた休符は、音そのものより強い印象を残すことがあります。

勢篇と同じ形をしているのは、力の大きさが量ではなく、相手の予期に対するタイミングで決まる点です。規則正しい拍が「正」、ずらしが「奇」にあたり、休符で溜めて一気に鳴らすのが「節」にあたります。規則が聴き手の耳に定着しているからこそ、ずらしが効くという点も、正が奇を支える構図と同じです。

違いは、相手の構えです。音楽の聴き手は驚きを楽しむために耳を傾けますが、戦場の相手は驚かされまいとして身構えます。
```

## 誤解されやすい点

```note
「勢」は、日常語の「勢い」よりずっと広い言葉です。日常語の勢いは、速さや気分の盛り上がりを指し、「勢いで決めた」のように使います。孫子の勢は、配置と形とタイミングが生む力そのものです。坂の上で止まっている丸い石にも、すでに勢はあります。気合いや熱気で勢を作れるとは、勢篇は一度も言っていません。なお、この篇は「兵勢篇」という名でも知られています。
```

## この篇の一行

勢篇を一文にまとめるなら、こうなります。力は人から絞り出すものではなく、配置から引き出すものだ、と。形が落差を作り、勢がその落差を一瞬で流します。奇と正を組み替え続け、溜めは長く、放ちは短くする。そうすれば、同じ兵力でも結果は変わります。人を責める前に、坂と石と一瞬を点検する。それが勢篇の教える順序です。

ただし、石を転がす坂は、相手の目の前にあります。相手が坂の下を避け、こちらを不利な場所へ誘い出したら、どれほど蓄えた勢も空を切ります。勢を作るには、相手を動かし、自分は動かされないこと。
