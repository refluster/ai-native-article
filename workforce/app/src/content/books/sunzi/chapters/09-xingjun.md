# 行軍篇 — 地を読み、兆候を読む

## 小さな変化は語るか

前章では、原則を守りながら状況に応じて変えてよいものを見分ける、という将の判断を読みました。では、その判断の材料はどこから来るのでしょうか。行軍篇は、その答えを足元の地形と、地平線の向こうの気配に求めます。軍を進め、陣を置き、敵を観察する。篇名の「行軍」は、この一連の実務を指す言葉です。

山道を歩いていて、前方の茂みから鳥が一斉に飛び立つ場面を思い浮かべてみましょう。鳥は何も語りません。けれども、何かが鳥を驚かせたことは確かです。風か、獣か、それとも息を潜めた人か。目に見える小さな変化の向こうに、目に見えない原因があります。行軍篇の後半は、この推論の練習帳のような形をしています。

戦場に限った話ではありません。いつもは早く返ってくる連絡が遅れる。会議で特定の人だけが急に口数を減らす。こうした小さな変化に、私たちは日々何かを読み取ろうとしています。ただ、読み取ったつもりで外すことも少なくありません。変化を見落とすこともあれば、何でもない変化に意味を読み込みすぎることもあります。

この篇が答える問いは一つです。目の前の小さな変化から、相手の意図は読めるのか。篇の構成から見えてくる答えは、条件つきの「読める」です。条件とは、まず読める位置に自分の足場を置くこと、そして読んだ結果を実行に移せる組織を持つことです。本章では、地の読み方、兆候の読み方、人の読み方を、篇の順に追っていきます。

## 地を読む——四つの軍と高い場所

行軍篇は、四つの環境に応じた陣の置き方から始まります。山に処する軍、水に処する軍、斥沢（せきたく）に処する軍、平陸に処する軍です。斥沢とは、塩分を含んだ湿地のことです。山では谷に沿って進み、見晴らしのよい高所に陣を取ります。湿地は急いで通り抜け、やむなく戦うなら水と草のそばに拠ります。平地では動きやすい場所を選び、高い所を右後ろに置きます。

水に処する軍の項には、よく知られた一節があります。

```quote
原文: 客絕水而來、勿迎之於水內、令半渡而擊之、利
訓読: 客、水を絶りて来たらば、之を水の内に迎うる勿く、半ば渡らしめて之を撃つは、利なり。
出典: 行軍篇
訳: 敵が川を渡って攻めてくるときは、水の中で迎え撃たず、半分ほど渡らせたところを撃てば有利である。
```

ここでいう「客」は、攻めてくる側の軍を指します。迎え撃つ側を主人に見立てた言い方です。川を渡りきった部隊は、隊形を整えられます。まだ渡っていない部隊は、岸で態勢を保てます。最も弱いのは、半分が水の中、半分が岸にいる瞬間です。前後に分かれた軍は、互いに助け合えません。

この一節は、相手の弱さが「状態」よりも「移り変わり」に宿ることを教えます。強い軍でも、ある形から別の形へ移る途中では脆くなります。同時に、こちらが水の中に入って迎えてはいけないとも念を押しています。自分が移り変わりの途中に身を置けば、同じ弱さを抱えるからです。

四つの軍の記述を終えると、篇は「凡そ此の四軍の利は、黄帝の四帝に勝ちし所以なり」とまとめます。黄帝は中国の伝説上の帝王で、四方の帝を破ったと伝えられます。史実かどうかは確かめられません。ここで大事なのは、地形に応じた布陣が古くからの勝ち方だ、という位置づけです。

```quote
原文: 凡軍好高而惡下、貴陽而賤陰
訓読: 凡そ軍は高きを好みて下きを悪み、陽を貴びて陰を賤しむ。
出典: 行軍篇
訳: およそ軍は、高い所を好んで低い所を嫌い、日当たりのよい所を重んじて日陰を避ける。
```

四つの環境を貫く原則が、この一節です。高い所が好まれる第一の理由は、見通しです。高所からは敵の動きが見え、低所からは見えません。攻め下る側は勢いを得て、攻め上る側は疲れます。

「陽」と「陰」は、ここでは日の当たる側と当たらない側を指します。原文はこのあと「生を養いて実に処れば、軍に百疾無し」と続きます。水や草が得やすく乾いた土地に陣を置けば、病が出ないという意味です。長く野営する軍にとって、病は戦わずに兵を失う原因になります。

つまり高く明るい場所は、敵を見るための場所であり、自軍を保つための場所でもあります。観察の足場と暮らしの足場が、一つの選択で同時に手に入るのです。兆候を読む前に、まず読める位置に立つ。行軍篇の前半は、その準備にあてられています。

## 兆候を読む——鳥・獣・塵・言葉

高所の原則のあと、篇は近づいてはならない地形を並べます。切り立った谷川、四方を囲まれた窪地、草木が絡み合って抜け出せない土地などです。篇はそこで「吾は之に遠ざかり、敵は之に近づかしむ」と述べます。自分は遠ざかり、敵がそこに近づくように仕向けよ、という意味です。悪い地形は避けるだけでなく、相手を押し込む場所にもなるのです。

陣を構えたら、次は周囲を見張ります。篇はまず、伏兵が潜みやすい場所を挙げます。険しい地形、水たまり、林、葦の茂みなどです。そうした場所は念入りに捜索せよと述べたあと、篇の中心となる兆候の列挙が始まります。

```quote
原文: 鳥起者、伏也。獸駭者、覆也
訓読: 鳥起つ者は、伏なり。獣駭く者は、覆なり。
出典: 行軍篇
訳: 鳥が飛び立つのは伏兵がいるからであり、獣が驚いて逃げ出すのは奇襲部隊が迫っているからである。
```

「伏」は待ち伏せの兵、「覆」は不意を突いて襲う部隊のことです。鳥や獣は、人の気配に人より敏感です。だから動物の異変は、人の目に入らない場所の出来事を知らせてくれます。見えないものを、見えるものを通して知る。これがこの一節の骨格です。

同じ形の条はほかにも続きます。塵が高く鋭く立つのは、戦車が来るからです。低く広がるのは、歩兵が来るからです。細く散らばるのは、薪を集めているからです。塵の形が、その下にいる者の種類と目的を教えます。

人の言葉も兆候になります。使者の言葉がへりくだっているのに守りを固めているなら、進撃の準備です。言葉が強気で前に押し出してくるなら、退く準備です。言葉と行動が食い違うとき、信じるべきは行動のほうだという読み方がここにあります。

日本では、源義家が鳥の飛び立つ様子から伏兵を見破った話が、この教えの実践として語られます。ただし、この話を載せる『古今著聞集』は後三年の役の約170年後に成った書物です。義家の学んだ兵法が『孫子』だとは書かれていません。

兆候の列挙を終えると、篇は兵の数について短く語ります。底本では「兵は益々多きを貴ぶに非ず」と書かれる一文です。むやみに突き進まず、力を一つに合わせ、敵の実情を見積もり、人を得られれば十分だ、という内容です。そのすぐあとに、次の警告が置かれています。

```quote
原文: 夫惟無慮而易敵者、必擒於人。
訓読: 夫れ惟だ慮り無くして敵を易る者は、必ず人に擒にせらる。
出典: 行軍篇
訳: 深く考えもせずに敵を侮る者は、必ず敵に捕らえられる。
```

「易る（あなどる）」は、相手をたやすいと見なすことです。「慮り無く」は、考えを巡らせないことです。この警告は、直前の兆候の列挙と対になっています。三十あまりの兆候は、敵を見積もるための道具です。その道具を使わずに相手を軽く見る者は捕らえられる、と篇は言います。

慢心が先にあると、兆候は目に入っても意味として読まれません。鳥が飛び立っても、「ただの鳥だろう」で済ませてしまいます。観察の失敗は、多くの場合、目ではなく心構えの側で起きるのです。

ここで兵の数の話と観察の話がつながります。数は観察の代わりになりません。数を頼む者ほど観察を怠り、観察を怠る者ほど数に頼ります。行軍篇がこの二つを並べて置いたのは、その悪循環を断つためだと読めます。

ここまでの兆候の読み方を、一枚の図にまとめます。

![図9 兆候→推論 — 鳥・獣・塵・使者の言葉という観測から、伏兵・奇襲・接近・意図を推論する対応](figures/09-signs.svg)

図の左には観測できるもの、右にはそこから推論されるものを置いています。鳥、獣、塵、使者の言葉という四つの観測が、それぞれ伏兵、奇襲、戦車や歩兵の接近、進退の意図へとつながります。矢印は原因から結果ではなく、結果から原因へ向いています。私たちが見ているのは結果だけで、原因は推論するしかないからです。

図で見ると、もう一つ気づくことがあります。対応は一対一ではありません。鳥が飛び立つ原因は、伏兵以外にもありえます。だから篇は、伏兵の潜みやすい場所を先に挙げ、そこを捜索せよと言います。地の読みが兆候の読みを絞り込み、兆候の読みが次の行動を決める。篇の前半と後半は、この順序で一つの手続きになっています。

## 人を読む——信頼と規律の順序

篇の最後は、敵ではなく自軍に目を向けます。兆候を読めても、それに応じて動く兵がいなければ意味がありません。

```quote
原文: 卒未親附而罰之、則不服、不服則難用也。卒已親附而罰不行、則不可用也。
訓読: 卒未だ親附せずして之を罰すれば、則ち服せず。服せざれば則ち用い難きなり。卒已に親附して罰行われざれば、則ち用うべからざるなり。
出典: 行軍篇
訳: 兵がまだ将になついていないうちに罰すれば、心服しない。心服しなければ使いにくい。兵がすでになついているのに罰を行わなければ、やはり使いものにならない。
```

「親附（しんぷ）」は、兵が将になつき、心を寄せることです。この一節は、罰の時期について二つの失敗を並べています。一つは、関係ができる前に罰することです。兵はなぜ罰せられるのか納得できず、心が離れます。もう一つは、関係ができたあとに罰を行わないことです。兵は規律を軽く見るようになり、命令が通らなくなります。

大事なのは、二つの失敗が正反対の方向にあることです。厳しすぎても甘すぎても、軍は使えなくなります。しかも、どちらが正しいかは時期によって変わります。同じ罰が、関係の前では反発を生み、関係の後では秩序を生みます。

これは兆候の話とも無関係ではありません。相敵の条には「数（しばしば）賞する者は窘しむなり、数罰する者は困しむなり」とあります。賞罰を乱発する軍は、行き詰まっている兆候だというのです。敵を読む目は、そのまま自軍を読む目にもなります。

```quote
原文: 故令之以文、齊之以武、是謂必取。
訓読: 故に之に令するに文を以てし、之を斉うるに武を以てす。是を必取と謂う。
出典: 行軍篇
訳: だから兵には恩愛と道理で命じ、規律と刑罰で統制する。これを必ず勝ちを取る道という。
```

「文」は恩愛や道理による導き、「武」は規律や刑罰による統制です。二つは対立するものではなく、重ねて使うものとして置かれています。まず文で命じ、そのうえで武で揃える。前の一節が示した「親附の前と後」が、ここで方法として言い直されています。

「必取（ひっしゅ）」は、必ず勝ちを取る道という意味です。勝ちを取る道を、策略でも兵の数でもなく、統率の形に求めている点が目を引きます。

篇はこのあと、命令が日ごろから行われて民を教えていれば民は服し、そうでなければ服さない、と続けます。命令が日ごろから行われるのは、将と兵が互いに通じ合っているからだ、と篇は結びます。日常の命令が信頼を育て、その信頼が非常時の命令を通します。兆候を読む力も、読んだ結果を実行に移す組織があって初めて生きるのです。

## 同じ形をほかに探す

```connect
title: システム運用の「観測可能性」
大規模なソフトウェアの運用では、観測可能性という考え方が重んじられます。外から見える出力だけで、内部で何が起きているかを推論できる度合いのことです。運用者が直接見られるのは、動作の記録（ログ）や数値の推移（メトリクス）だけです。

応答が遅くなった、誤りの記録が急に増えた、ある数値だけが跳ね上がった。これらは行軍篇の「塵」にあたります。塵の形から車か徒歩かを見分けたように、運用者は数値の形から原因を絞り込みます。鋭く立ち上がる変化と、ゆっくり広がる変化では、疑うべき原因が違います。

なぜ同じ形なのか。どちらも、原因を直接は見られず、原因が残す痕跡だけから原因を推論する問題だからです。行軍篇が高所に陣を取ったように、運用でも観測の足場を先に作ります。何を記録するかを事前に決めておかなければ、異変が起きても読む材料がありません。

違いもあります。システムの痕跡は、敵のように意図して偽装してくることはまれです。行軍篇の兆候には、使者の低姿勢のように、相手がわざと見せる偽の兆候が含まれています。
```

```connect
title: 医療の問診——症状から病を推す
医師の診察は、問診から始まります。いつから、どこが、どのように痛むのか。患者の言葉と体に現れた症状は、見えない病を知らせる兆候です。医師はそこから考えられる病をいくつか挙げ、検査で絞り込んでいきます。

この手続きは、行軍篇の構成とよく重なります。まず、どんな人かという足場を確かめます。年齢や持病、最近の行動によって、同じ症状でも疑う病が変わります。伏兵の潜みやすい場所を先に知っておくのと同じです。次に症状を読み、最後に診断に基づいて治療という行動に移ります。

なぜ同じ形なのか。どちらも、一つの兆候に複数の原因がありうる中で、事前の知識と組み合わせて最も確からしい原因を選ぶ推論だからです。鳥が飛び立つ理由が伏兵だけではないように、発熱の理由も一つではありません。

違うのは、患者の多くが協力者だという点です。病は兆候を隠そうとしませんが、敵は兆候を隠し、ときには作り出します。
```

```note
相敵（敵情を見積もること）の条は三十あまりあり、本章で取り上げたのは鳥・獣・塵・使者の言葉・賞罰など代表的な例だけです。ほかにも「杖をついて立つ者は飢えている」「水を汲んで先に飲む者は渇いている」といった条が続きます。「夜に叫ぶ者は恐れている」「鳥が集まる陣は空である」もその一部です。
```

## この篇の一行

行軍篇を一文にすれば、「見通せる足場に立ち、見えるものから見えないものを推し、推したことを動かせる軍を育てよ」となります。地の読み、兆候の読み、人の読みは、別々の技術ではありません。高所は観察を可能にし、観察は慢心を防ぎ、信頼と規律は観察の結果を行動に変えます。冒頭の問いに戻れば、小さな変化から相手の意図は読めます。ただしそれは、読む位置と読む心構え、そして読んだあとに動く組織がそろっているときに限られます。兆候を読んだら、地形そのものを味方にする。
